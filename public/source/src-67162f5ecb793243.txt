"""PATCH_RESNET_GN -- `ResNet18_gn`: ResNet18 with every BatchNorm2d replaced by
GroupNorm(32, C), AND NOTHING ELSE CHANGED.  Patches `build_network.py` ONLY.
**NO OPTIMISER CHANGE.  `Optimizers/HF.py` IS NOT TOUCHED BY THIS PATCH.**

WHY.  The campaign's tail mechanism says the matched-count partition gap
    D = plateau5(chunk777) - plateau5(nodewise)
lives ENTIRELY in the degenerate size-1 tail: nodewise's m = 14,420 groups contain
9,610 size-1 groups (66.6436%) covering 0.0860% of the weights, and all of them sit on
the 41 one-dimensional tensors -- every BatchNorm scale and shift, plus `linear.bias`.
With the tail already merged on both sides the gap collapses (G = chunk2325 -
nodewise1d = +0.295 UNDECIDED / +0.011 / -0.001).

That sentence contains the word "BatchNorm" in one reading and the word "size-1" in
another, and NOTHING THE CAMPAIGN OWNS SEPARATES THEM.  Every D was measured on a net
whose only 1-D tensors are BatchNorm parameters, so "the carrier is the degenerate
tail" and "the carrier is BatchNorm" are the same measurement seen twice.

WHAT THIS PATCH MAKES POSSIBLE, AND WHAT IT DOES NOT.  `nn.GroupNorm(G, C)` has
`weight` and `bias` of shape `(C,)`, EXACTLY as `nn.BatchNorm2d(C)` does, and BN's
`running_mean` / `running_var` are BUFFERS -- they never enter `named_parameters()`, so
they never received a step size under any granularity and their absence changes
nothing.  Therefore:

    ResNet18      11,173,962 params | 62 tensors | 41 one-D | m(nodewise) 14,420
                  9,610 singletons  | m(nodewise1d) 4,851   | m(chunk777) 14,421
    ResNet18_gn   IDENTICAL IN EVERY ONE OF THOSE COLUMNS

and `train.py` / `Optimizers/HF.py` contain NO module-type logic whatsoever (no
`BatchNorm`, no `named_modules`, no `isinstance`-on-modules; `HF.init_meta` is driven
entirely by `[(name, p.data.size()) for name, p in net.named_parameters()]`).  So the
partition is not merely SIMILAR across the two networks -- **it is provably the same
object**, and exactly one thing in the experiment changes.

    IT IS THEREFORE A TEST OF: is the gap carried by the degenerate size-1 tail PER SE,
    or by BATCHNORM specifically?
    IT IS **NOT** A TEST OF: "does a network without normalisation show a partition
    gap".  IT REMOVES ZERO SINGLETONS.  `bin/c84_normaliser_transfer.sh` T3.2 forbids
    writing it up as one, and this docstring is part of that prohibition.

THE DECLARED CONFOUNDS, WRITTEN BEFORE ANY RUN EXISTS.  BatchNorm normalises PER
CHANNEL, so gamma_c is the sole controller of a channel's effective magnitude.
`nn.GroupNorm(32, C)` takes num_groups=32, so it forms **32 GROUPS OF C/32 CHANNELS**
-- 2, 4, 8 and 16 channels per group at ResNet18's widths 64/128/256/512.  (An earlier
draft of this docstring said "blocks of 32 channels".  THAT WAS BACKWARDS, and since it
was the sole basis of this paragraph it is corrected here, at cycle-84 review, BEFORE
any run.)  Per-channel scale invariance therefore does NOT hold -- and the departure is
GRADED BY DEPTH: nearly per-channel at layer1 (2 to a group), 16 to a group at layer4.
Only the PARTITION role of a singleton is preserved, not its FUNCTIONAL role.
The test is ASYMMETRIC: a POSITIVE (the gap survives) is clean, because all three of
the readings below can only SUPPRESS a gap, never manufacture one.  A NULL is ambiguous
between THREE readings and this batch separates NONE of them: (i) the carrier is batch
statistics; (ii) the carrier is per-channel scale invariance, depth-graded as above;
(iii) MISTUNING -- gn1 runs a different network at a BatchNorm-derived cell with no
argmax located on either net (RULE 11).  So a null from gn1 alone MAY NOT be written as
a mechanism narrowing.  The follow-ups are registered in advance in
bin/c84_normaliser_transfer.sh: gn2a, the alpha0=3e-4 tuning bracket (provably box-free
in BOTH directions), and gn2b, `GroupNorm(num_groups == C)`.

WHY G = 32.  Every ResNet18 channel count is 64/128/256/512, each divisible by 32,
including the three downsample shortcuts, so `nn.GroupNorm(32, C)` constructs
everywhere.  LayerNorm is REJECTED: on conv activations it is `GroupNorm(1, C)` -- the
same caveat in its most extreme form, with no compensating advantage.

WHAT THIS PATCH ADDS -- FOUR ADDITIVE EDITS, NO EXISTING BEHAVIOUR ALTERED.
  1. `_norm2d(norm, c)`: `nn.BatchNorm2d(c)` when norm == 'bn', `nn.GroupNorm(32, c)`
     when norm == 'gn', and `0/0` otherwise -- the file's own error idiom, so a typo'd
     norm raises instead of silently building a BatchNorm net.
  2. `BasicBlock.__init__(..., norm='bn')` and `Bottleneck.__init__(..., norm='bn')`.
  3. `ResNet.__init__(..., norm='bn')`, stored as `self._norm` and threaded through
     `_make_layer`.
  4. `if network_name == 'ResNet18_gn': return ResNet(BasicBlock, [2,2,2,2], norm='gn')`.

**THE ATTRIBUTE NAMES ARE UNCHANGED.**  `bn1`, `bn2`, `bn3` and the shortcut's
`nn.Sequential` index 1 keep their names and positions, so `named_parameters()` yields
the SAME NAMES IN THE SAME ORDER for both networks.  That is not cosmetic: `HF.init_meta`
consumes that list positionally, so a reordering would silently re-map every beta.
`tests/test_resnet18_gn.py` G3 asserts the two lists are elementwise equal.

INERTNESS.  `norm` defaults to `'bn'` in all three signatures and `_norm2d('bn', c)` is
`nn.BatchNorm2d(c)`, so every one of the twelve existing `network_name` strings takes a
construction path that is textually and semantically what it was before.  `ResNet_soft`
and `BasicBlock_soft` are NOT TOUCHED AT ALL.  The new name `'ResNet18_gn'` is reachable
only by an exact `--NN-name ResNet18_gn`, which no prior batch used (verified against
`results/all_runs.csv`: the `network` column holds only ResNet18/18_c100/10/10_c100/
34/34_c100/50/101).  `tests/test_resnet18_gn.py` G1 asserts inertness the strong way --
BITWISE, against the UNPATCHED tree, on both the initial weights and a 25-step run --
rather than against my reading of the diff.

STANDING RULE 20 is observed by the suite: it runs on CPU and its FIRST assertion is
that a configuration equals ITSELF.

APPLY (OPERATOR STEP -- this repo does NOT ship the patched cluster file):
    ssh cluster_a
    cd /cluster/account_a/metaopt
    cp MetaOptimize/codes/Supervised_tasks/MetaOptimize/cifar10/build_network.py \
       MetaOptimize/codes/Supervised_tasks/MetaOptimize/cifar10/build_network.py.pre_gn
    python3 hierarchical-metaoptimize/patches/patch_resnet_gn.py
    module load Python/3.10.4-GCCcore-11.3.0 && source envs/mo/bin/activate
    cd hierarchical-metaoptimize && NODEBN_TEST_DEVICE=cpu python3 tests/test_resnet18_gn.py
VERIFY WITHOUT TOUCHING THE LIVE TREE (what this tick did):
    BUILD_NET_PATH=<scratch copy>/build_network.py python3 patches/patch_resnet_gn.py
    CIFAR10_DIR=<scratch copy> GN_TEST_REF_DIR=<live tree> \
        NODEBN_TEST_DEVICE=cpu python3 tests/test_resnet18_gn.py
"""
import os
import sys

P = os.environ.get(
    "BUILD_NET_PATH",
    "/cluster/account_a/metaopt/MetaOptimize/codes/Supervised_tasks/"
    "MetaOptimize/cifar10/build_network.py")

src = open(P).read()

# --- 0. idempotency.  Re-running must not double-patch. --------------------------------
if "PATCH_RESNET_GN" in src:
    print("PATCH_RESNET_GN already applied to", P, "-- nothing to do")
    sys.exit(0)

# The file this patch was written against, byte-identical (md5 3ce37b89fd93302c7a26862
# d2e592824, 255 lines).  Anchors below are asserted to occur EXACTLY ONCE, which is the
# real guard; this is the cheap sanity line.
if "class ResNet(nn.Module):" not in src or "def build_network(" not in src:
    sys.exit("refusing to patch: %s is not a MetaOptimize build_network.py" % P)

# --- 1. the normaliser factory -------------------------------------------------------
# Inserted immediately before BasicBlock_soft, i.e. at the top of the ResNets section and
# ABOVE every class that calls it.  BasicBlock_soft itself is not modified.
a1 = "class BasicBlock_soft(nn.Module):\n"
assert src.count(a1) == 1, f"anchor 1 count={src.count(a1)} -- refusing to patch"
n1 = """# --- PATCH_RESNET_GN: the normaliser factory. -----------------------------------
# nn.GroupNorm(G, C) has weight and bias of shape (C,), EXACTLY as nn.BatchNorm2d(C)
# does, so the parameter shape list -- and therefore every step-size partition HF.py
# computes from it -- is IDENTICAL for the two.  BN's running_mean/running_var are
# BUFFERS and never enter named_parameters(), so they never carried a step size.
# G = 32 divides every ResNet18 channel count (64/128/256/512), including the three
# downsample shortcuts.  An unknown `norm` raises via the file's own 0/0 idiom rather
# than falling back to BatchNorm, so a typo cannot silently produce the control arm.
GN_GROUPS = 32


def _norm2d(norm, c):
    if norm == 'bn':
        return nn.BatchNorm2d(c)
    if norm == 'gn':
        return nn.GroupNorm(GN_GROUPS, c)
    0/0  # unknown normaliser -- fail loudly, exactly as build_network does


""" + a1
src = src.replace(a1, n1, 1)

# --- 2. BasicBlock: the norm kwarg, ATTRIBUTE NAMES UNCHANGED ------------------------
a2 = """class BasicBlock(nn.Module):
    expansion = 1

    def __init__(self, in_planes, planes, stride=1):
        super(BasicBlock, self).__init__()
        self.conv1 = nn.Conv2d(
            in_planes, planes, kernel_size=3, stride=stride, padding=1, bias=False)
        self.bn1 = nn.BatchNorm2d(planes)
        self.conv2 = nn.Conv2d(planes, planes, kernel_size=3,
                               stride=1, padding=1, bias=False)
        self.bn2 = nn.BatchNorm2d(planes)

        self.shortcut = nn.Sequential()
        if stride != 1 or in_planes != self.expansion*planes:
            self.shortcut = nn.Sequential(
                nn.Conv2d(in_planes, self.expansion*planes,
                          kernel_size=1, stride=stride, bias=False),
                nn.BatchNorm2d(self.expansion*planes)
            )
"""
assert src.count(a2) == 1, f"anchor 2 count={src.count(a2)} -- refusing to patch"
n2 = """class BasicBlock(nn.Module):
    expansion = 1

    # --- PATCH_RESNET_GN: `norm` added with the default 'bn'.  The attribute names
    # bn1 / bn2 and the shortcut Sequential's index 1 are DELIBERATELY UNCHANGED, so
    # named_parameters() yields the same names in the same order under either norm --
    # HF.init_meta consumes that list POSITIONALLY.
    def __init__(self, in_planes, planes, stride=1, norm='bn'):
        super(BasicBlock, self).__init__()
        self.conv1 = nn.Conv2d(
            in_planes, planes, kernel_size=3, stride=stride, padding=1, bias=False)
        self.bn1 = _norm2d(norm, planes)
        self.conv2 = nn.Conv2d(planes, planes, kernel_size=3,
                               stride=1, padding=1, bias=False)
        self.bn2 = _norm2d(norm, planes)

        self.shortcut = nn.Sequential()
        if stride != 1 or in_planes != self.expansion*planes:
            self.shortcut = nn.Sequential(
                nn.Conv2d(in_planes, self.expansion*planes,
                          kernel_size=1, stride=stride, bias=False),
                _norm2d(norm, self.expansion*planes)
            )
"""
src = src.replace(a2, n2, 1)

# --- 3. Bottleneck: the same kwarg, so ResNet can thread `norm` to EITHER block ------
# ResNet50/101/152 pass through here.  They keep norm='bn' by default and are untouched
# in effect; the kwarg exists only so _make_layer can pass it uniformly.
a3 = """class Bottleneck(nn.Module):
    expansion = 4

    def __init__(self, in_planes, planes, stride=1):
        super(Bottleneck, self).__init__()
        self.conv1 = nn.Conv2d(in_planes, planes, kernel_size=1, bias=False)
        self.bn1 = nn.BatchNorm2d(planes)
        self.conv2 = nn.Conv2d(planes, planes, kernel_size=3,
                               stride=stride, padding=1, bias=False)
        self.bn2 = nn.BatchNorm2d(planes)
        self.conv3 = nn.Conv2d(planes, self.expansion *
                               planes, kernel_size=1, bias=False)
        self.bn3 = nn.BatchNorm2d(self.expansion*planes)

        self.shortcut = nn.Sequential()
        if stride != 1 or in_planes != self.expansion*planes:
            self.shortcut = nn.Sequential(
                nn.Conv2d(in_planes, self.expansion*planes,
                          kernel_size=1, stride=stride, bias=False),
                nn.BatchNorm2d(self.expansion*planes)
            )
"""
assert src.count(a3) == 1, f"anchor 3 count={src.count(a3)} -- refusing to patch"
n3 = """class Bottleneck(nn.Module):
    expansion = 4

    # --- PATCH_RESNET_GN: `norm` added with the default 'bn'; names unchanged. ---
    def __init__(self, in_planes, planes, stride=1, norm='bn'):
        super(Bottleneck, self).__init__()
        self.conv1 = nn.Conv2d(in_planes, planes, kernel_size=1, bias=False)
        self.bn1 = _norm2d(norm, planes)
        self.conv2 = nn.Conv2d(planes, planes, kernel_size=3,
                               stride=stride, padding=1, bias=False)
        self.bn2 = _norm2d(norm, planes)
        self.conv3 = nn.Conv2d(planes, self.expansion *
                               planes, kernel_size=1, bias=False)
        self.bn3 = _norm2d(norm, self.expansion*planes)

        self.shortcut = nn.Sequential()
        if stride != 1 or in_planes != self.expansion*planes:
            self.shortcut = nn.Sequential(
                nn.Conv2d(in_planes, self.expansion*planes,
                          kernel_size=1, stride=stride, bias=False),
                _norm2d(norm, self.expansion*planes)
            )
"""
src = src.replace(a3, n3, 1)

# --- 4. ResNet: the kwarg, stored BEFORE _make_layer runs, threaded to the blocks ----
# ResNet_soft carries byte-identical __init__ and _make_layer bodies, so this anchor
# includes the class line and the super() line, which are what make it unique.
# ResNet_soft is NOT patched: it is not on this batch's path.
a4 = """class ResNet(nn.Module):
    def __init__(self, block, num_blocks, num_classes=10):
        super(ResNet, self).__init__()
        self.in_planes = 64

        self.conv1 = nn.Conv2d(3, 64, kernel_size=3,
                               stride=1, padding=1, bias=False)
        self.bn1 = nn.BatchNorm2d(64)
        self.layer1 = self._make_layer(block, 64, num_blocks[0], stride=1)
        self.layer2 = self._make_layer(block, 128, num_blocks[1], stride=2)
        self.layer3 = self._make_layer(block, 256, num_blocks[2], stride=2)
        self.layer4 = self._make_layer(block, 512, num_blocks[3], stride=2)
        self.linear = nn.Linear(512*block.expansion, num_classes)

    def _make_layer(self, block, planes, num_blocks, stride):
        strides = [stride] + [1]*(num_blocks-1)
        layers = []
        for stride in strides:
            layers.append(block(self.in_planes, planes, stride))
            self.in_planes = planes * block.expansion
        return nn.Sequential(*layers)
"""
assert src.count(a4) == 1, f"anchor 4 count={src.count(a4)} -- refusing to patch"
n4 = """class ResNet(nn.Module):
    # --- PATCH_RESNET_GN: `norm` added with the default 'bn'.  self._norm is set
    # BEFORE the first _make_layer call, because _make_layer reads it.  Attribute
    # names (bn1, layerN, linear) are unchanged, so named_parameters() ordering is
    # identical under either norm. ---
    def __init__(self, block, num_blocks, num_classes=10, norm='bn'):
        super(ResNet, self).__init__()
        self.in_planes = 64
        self._norm = norm

        self.conv1 = nn.Conv2d(3, 64, kernel_size=3,
                               stride=1, padding=1, bias=False)
        self.bn1 = _norm2d(norm, 64)
        self.layer1 = self._make_layer(block, 64, num_blocks[0], stride=1)
        self.layer2 = self._make_layer(block, 128, num_blocks[1], stride=2)
        self.layer3 = self._make_layer(block, 256, num_blocks[2], stride=2)
        self.layer4 = self._make_layer(block, 512, num_blocks[3], stride=2)
        self.linear = nn.Linear(512*block.expansion, num_classes)

    def _make_layer(self, block, planes, num_blocks, stride):
        strides = [stride] + [1]*(num_blocks-1)
        layers = []
        for stride in strides:
            layers.append(block(self.in_planes, planes, stride, norm=self._norm))
            self.in_planes = planes * block.expansion
        return nn.Sequential(*layers)
"""
src = src.replace(a4, n4, 1)

# --- 5. the dispatch, inserted directly after ResNet18's ------------------------------
a5 = """    if network_name == 'ResNet18':
        return ResNet(BasicBlock, [2, 2, 2, 2]).to(device)
"""
assert src.count(a5) == 1, f"anchor 5 count={src.count(a5)} -- refusing to patch"
n5 = a5 + """
    # --- PATCH_RESNET_GN: the ONLY new name.  Same block, same depths, same class
    # count; GroupNorm(32, C) in place of BatchNorm2d(C).  Reachable only by an exact
    # `--NN-name ResNet18_gn`, which no prior batch used. ---
    if network_name == 'ResNet18_gn':
        return ResNet(BasicBlock, [2, 2, 2, 2], norm='gn').to(device)
"""
src = src.replace(a5, n5, 1)

# --- 6. POST-CONDITIONS, asserted on the patched text --------------------------------
# 6a: the twelve pre-existing dispatch names are all still present and unedited.
for name in ('M1', 'M2', 'ResNet18', 'ResNet18_c100', 'ResNet10', 'ResNet34',
             'ResNet10_c100', 'ResNet34_c100', 'ResNet18_soft', 'ResNet50',
             'ResNet101', 'ResNet152'):
    assert "network_name == '%s'" % name in src, "dispatch for %s went missing" % name
# 6b: exactly one new dispatch, and it is the only place norm='gn' appears.
assert src.count("network_name == 'ResNet18_gn'") == 1
assert src.count("norm='gn'") == 1, "norm='gn' must appear exactly once, in the dispatch"
# 6c: ResNet_soft / BasicBlock_soft are untouched -- they still construct BatchNorm2d
# directly and take NO norm kwarg.
assert "super(ResNet_soft, self).__init__()" in src
assert "def __init__(self, in_planes, planes, stride=1):\n        super(BasicBlock_soft" \
    in src, "BasicBlock_soft's signature changed -- it must not"
# 6d: no BatchNorm2d construction survives inside the three patched classes; they all
# go through the factory now.  (The factory itself and the _soft classes still name it.)
# COMMENT lines are excluded -- the docstring/comments this patch inserts mention
# nn.BatchNorm2d by name and are not construction sites.
_bn_code = sum(l.count("nn.BatchNorm2d(") for l in src.splitlines()
               if not l.lstrip().startswith("#"))
assert _bn_code == 5, (
    "expected exactly 5 nn.BatchNorm2d( CODE sites after patching: 1 in _norm2d and 4 "
    "in the untouched _soft classes (3 in BasicBlock_soft, 1 in ResNet_soft); found %d"
    % _bn_code)
# 6e: the factory is defined above its first use.
assert src.index("def _norm2d(") < src.index("self.bn1 = _norm2d(")
# 6f: nn is imported (the factory uses it); the file imports torch.nn as nn at the top.
assert "import torch.nn as nn" in src
# 6g: compiles.
compile(src, P, "exec")

open(P, "w").write(src)
print("PATCHED PATCH_RESNET_GN ->", P)
print("  added: _norm2d(norm, c) with GN_GROUPS=32; norm='bn' kwarg on BasicBlock, "
      "Bottleneck and ResNet; dispatch for 'ResNet18_gn'")
print("  NOW RUN THE SUITE ON CPU BEFORE ANY sbatch:")
print("    NODEBN_TEST_DEVICE=cpu python3 tests/test_resnet18_gn.py")
