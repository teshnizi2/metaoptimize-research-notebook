#!/bin/bash
# =============================================================================
# Cycle 73 -- wm9: THE **WEIGHTWISE** ARM OF THE ms LADDER, WHICH DOES NOT EXIST.
# cluster_a (account_a).  10 jobs.  Tag `wm9-*`.  100 epochs.
#
# THE OPEN QUESTION, AND WHY IT IS OPEN.
# `hz9` (this tick, FINDINGS 72.1) settled the nodewise-vs-layerwise comparison AT
# EACH ARM'S OWN TUNED ms: level -0.360 pp, inside a registered +-0.50 bar, TIED.
# Its H2 arm shows the same two partitions differ by **+1.138 pp paired 2/2** when
# compared at a COMMON ms=1e-3.  So a granularity contrast at fixed ms is partly a
# statement about which ms that partition happens to want, not about the partition.
#
# That makes the per-rung ms optimum the object of interest.  A FULLY AXIS-MATCHED
# census of results/all_runs.csv -- matching on all of network, dataset, batch_size,
# base, meta, alpha0, gamma, augment, beta_clip, hier, lam, eta_ratio, epochs_done
# -- gives, at 100 epochs (plateau5, non-collapsed):
#
#     rung          best ms     plateau5     n     frozen (ms=1e-8)
#     scalar          1e-4       92.262      5         90.451
#     nodewise        3e-4       92.450      5           --
#     resnet18_blk6   1e-4       92.652      2           --
#     layerwise       1e-4       92.867      8         90.316
#     weightwise        ??          ??       ??          --
#
#   * The four known rungs span **0.605 pp** once each is tuned.
#   * MISTUNING ms costs far more than choosing the partition: scalar falls
#     92.262 -> 87.839 between ms=1e-4 and ms=1e-3, **-4.42 pp**, and layerwise
#     falls 92.867 -> 91.196, **-1.67 pp**, over the same one-decade move.
#   * **WEIGHTWISE HAS EXACTLY ONE MATCHED RUN IN THE ENTIRE CORPUS**
#     (`kt2_ww_a1e-3_s0`, ms=1e-3, plateau5 91.308, n=1) -- and ms=1e-3 is
#     demonstrably PAST the optimum for every other rung that has been swept.
#
# So the campaign's weightwise numbers sit at an ms nobody has shown is right for
# weightwise, and weightwise is the rung the sign-agreement result (53.1% of
# 11,173,962 per-weight meta-gradients) is entirely about.  **Every "weightwise is
# worst" reading in this project is currently confounded with a single untuned ms.**
# THE `gc-w-*` RUNS DO NOT ANSWER THIS: they differ from the reference signature on
# at least one axis and drop out under full matching, which is exactly the
# contamination CORRECTIONS 99/100 catalogued.  Guard 3b re-checks that live.
#
# THE DESIGN.  ms in {1e-5, 3e-5, 1e-4, 3e-4, 1e-3} x seeds {0,1} = 10 jobs.
#   * The grid BRACKETS the other rungs' optimum (1e-4) by a decade either side,
#     so a weightwise optimum that sits where layerwise's does is detectable, and
#     one that sits lower is bracketed rather than clipped at the grid edge.
#   * ms=1e-3 is included as a REPRODUCTION CONTROL: it must land near the single
#     existing matched run's 91.308.  If it does not, the axis match is wrong and
#     the whole ladder is uninterpretable -- that check comes BEFORE any optimum.
#
# NO PROBE.  PROBE / PROBE5 are deliberately NOT exported.  This batch's question
# is ACCURACY vs ms, and the reference cells it must be comparable to (`rs-*`,
# `ms-*`) were run without them.  Adding instrumentation to one side of a matched
# comparison is the failure this file's own guard 3 exists to prevent.  THE COST IS
# STATED: wm9 yields no N_eff/m and no sign counts.  The right order is to LOCATE
# the optimum here, then re-run the single winning cell with PROBE5=1 for the
# sign-agreement read at a *tuned* weightwise operating point.
#
# THE PRE-REGISTERED GATES.  Nothing below may be edited after the data lands.
#
#   W0    VALIDITY.  epochs_done == 100 == requested, collapsed false, per job.
#   W0.2  **THE REPRODUCTION CONTROL, SCORED FIRST.**  wm9 at ms=1e-3 vs the
#         existing matched `kt2_ww_a1e-3_s0` plateau5 = 91.308.  Bar: |diff| <=
#         0.50 pp (STANDING RULE 9's level bar).  FAILS -> the ladder is VOID and
#         no optimum is read off it.  This gate can ONLY VOID.
#   W1    THE OPTIMUM.  argmax over ms of mean plateau5, n=2 per cell.  Reported
#         with its own SE, and DECIDED only if the gap to the runner-up exceeds
#         2 SE of the difference.  Otherwise UNDECIDED and the grid is refined.
#   W1b   **IS THE OPTIMUM INTERIOR?**  If the argmax is at a grid EDGE (1e-5 or
#         1e-3) the optimum is NOT bracketed and W2 is NOT scored -- the result is
#         "the grid is wrong", and the next batch extends it in that direction.
#         Registering this here is what stops an edge maximum being read as a peak.
#   W2    THE LADDER, ONLY IF W1b SAYS INTERIOR.  tuned weightwise vs the four
#         tuned rungs above.  REGISTERED PREDICTION, WRITTEN BEFORE THE DATA:
#         **weightwise's tuned plateau5 lands INSIDE [92.2, 92.9]**, i.e. within
#         the 0.605 pp band the other four rungs occupy, and its optimal ms is
#         **at or below 1e-4**.
#         CONFIRMS -> the granularity ladder is FLAT once every rung is ms-tuned,
#              across a 180,000x range in group count (62 -> 11.17M).  That is a
#              far stronger form of the campaign's central negative result than
#              "the anomaly is 0.5pp", and it is the sentence direction C needs.
#         REFUTES (weightwise below 92.2 at ITS OWN best ms) -> granularity has a
#              real cost at the finest partition that tuning cannot buy back, the
#              ladder is NOT flat, and the sqrt(N) literature's premise survives in
#              the one place this campaign has been unable to test it.
#         Either way it is a result.  That is why it is registered before the run.
#
# STRUCTURAL CHECKS BEFORE USING ANY NUMBER (Rule 4)
#   1. W0, W0.2 above, IN THAT ORDER, before W1 is even computed.
#   2. Re-derive the reference table above from results/all_runs.csv with the FULL
#      13-axis match -- never from this comment (STANDING RULE 1, 15).
#   3. plateau5 is PRIMARY.  best_test inflates ~0.37 pp, the size of this effect.
#
# USAGE
#   bash c73_wm9_weightwise_ms.sh            # dry run: prints every sbatch line
#   bash c73_wm9_weightwise_ms.sh --submit   # submits, ONLY if the guards pass
# =============================================================================
set -u

WS=/cluster/account_a/metaopt                   # cluster_a
RUNNER=$WS/jobs/run_cifar.sh
HF=$WS/MetaOptimize/codes/Supervised_tasks/MetaOptimize/cifar10/Optimizers/HF.py
SAVE=$WS/runs/wm9
PARTS=gpu-short,gpu-l4-24g,gpu-2080ti-11g,gpu-mig-40g,gpu-a100-80g
USER_NAME=account_a
PEND_CAP=40
NJOBS=10
CLIP=-15:-2.3026               # the rs-/ms- reference signature, NOT a new box
EPOCHS=100
WALL=03:50:00
GRID="1e-5 3e-5 1e-4 3e-4 1e-3"
SUBMIT=0
[ "${1:-}" = "--submit" ] && SUBMIT=1

echo "=== c73 wm9 -- the WEIGHTWISE arm of the ms ladder (cluster_a) ==="
echo "    ms in {$GRID} x seeds {0,1}, ${EPOCHS}ep, BETA_CLIP=$CLIP"
echo "    weightwise has ONE matched run in the whole corpus, at ms=1e-3"
echo "    W2 registers: tuned weightwise lands INSIDE [92.2, 92.9], best ms <= 1e-4"
echo

# GUARD 1 -- the runner and the optimizer source.
[ -r "$RUNNER" ] || { echo "GUARD FAIL: $RUNNER not readable"; exit 1; }
[ -r "$HF" ]     || { echo "GUARD FAIL: $HF not readable"; exit 1; }
grep -q PATCH_CLIP "$HF" || { echo "GUARD FAIL: PATCH_CLIP not present in $HF"; exit 1; }
echo "guard 1: runner readable; PATCH_CLIP present  OK"

python3 -c "import py_compile; py_compile.compile('$HF', doraise=True)" 2>/dev/null || {
  echo "GUARD FAIL: $HF does not compile"; exit 1; }
echo "guard 2: HF.py compiles  OK"

# GUARD 3 -- **THE AXIS SIGNATURE IS READ OUT OF THE CSV, NOT ASSERTED HERE.**
# This is the guard the whole batch stands on.  It re-derives the reference cell's
# 13-axis signature from results/all_runs.csv and checks that every axis this
# script sets equals it.  A mismatch on ANY axis makes wm9 incomparable to the
# ladder it is supposed to extend -- CORRECTIONS 99/100's contamination, caught
# before the compute rather than in an audit six cycles later.
# CSV PATH PASSED IN FROM BASH, never derived from __file__ (CORRECTIONS 101.11).
CSVP="$(cd "$(dirname "$0")/.." && pwd)/results/all_runs.csv"
[ -r "$CSVP" ] || { echo "GUARD FAIL: $CSVP not readable"; exit 1; }
python3 - "$CSVP" "$CLIP" "$EPOCHS" <<'PYEOF' || exit 1
import csv, sys
csvp, clip, epochs = sys.argv[1], sys.argv[2], sys.argv[3]
rd = list(csv.DictReader(open(csvp)))
AX = ['network', 'dataset', 'batch_size', 'base', 'meta', 'alpha0', 'gamma',
      'augment', 'beta_clip', 'hier', 'lam', 'eta_ratio', 'epochs_done']
ref = [r for r in rd if r['run'].startswith('rs-lay-1e4')]
if not ref:
    sys.exit("GUARD FAIL: no rs-lay-1e4 reference row in the CSV -- wrong CSV?")
sig = {a: ref[0][a] for a in AX}
if len({tuple(r[a] for a in AX) for r in ref}) != 1:
    sys.exit("GUARD FAIL: the rs-lay-1e4 reference rows do not share one signature")
# the axes THIS script sets, and the values it sets them to
mine = {'network': 'ResNet18', 'dataset': 'CIFAR10', 'batch_size': '100',
        'base': 'SGDm', 'meta': 'Lion', 'alpha0': '1e-3', 'gamma': '1',
        'augment': '1', 'beta_clip': clip, 'epochs_done': epochs}
bad = [(a, mine[a], sig[a]) for a in mine if mine[a] != sig[a]]
if bad:
    for a, m, s in bad:
        print(f"  axis {a}: this batch {m!r} vs reference {s!r}")
    sys.exit("GUARD FAIL: wm9 does not match the ladder's axis signature -- it would "
             "not be comparable to the cells it is meant to extend.  STOP.")
for a in ('hier', 'lam', 'eta_ratio'):
    if sig[a] not in ('', 'na'):
        sys.exit(f"GUARD FAIL: reference has {a}={sig[a]!r}; this batch sets no "
                 f"hierarchical operator, so it is not the same arm")
print("guard 3: all 13 axes match the rs-lay-1e4 reference signature read FROM THE CSV")
print("         (beta_clip=%s, alpha0=%s, gamma=%s, augment=%s, hier=%r/lam=%s)"
      % (sig['beta_clip'], sig['alpha0'], sig['gamma'], sig['augment'], sig['hier'], sig['lam']))
PYEOF

# GUARD 3b -- **THE QUESTION IS ACTUALLY OPEN.**  The operator's standing rule is
# that every job must name an open question and that a batch answered by data
# already in the CSV must not be run.  So count the MATCHED weightwise cells.
python3 - "$CSVP" "$CLIP" "$EPOCHS" "$GRID" <<'PYEOF' || exit 1
import csv, sys, collections, statistics
csvp, clip, epochs, grid = sys.argv[1], sys.argv[2], sys.argv[3], sys.argv[4].split()
rd = list(csv.DictReader(open(csvp)))
AX = ['network', 'dataset', 'batch_size', 'base', 'meta', 'alpha0', 'gamma',
      'augment', 'beta_clip', 'hier', 'lam', 'eta_ratio', 'epochs_done']
ref = [r for r in rd if r['run'].startswith('rs-lay-1e4')][0]
sig = tuple(ref[a] for a in AX)
def matched(g):
    return [r for r in rd if tuple(r[a] for a in AX) == sig
            and r['granularity'] == g
            and r['collapsed'] in ('False', 'false', '0', '') and r['plateau5']]
w = matched('weightwise')
cells = collections.Counter(r['meta_stepsize'] for r in w)
print("guard 3b: matched weightwise runs in the CSV: %d  %s"
      % (len(w), dict(cells) if cells else "{}"))
if len(w) > 4:
    sys.exit(f"GUARD FAIL: {len(w)} matched weightwise runs already exist -- this "
             f"batch may be re-running an answered question.  Re-read the census.")
# the reproduction control must have something to reproduce
if '1e-3' not in cells:
    sys.exit("GUARD FAIL: no matched weightwise ms=1e-3 run -- W0.2's reproduction "
             "control has no reference, so the ladder could not be validated")
ctrl = [float(r['plateau5']) for r in w if r['meta_stepsize'] == '1e-3']
print("          W0.2 reference: weightwise ms=1e-3 plateau5 = %s (n=%d)"
      % (", ".join("%.3f" % c for c in ctrl), len(ctrl)))
# and the OTHER rungs must really peak at 1e-4, or the grid is centred wrong
for g, want in (('layerwise', '1e-4'), ('scalar', '1e-4')):
    cel = collections.defaultdict(list)
    for r in matched(g):
        cel[r['meta_stepsize']].append(float(r['plateau5']))
    if not cel:
        sys.exit(f"GUARD FAIL: no matched {g} cells to centre the grid on")
    best = max(cel, key=lambda k: statistics.mean(cel[k]))
    if best != want:
        sys.exit(f"GUARD FAIL: {g}'s matched optimum is ms={best}, not {want} -- the "
                 f"grid in this script is centred on a number the CSV does not support")
    print("          %-10s matched optimum ms=%s  plateau5 %.3f (n=%d)  -- grid centre confirmed"
          % (g, best, statistics.mean(cel[best]), len(cel[best])))
for m in grid:
    float(m)
print("          grid %s brackets 1e-4 by a decade either side  OK" % " ".join(grid))
PYEOF

# GUARD 4 -- queue depth.  10 jobs is inside the ~20-job / 0.5%-RawUsage rule.
FS=$(sshare -U -u "$USER_NAME" -n -o FairShare 2>/dev/null | tr -d ' ' | head -1)
PEND=$(squeue -h -u "$USER_NAME" -t PENDING 2>/dev/null | wc -l | tr -d ' ')
echo "guard 4: FairShare=${FS:-unknown} (informational), pending=$PEND, adding $NJOBS"
if [ "$SUBMIT" = "1" ]; then
  [ "$((PEND + NJOBS))" -le "$PEND_CAP" ] || {
    echo "ABORT: $PEND pending + $NJOBS would exceed the $PEND_CAP cap"; exit 1; }
fi

# GUARD 5 -- the wall-clock request must fit the TIGHTEST partition in $PARTS.
python3 - "$WALL" "$PARTS" <<'PYEOF' || exit 1
import subprocess, sys
def secs(t):
    d, _, rest = t.partition("-")
    if not rest: rest, d = d, "0"
    p = [int(x) for x in rest.split(":")]
    while len(p) < 3: p.insert(0, 0)
    return int(d) * 86400 + p[0] * 3600 + p[1] * 60 + p[2]
want, parts = sys.argv[1], sys.argv[2].split(",")
out = subprocess.run(["sinfo", "-h", "-o", "%P %l"], capture_output=True, text=True).stdout
lim = {}
for ln in out.split("\n"):
    f = ln.split()
    if len(f) == 2 and f[1] not in ("infinite", "n/a"):
        lim[f[0].rstrip("*")] = secs(f[1])
tight = [(p, lim[p]) for p in parts if p in lim]
if not tight:
    sys.exit("GUARD FAIL: sinfo returned no limit for any requested partition")
name, cap = min(tight, key=lambda kv: kv[1])
if secs(want) > cap:
    sys.exit(f"GUARD FAIL: --time={want} exceeds {name}'s MaxTime "
             f"({cap // 3600}:{cap % 3600 // 60:02d}) -- sbatch would reject the WHOLE batch")
print(f"guard 5: --time={want} fits the tightest partition {name} "
      f"({cap // 3600}:{cap % 3600 // 60:02d})  OK")
PYEOF

# GUARD 6 -- THROUGHPUT HEADROOM against MEASURED 100-epoch weightwise wallclock.
python3 - "$WALL" "$CSVP" <<'PYEOF' || exit 1
import csv, sys
def secs(t):
    p = [int(x) for x in t.split(":")]
    while len(p) < 3: p.insert(0, 0)
    return p[0] * 3600 + p[1] * 60 + p[2]
wall_min = secs(sys.argv[1]) / 60.0
w = []
for r in csv.DictReader(open(sys.argv[2])):
    if r.get('granularity') == 'weightwise' and r.get('epochs_done') == '100' \
            and r.get('wallclock_min'):
        try: w.append(float(r['wallclock_min']))
        except ValueError: pass
if not w:
    sys.exit("GUARD FAIL: no completed 100-epoch weightwise wallclock to size against")
slow = max(w)
if slow > wall_min:
    sys.exit(f"GUARD FAIL: slowest 100-ep weightwise run took {slow:.0f} min but --time "
             f"is {wall_min:.0f} min -- would truncate")
print(f"guard 6: 100-ep weightwise wallclock n={len(w)}, median {sorted(w)[len(w)//2]:.0f} min, "
      f"slowest {slow:.0f} min, against a {wall_min:.0f} min wall "
      f"({wall_min / slow:.1f}x headroom on the slowest)  OK")
PYEOF

mkdir -p "$SAVE"
N=0
FAIL=0
SGDM=(--optimizer HF --alg-base SGDm --momentum-param-base 0.99 --weight-decay-base 0.1
      --alg-meta Lion --momentum-param-meta 0.99 --Lion-beta2-meta 0.9 --weight-decay-meta 0)
for MST in $GRID; do
  TAG=$(printf '%s' "$MST" | tr -d '-')
  for S in 0 1; do
    RN="wm9-w-${TAG}-s${S}"
    CMD=(sbatch --job-name="$RN" --partition="$PARTS" --gres=gpu:1 --cpus-per-task=6
      --mem=14G --time="$WALL" --nice=0
      --export="ALL,AUGMENT=1,BETA_CLIP=${CLIP}"
      "$RUNNER" "${SGDM[@]}"
      --dataset CIFAR10 --NN-name ResNet18 --batch-size 100
      --max-time 999:00:00 --gamma 1 --meta-stepsize "$MST" --alpha0 1e-3
      --num-epochs "$EPOCHS" --stepsize-groups weightwise --seed "$S"
      --save-directory "$SAVE" --run-name "$RN")
    # COUNT WHAT SLURM ACCEPTED, NOT WHAT WE TRIED (CORRECTIONS 71).
    if [ "$SUBMIT" = "1" ]; then
      if "${CMD[@]}" >/dev/null; then N=$((N+1)); else FAIL=$((FAIL+1)); fi
    else
      N=$((N+1)); printf '%s\n' "${CMD[*]}"
    fi
  done
done
echo "---- $N jobs ($( [ "$SUBMIT" = 1 ] && echo ACCEPTED BY SLURM || echo 'dry run, nothing submitted' )); $FAIL rejected ----"
[ "$N" = "$NJOBS" ] || echo "!!! expected $NJOBS jobs, built $N -- DO NOT TREAT AS SUBMITTED"
[ "$FAIL" -gt 0 ] && echo "!!! $FAIL sbatch calls FAILED -- do not treat this batch as submitted"
echo "reduce with, IN THIS ORDER:"
echo "  1. W0    epochs_done==100==requested, collapsed false, PER JOB"
echo "  2. W0.2  **REPRODUCTION CONTROL FIRST**: wm9 ms=1e-3 vs kt2_ww_a1e-3_s0"
echo "           91.308, bar +-0.50.  FAILS => the ladder is VOID, read no optimum."
echo "  3. W1    argmax over ms, n=2/cell, DECIDED only at gap > 2 SE"
echo "  4. W1b   **INTERIOR?**  argmax at a grid edge => the grid is wrong and W2"
echo "           is NOT scored.  Extend the grid; do not read an edge as a peak."
echo "  5. W2    REGISTERED: tuned weightwise INSIDE [92.2, 92.9] and best ms <= 1e-4."
echo "           CONFIRMS => the granularity ladder is FLAT across 62 -> 11.17M groups."
echo "           REFUTES  => the finest partition has a real cost tuning cannot recover."
