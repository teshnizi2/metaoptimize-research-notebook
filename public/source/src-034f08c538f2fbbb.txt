# THIS BATCH CARRIES A HARNESS CHANGE.  patches/patch_namesets.py.
# -----------------------------------------------------------------------------
# It adds ONE string form to `--stepsize-groups`:
#     sets:<group>/<group>/...   group := item[,item]*
#     item := <1-based index> | <lo>-<hi> | <parameter name>
# and nothing else.  It is ADDITIVE: two insertions, no existing line edited,
# and every pre-existing spec form fails `startswith('sets:')` and reaches the
# original body byte-unchanged.  tests/test_namesets.py proves this against the
# UNPATCHED code path on 50 specs drawn from the corpus's own `granularity`
# column, proves `sets:1-49/50-62` composes to EXACTLY what `[49,13]` composes
# to (both group name lists AND the resulting init_meta state), and proves the
# grammar is total and loud on eleven malformed specs.  Guard 4h below re-checks
# the live tree.
#
# RULE 20.  The new spec is ONE shell token of [A-Za-z0-9_.,:/-] -- no space, no
# quote, no `=`, no leading dash -- so analysis/argsline_guard.py tokenises and
# attributes it as a single value with NO change to that file, and still detects
# a repeated flag.  argsline_guard.py IS NOT EDITED; the grammar was chosen to
# fit it as it stands.  This was verified before composition, both by
# --cmdline on a real composed line and by --batch-consistency over a synthetic
# 15-file ARGS corpus, including a negative control with an injected duplicate
# --stepsize-groups (correctly reported "LAST OF 2", exit 1).
#
# -----------------------------------------------------------------------------
# THE QUESTION -- WHAT 161.7c LEFT UNANSWERABLE
# -----------------------------------------------------------------------------
# On ResNet18_c100, `class == index mod 3` at EVERY tensor index 1..60, and
# `[k,62-k]` is a contiguous prefix.  So NO prefix cut can separate a tensor's
# CLASS from its ORDINAL POSITION, and 161's 15/15 sign census is barred from
# becoming "tensor class governs the partition response".  cpr1 holds m = 2 and
# both group sizes (49 and 13) FIXED and EXCHANGES ONE TENSOR across the cut.
#
# -----------------------------------------------------------------------------

#   kL   [49,13]                             LEGACY grammar / OLD code path

#   kS   ...bn2.weight for conv2.weight      THE SWAP  (conv -> BN scale)
#   kC   ...shortcut.0.weight for conv2      THE CLASS-MATCHED CONTROL (conv -> conv)
#   SEEDS {9,10,11} -- ZERO rows anywhere in this cell carry them, so ZERO
#   duplicates.  HORIZON 100, the horizon every anchor is measured at.
#
# WHY THE BRIEFING'S 6 RUNS BECAME 15, ITEM BY ITEM.
#   +k01  the briefing itself requires a floor/saturation gate, and H-CLASS
#         PREDICTS kS lands BELOW this cell's m=1 floor.  Without an in-batch
#         anchor the truncation could not be detected, let alone reported as a
#         bound.  3 runs.
#   +kL   the batch's science rests on a harness change.  kL vs kP converts the
#         static inertness proof into a MEASURED equivalence at fixed seeds.
#         It is also a genuine in-cell replicate on a new seed triple, so it
#         doubles as R-CTRL.  3 runs.
#   +kC   WITHOUT IT `CLASS-OPERATIVE` IS NOT CLAIMABLE.  kS is the only
#         non-contiguous arm in a corpus of prefixes, so if kS alone fell away
#         four accounts would survive: the crossing tensor's CLASS, a MASS
#         THRESHOLD on it, the coarse group's TOTAL MASS, and CONTIGUITY itself.
#         kC is non-contiguous like kS and low-mass like kS (their coarse masses
#         differ by 3.30 %) but CONV-crossing like kP, so kC ~ kP kills coarse
#         mass and contiguity together.  3 runs.
#   TOTAL 15 runs at 100 epochs -- about 12 GPU-hours, against ~117 for cpk3.
#
# WHAT cpr1 STILL CANNOT DO, SAID BEFORE IT RUNS.  It cannot separate CLASS from
# a MASS THRESHOLD on the crossing tensor.  On ResNet-18 the smallest
# convolution is 131,072 parameters and the largest normalisation tensor is 512
# -- a 256x gap with no overlap -- so the two are the same predicate on this
# network (161.7c i).  THE BRIEFING'S CLAIM THAT THIS SWAP "separates class from
# the mass threshold in the same stroke" IS WRONG and is not adopted.  The
# verdict string carries the rider permanently.
#
# WHY PROBE STAYS 0, AND WHAT IT COSTS.  161.12 asked for a PROBE arm so that
# 152.12's rival (c) could finally be tested with per-tensor <h,g>.  DECLINED,

# pre-reduction shape shipped in the SAME batch as the grammar change -- two

    print("          %4d  %s" % (ln, txt))
if not (len(decl) == 1 and len(loop) == 1 and not other):

    print("!!! guard 4i: train.py mentions a scheduler; check it is not epoch-keyed:")

        print("          %4d  %s" % (ln, txt))
