#   * 46 ms=3e-4 runs sit in the canonical box with HIER=none.
#   * EXACTLY 15 of them carry a probe at all.  Those 15 are
#     `ar1-c23-s{0,1,2}` (chunk2325), `ar1-ch-s{0,1,2}` (chunk777),
#     `ar1-n1d-s{0,1,2}` (nodewise1d), `ar1-node-s{0,1,2}` and

#      gate, not a formality, and this registration does not assume its answer.
#
# WHAT IS KNOWN, AND IT IS STRONG BUT IT IS NOT THE MEASUREMENT:
#   (a) ARITHMETIC.  --weight-decay-meta 0 makes the Lion meta-update
#       beta <- beta - ms*sign(.) with sign(.) in {-1,0,+1}, so |dbeta| <= ms
#       EXACTLY per meta-step.  Over T = 50000 meta-steps from
#       beta0 = float32 log(1e-3) = -6.907755, simulated in float32:
#           ms = 1e-4  ->  beta >= -11.914545   -15 UNREACHABLE (null by
#                          construction; no arm is run there, as in cfr1)
#           ms = 3e-4  ->  beta >= -21.907576   -15 IS reachable, first
#                          attainable at meta-step 26975 = 53.95% of training,
#                          leaving AT MOST 46.05% of the run exposed to it
#           ms = 1e-3  ->  beta >= -56.888439   (cfr1's rung, 83.81% exposure)
#       and -80.0 sits 58.092424 nats BELOW the ms=3e-4 bound -- 193641
#       meta-steps that do not exist.  The released floor is MORE
#       unreachable here than at cfr1's rung (23111 steps), so the one-factor
#       instrument transfers with a wider margin, not a narrower one.
#       alpha = exp(-21.907576) = 3.06e-10 is a normal float32.
#   (b) MEASURED, at THIS ms, on the neighbouring rungs of m.  Over the 15
#       probed ms=3e-4 runs above, all 15 reach exactly -15.0000, first
#       arrival at meta-step 27005-27395 against the theoretical earliest
#       26975, i.e. the fastest coordinate descends at 98.5-99.9% of the
#       maximum possible rate, and floor occupancy runs 45.2-46.0% of records
#       against the 46.05% ceiling.  The descent is free-fall.
#   (c) MEASURED, at m = 62, on cfr1's rung.  cfr1's three RELEASED layerwise
#       runs bottom at -56.60 / -56.51 / -56.57 against a float32 travel bound
#       of -56.888439: 99.4-99.6% of maximum descent, monotone, first crossing
#       -15 at meta-step 8300-8400 against the earliest possible 8093.
#   (b) and (c) together bracket the untested corner (m = 62 AT ms = 3e-4) but
#   they do not measure it.  cfr2's clamped layerwise arm measures it, and that
#   measurement is a deliverable of this batch WHATEVER the DID does.
#
# -----------------------------------------------------------------------------
# THE DESIGN.  2 granularities x 2 boxes x 3 seeds = 12 jobs, ONE submission.
#
#   factor A  granularity   sc  = scalar     (m = 1  coordinate)
#                           lay = layerwise  (m = 62 coordinates)
#   factor B  box           C = CLAMPED  BETA_CLIP=-15:-2.3026 (campaign std)
#                           R = RELEASED BETA_CLIP=-80:-2.3026 (floor released,
#                                                               SAME ceiling)
#
#   ResNet18 / CIFAR-10 / SGDm base / Lion meta / meta-stepsize 3e-4 /
#   alpha0 1e-3 / 100 epochs / batch 100 / gamma 1 / AUGMENT=1 / HIER unset /
#   SCHED none / PROBE=100 with a per-run PROBE_DIR.  ONLY `--meta-stepsize`
#   differs from cfr1; every other flag and every environment variable is
#   byte-identical to bin/cO1_floor_release_row24.sh.
#
#   ESTIMAND, the primary and the only one:
#       G_C  = mean(lay, C) - mean(sc, C)        the clamped granularity gap
#       G_R  = mean(lay, R) - mean(sc, R)        the released granularity gap
#       DID  = G_R - G_C                         the difference in differences
#   All four cells IN ONE BATCH, so the cross-batch offset cancels outright.
#   BATCH is the unit of replication (F(62,85) = 5.47, p 6.9e-13; seed is null,
#   F(11,1976) = 0.152), so no other batch's arms are spliced in -- not `rs-`,
#   which supplies this rung's entire corpus cell and is a SINGLE FAMILY at
#   n = 5 v 5, and not `cfr1`, whose rung is a different rung.
#
#   NO blk6 ARM AT THIS RUNG.  A refusal with three reasons, all re-derived by
#   --selftest:
#     (i)  THE DOSE-RESPONSE IS NOT DEFINED HERE.  The 0% / 68.8% / 100%
#          scalar/blk6/layerwise binding ladder that a blk6 arm would turn into
#          a dose-response is CORRECTIONS 148.5's `Core set, ms=1e-3` table.
#          At ms=3e-4 blk6's binding rate is UNMEASURED -- zero of the 15
#          probed runs at this rung is blk6.  Adding blk6 here would not build
#          that dose-response; it would open a second unmeasured premise.
#          `cfr3` at ms=1e-3, already registered at CORRECTIONS 153.9, is where
#          that arm belongs.
#     (ii) THERE IS NO CORPUS ANCHOR AT THIS RUNG.  In the stratum above, blk6
#          at ms=3e-4 has n = 1 surviving run (`rs-blk6-3e4-s0`, plateau5
#          92.02).  Its two siblings are inside MASTER-TABLE row 106's
#          truncation contaminant, re-derived here over the 67 `rs-` rows:
#          scalar 0/22 truncated, layerwise 0/22, resnet18_blocks 6/13,
#          nodewise 6/10 -- REFUTED.  A blk6 arm would audit a falloff number
#          that row 106 has already refuted, against an n = 1 baseline.
#     (iii) COST AND MULTIPLICITY.  +6 jobs (+50%) and a second, uncorrected
#          estimand, spent before the two-arm instrument has been shown to have
#          a wall at this rung at all (see R4(ii): that is genuinely unknown).
#     scalar and layerwise are exactly the two arms of row 24 whose numbers
#     survive row 106's audit, and they are the two arms the +3.182000 gap is
#     made of.
#
# -----------------------------------------------------------------------------
# PROBE = 100, AND WHY THE DETECTOR IS TIGHTER HERE THAN AT cfr1's RUNG
# -----------------------------------------------------------------------------
# The manipulation check must be at the COORDINATE denominator (FINDINGS 51.1)
# and over the FULL trajectory (CORRECTIONS 149.7: terminal and sampled
# occupancy rates are LOWER BOUNDS, because coordinates bounce off a wall and
# drift back).  Neither is available from TensorBoard: HF.py emits beta scalars
# only for stepsize_type in {scalar, blockwise} and `layerwise` EMITS NONE, so
# the fine arm is unauditable without the probe.  PROBE is not optional for
# this batch, and it is set IDENTICALLY on all 12 runs so it cannot enter the
# contrast.  The launcher's guard 4g re-derives the TensorBoard fact from the
# live source rather than trusting this paragraph.
#
# PROBE is an INTERVAL (_probe_every = int(PROBE)), not a flag.  |dbeta| <= ms
# per meta-step bounds the movement over one stride by ms * PROBE, so
#     at ms = 1e-3 (cfr1)  one stride <= 0.1  nats, detector bound 0.1004
#     at ms = 3e-4 (cfr2)  one stride <= 0.03 nats, detector bound 0.0304
# and the detector
#     REACHED(wall) := min over records of beta_true_min <= wall + 0.0304
# has NO FALSE NEGATIVES -- it is EXACT for "some coordinate reached the wall
# at some meta-step", not a lower bound.  Holding PROBE at 100 therefore buys a
# 3.33x TIGHTER wall detector at EXACTLY cfr1's cost (500 records per run,
# ~2 MB, ~3 s of device-to-host syncs against a ~40-55 min run), and it keeps
# the ENV line byte-identical to cfr1 so that ms remains the only difference
# between the two batches.  Loosening PROBE to 333 to hold the tolerance at 0.1
# nats was considered and REFUSED: it would save about 2 s and 1.3 MB per run,
# throw away 350 of 500 records, and introduce a second differing factor
# between the two rungs of one audit.  The exact-equality counter n_at_lo
# (PATCH_CLIPCOUNT, tolerance 1e-6) has no FALSE POSITIVES and is reported
# beside it as the lower bound; both are printed for every run.
#
# THE OCCUPANCY YARDSTICK IS DIFFERENT AT THIS RUNG, AND IS REGISTERED NOW SO
# IT CANNOT BE READ AGAINST cfr1's.  The floor cannot be reached before
# meta-step 26975, so of the 500 records PROBE=100 writes at steps
# 0, 100, ..., 49900, AT MOST 230 (46.00%) can carry a pinned coordinate.  At
# cfr1's rung the same ceiling was 419/500 = 83.80%, and cfr1 measured
# 83.2-83.4%.  A cfr2 clamped layerwise run at lo_rate ~ 0.46 is a FULLY
# SATURATED manipulation, not a weak one.
#
# The probe fields this scorer reads, all written by PATCH_CLIP /
# PATCH_CLIPCOUNT in HF._probe and none derived here: beta_true_min,
# beta_true_max, n_at_lo, n_at_hi, n_beta.  n_beta is checked against the
# registered coordinate count (1 for scalar, 62 for layerwise) so a
# per-tensor-MEAN reading can never be mistaken for a coordinate one.
#
# -----------------------------------------------------------------------------
# THE PRE-REGISTRATION.  Gates fire IN ORDER; the first failure decides.
#
#   G0 PROVENANCE  12 runs, 4 cells x 3 seeds, 12 distinct job ids, 100/100
#      epochs, no repeated flag on any ARGS line, and every run's NAME agreeing
#      with its OWN ARGS line and its OWN ENV line.  BETA_CLIP and PROBE are
#      environment variables and cannot ride the ARGS line, so they are audited
#      from the ENV line (STANDING RULE 20's known blind spot).
#
#   R1 MANIPULATION, at the coordinate denominator, over the full trajectory.
#      (a) every RELEASED run must stay strictly clear of -80: min over records
#          of beta_true_min > -80 + 0.0304, and n_at_lo = 0 at every record.
#      (b) every run must carry >= 400 records and the registered coordinate
#          count (1 for sc, 62 for lay).
#      (c) an unreadable or missing probe fails CLOSED to
#          UNRESOLVED-MANIPULATION-UNCHECKED.
#      A released run that touches its floor means the manipulation FAILED and
#      this batch is UNRESOLVED, NOT evidence.
#
#   R2 DIVERGENCE  any run with < 100 epochs, a non-finite metric, or
#      plateau5 <= 15.00 pp (CIFAR-10 chance is 10.0 pp) is DEAD ->
#      UNRESOLVED-DIVERGED.  Registered in advance precisely so that "the
#      RELEASED ARMS FAILED TO TRAIN" can NEVER be scored as "the tolerance
#      collapsed".  COLLAPSED-BY-FREEZING is its own label: it fires when every
#      released cell's terminal beta_true_max <= -20, i.e. every coordinate's
#      stepsize is below 2.1e-9 and the arm has stopped learning -- a statement
#      about the floor AS A FLOOR, not about tolerance.
#
#   R3 NOISE  any of the four cell SDs above 3*sigma_w = 0.6451 pp ->
#      UNRESOLVED-NOISY: the registered noise floor did not transfer and the
#      bars below do not apply.
#
#   R4 PREMISE, both halves.
#      (i)  G_C >= 1.5910 pp, half the corpus's own clamped gap AT THIS RUNG
#           (layerwise 91.926400 n=5 minus scalar 88.744400 n=5 = 3.182000 pp).
#      (ii) THE WALL MUST EXIST AT THIS RUNG: at least 2 of the 3 CLAMPED
#           LAYERWISE runs must have reached the -15 floor.  Per the correction
#           above this is genuinely unknown at m = 62 / ms = 3e-4, so the
#           branch is registered with its reading spelled out in full -- see
#           PREMISE-NOWALL below.  It is NOT a formality and it is NOT an
#           excuse to re-read a null as a pass.
#
#   VERDICT on DID = G_R - G_C, at the registered bar 2*SE_DID = 0.4966 pp:
#      |DID| <= 0.4966                       ROW24-3E4-SURVIVES
#           at ms = 3e-4 releasing the floor does not move the granularity gap,
#           so the tolerance is a property of the PARTITION at the rung where
#           93% of it switches on.
#      DID <= -0.4966 and G_R >= 1.5910      ROW24-3E4-ATTENUATED
#           the wall carries PART of the gap at this rung; row 24's magnitude
#           must be restated with the released number beside it.
#      DID <= -0.4966 and G_R <  1.5910      ROW24-3E4-WALL-DRIVEN
#           the gap at the rung that carries 93% of the rise WAS the wall.
#           Row 24 must be REWRITTEN and cfr1's ms=1e-3 null re-read as the
#           top of a decade whose interior is an artefact.
#      DID >= +0.4966                        ROW24-3E4-BOX-SUPPRESSED
#           the released box GROWS the gap; row 24 understates its own effect.
#
#   PREMISE-NOWALL-3E4-CLAMP-FREE (R4(ii) fails).  Registered reading, in full,
#   so it cannot be written up either as a pass or as a wasted batch:
#      * The DID IS NOT A MEASUREMENT OF A WALL'S EFFECT and may not be
#        reported as one.  It is null BY CONSTRUCTION, exactly as at ms = 1e-4.
#      * What IS measured, and is new, is that the layerwise arm at ms = 3e-4
#        does not reach the -15 floor -- the first probe of ANY m = 62 or m = 1
#        run at this rung in the corpus.
#      * The valid deduction, and its limit: if the floor is not touched at
#        this cell then the floor cannot be generating this cell's granularity
#        gap, so the floor-artefact account of the +3.182000 pp gap is refuted
#        BY ABSENCE OF A WALL rather than by a measured null.  That deduction
#        is about THIS BATCH's cell.  Extending it to the `rs-` runs that
#        supply the corpus number requires that the two batches place beta on
#        the same trajectory, which BATCH-as-unit-of-replication does not
#        guarantee; it must be written as an inference, not a replicate.
#      * The rung is then in the same class as ms = 1e-4 and the honest move
#        for row 24 is to SCOPE the clamp threat to ms >= (the lowest rung at
#        which the floor is actually reached for the arms in question), not to
#        claim a null DID as a discharge.
#
#   DISCLOSED, PRE-SPECIFIED, NON-GATING diagnostics, reported every run:
#      * NEGATIVE CONTROL.  The census measures scalar 0/33 bound corpus-wide
#        at ms=1e-3, and cfr1's released scalar arm descended at only 8.3% of
#        the maximum rate to -11.05, never approaching -15; at ms=3e-4 the
#        scalar arm has 3.33x less travel available.  It should not move when
#        the floor is released: |mean(sc,R) - mean(sc,C)| against
#        2*SE_GAP = 0.3512 pp.  A scalar arm that moves is reported, loudly; it
#        does not void the DID, which is a difference in differences either way.
#      * THE FREE-FALL RATE AT m = 62, ms = 3e-4 -- the corner (b) and (c)
#        bracket but neither measures.  For every clamped layerwise run, the
#        first record at which beta_true_min <= -15 + 0.0304, against the
#        theoretical earliest meta-step 26975; and for every RELEASED layerwise
#        run, the terminal beta_true_min against the travel bound -21.907576.
#        Their ratio is the descent rate as a fraction of the maximum.
#      * FLOOR OCCUPANCY against THIS rung's ceiling of 46.00% of records, both
#        as the exact lower bound (n_at_lo >= 1) and as the no-false-negative
#        detector above.
#      * CEILING SCOPE.  max n_at_hi over the clamped layerwise runs, deciding
#        whether the floor was the only wall at this cell.
#
# MAY NOT CLAIM: anything about any meta-stepsize other than 3e-4, or any other
# alpha0, dataset, architecture, base/meta optimiser pair, granularity other
# than scalar and layerwise, or box other than the two run here; anything about
# the CEILING as a wall beyond the diagnostic above; any splice with `rs-`,
# `ms-`, `mx-`, `cfr1`, `tc1`, `ub9` or any other batch's arms; and any
# statement about row 24's FITTED pp/decade slope, which is a multi-rung object
# this batch does not measure.  What is measured is the GAP at ms = 3e-4 under
# two boxes.  Together with cfr1 this audits two of the decade's three rungs
# and the third (1e-4) is clamp-free by arithmetic -- that is a statement about
# THREE POINTS, still not about a fitted slope.
#
# PRIMARY IS plateau5.  The CSV `plateau` column is BANNED as primary and
# best_test is not a plateau.  TRAIN is reported alongside TEST at every arm.
#
# ON --selftest, AND THE FALSE CLAIM THAT IS NOT REPEATED HERE
# -----------------------------------------------------------------------------
# `cfr1`'s registration asserted that its --selftest would stay green after its

def _csv_rows(path=CSV):
    with open(path) as fh:
        return [r for r in csv.DictReader(fh) if (r.get("superseded") or "0") != "1"]


def _batch_of(run):
    return re.split(r"[-_]", str(run))[0]


def _in_stratum(r):
    """The canonical-box cell row 24's clamped numbers were measured in."""
    return (r["network"] == NET and r["dataset"] == DSET
            and r["base"] == BASE_ALG and r["meta"] == META_ALG
            and r["alpha0"] == ALPHA0 and r["gamma"] == GAMMA
            and r["augment"] == AUG and r["beta_clip"] == CLIP_C
            and not (r.get("hier") or "").strip()
            and r["batch_size"] == str(BATCH)
            and r["epochs_requested"] == str(EPOCHS)
            and r["epochs_done"] == str(EPOCHS)
            and r["collapsed"] == "0"
            and r["granularity"] in ("scalar", "layerwise")
            and not str(r.get("run") or "").startswith(PREFIX))


def noise_floor_from_csv(path=CSV):
    """Pooled WITHIN (family x granularity x meta-stepsize) SD of plateau5."""
    cells = collections.defaultdict(list)
    for r in _csv_rows(path):
        if not _in_stratum(r):
            continue
        try:
            cells[(_batch_of(r["run"]), r["granularity"],
                   r["meta_stepsize"])].append(float(r["plateau5"]))
        except (TypeError, ValueError):
            pass
    ss, df, nc = 0.0, 0, 0
    for v in cells.values():
        if len(v) >= 2:
            m = statistics.mean(v)
            ss += sum((x - m) ** 2 for x in v)
            df += len(v) - 1
            nc += 1
    return (math.sqrt(ss / df) if df else float("nan")), df, nc


def corpus_gap_from_csv(ms=MS, path=CSV):
    """The corpus's own clamped layerwise - scalar gap at one meta-stepsize."""
    g = collections.defaultdict(list)
    for r in _csv_rows(path):
        if _in_stratum(r) and r["meta_stepsize"] == ms:
            try:
                g[r["granularity"]].append(float(r["plateau5"]))
            except (TypeError, ValueError):
                pass
    if "layerwise" not in g or "scalar" not in g:
        return None
    lay, sc = statistics.mean(g["layerwise"]), statistics.mean(g["scalar"])
    return lay, sc, lay - sc, len(g["layerwise"]), len(g["scalar"])


def corpus_families_at(ms=MS, path=CSV):
    """{granularity: Counter(batch family)} at one rung -- how thin the cell is."""
    out = collections.defaultdict(collections.Counter)
    for r in _csv_rows(path):
        if _in_stratum(r) and r["meta_stepsize"] == ms:
            out[r["granularity"]][_batch_of(r["run"])] += 1
    return dict(out)

# =============================================================================
# the SE arithmetic.  Each contrast gets the SE of ITS OWN linear combination.
# =============================================================================
def se_of_combo(coefs, sigma=SIGMA_W, n=3):
    """SE, in PERCENTAGE POINTS, of sum_i coefs[i]*mean(cell_i), n seeds each."""
    return sigma * math.sqrt(sum(c * c for c in coefs) / float(n))


SE_ARM = se_of_combo((1,))                # one cell mean
SE_GAP = se_of_combo((1, -1))             # G_C, G_R, and the scalar control
SE_DID = se_of_combo((1, -1, -1, 1))      # DID = G_R - G_C


def power_against(delta, bar=DID_BAR, se=None):
    """Two-sided normal power of the registered rule against a true |DID|."""
    se = se if se is not None else SE_DID
    def phi(z):
        return 0.5 * (1.0 + math.erf(z / math.sqrt(2.0)))
    return phi((abs(delta) - bar) / se) + phi((-abs(delta) - bar) / se)

def _tokens(line):
    import shlex
    try:
        return shlex.split(line)
    except ValueError:
        return line.split()


def parse_args_line(line):
    """(effective_flags, repeated_flags).  argparse keeps the LAST occurrence."""
    toks = _tokens(line)
    eff, seen = {}, collections.Counter()
    i = 0
    while i < len(toks):
        t = toks[i]
        if t.startswith("--"):
            key = t[2:]
            val = "1"
            if i + 1 < len(toks) and not toks[i + 1].startswith("--"):
                val = toks[i + 1]
                i += 1
            seen[key] += 1
            eff[key] = val
        i += 1
    return eff, sorted(k for k, c in seen.items() if c > 1)


def parse_env_line(line):
    out = {}
    for tok in line.split():
        if "=" in tok:
            k, v = tok.split("=", 1)
            out[k] = v
    return out


def read_out(path):
    args = env = None
    test, train = {}, {}
    try:
        with open(path, "r", errors="replace") as fh:
            for line in fh:
                if args is None:
                    m = ARGS_RE.match(line)
                    if m:
                        args = m.group(1).strip()
                        continue
                if env is None:
                    m = ENV_RE.match(line)
                    if m:
                        env = m.group(1).strip()
                        continue
                m = EP_RE.search(line)
                if m:
                    test[int(m.group(1))] = float(m.group(2))
                m = EPTR_RE.search(line)
                if m:
                    train[int(m.group(1))] = float(m.group(2))
    except IOError:
        return None
    if args is None:
        return None
    eff, dup = parse_args_line(args)
    return {"args": eff, "dup": dup, "argsline": args,
            "env": parse_env_line(env or ""), "envline": env or "",
            "test": test, "train": train, "path": path}


def tail5(series, budget=EPOCHS, w=5):
    """PRIMARY window.  Mean of the LAST 5 epochs; train.py prints 0-indexed."""
    v = [series[e] for e in range(budget - w, budget) if e in series]
    return sum(v) / len(v) if len(v) == w else None


def norm_num(s):
    try:
        return "%g" % float(s)
    except (TypeError, ValueError):
        return None


def collect(runsdir):
    """Every cfr2 .out file, with its cell MEASURED from its own ARGS and ENV."""
    recs = []
    for p in sorted(glob.glob(os.path.join(runsdir, PREFIX + "*.out"))):
        base = os.path.basename(p)
        m = NAME_RE.match(base)
        r = read_out(p)
        if r is None:
            recs.append({"path": p, "base": base, "bad": "no ARGS line"})
            continue
        r["base"] = base
        r["run"] = base.rsplit("-", 1)[0] if m else base[:-4]
        r["job_id"] = m.group(4) if m else None
        r["name_arm"] = m.group(1) if m else None
        r["name_box"] = m.group(2) if m else None
        r["name_seed"] = int(m.group(3)) if m else None
        spec = r["args"].get("stepsize-groups")
        r["meas_arm"] = None
        for a in ARMS:
            if spec == ARM_SPEC[a]:
                r["meas_arm"] = a
        clip = r["env"].get("BETA_CLIP")
        r["meas_box"] = {CLIP_C: "C", CLIP_R: "R"}.get(clip)
        r["clip"] = clip
        try:
            r["seed"] = int(r["args"].get("seed"))
        except (TypeError, ValueError):
            r["seed"] = None
        r["p5"] = tail5(r["test"])
        r["t5"] = tail5(r["train"])
        r["n_ep"] = len(r["test"])
        recs.append(r)
    return recs

# the manipulation check, read from the runs' OWN probe.jsonl.
# COORDINATE denominator (beta_true_min/max, n_at_lo/n_at_hi over ALL beta
# coordinates), FULL trajectory (every record, not the terminal one).
# =============================================================================
PROBE_FIELDS = ("step", "beta_true_min", "beta_true_max",
                "n_at_lo", "n_at_hi", "n_beta")


def probe_summary_one(path, floor=FLOOR_C):
    """Reduce one probe.jsonl to the registered scalars.  None if unreadable.

    `first_lo_step` is the step of the FIRST record whose beta_true_min is
    within STEP_BOUND of `floor`; it is the free-fall diagnostic and is never
    a gate.
    """
    n = 0
    bmin = float("inf")
    bmax = float("-inf")
    nlo_max = 0
    nhi_max = 0
    nlo_hits = 0
    nhi_hits = 0
    nbeta = None
    last = None
    first_lo_step = None
    last_step = None
    try:
        with open(path, "r", errors="replace") as fh:
            for line in fh:
                line = line.strip()
                if not line:
                    continue
                try:
                    rec = json.loads(line)
                except ValueError:
                    continue
                try:
                    tmin = float(rec["beta_true_min"])
                    tmax = float(rec["beta_true_max"])
                except (KeyError, TypeError, ValueError):
                    continue
                if tmin != tmin or tmax != tmax:      # NaN
                    continue
                n += 1
                bmin = min(bmin, tmin)
                bmax = max(bmax, tmax)
                lo = int(rec.get("n_at_lo") or 0)
                hi = int(rec.get("n_at_hi") or 0)
                nlo_max = max(nlo_max, lo)
                nhi_max = max(nhi_max, hi)
                nlo_hits += 1 if lo >= 1 else 0
                nhi_hits += 1 if hi >= 1 else 0
                if rec.get("n_beta") is not None:
                    nbeta = int(rec["n_beta"])
                try:
                    st = int(rec.get("step"))
                except (TypeError, ValueError):
                    st = None
                if st is not None:
                    last_step = st
                    if first_lo_step is None and tmin <= floor + STEP_BOUND:
                        first_lo_step = st
                last = (tmin, tmax)
    except IOError:
        return None
    if n == 0:
        return None
    return {"n": n, "bmin": bmin, "bmax": bmax, "n_at_lo_max": nlo_max,
            "n_at_hi_max": nhi_max, "lo_rate": nlo_hits / float(n),
            "hi_rate": nhi_hits / float(n), "n_beta": nbeta,
            "last_min": last[0], "last_max": last[1],
            "first_lo_step": first_lo_step, "last_step": last_step}


def probes_from_dir(probedir):
    """{run_name: summary} over <probedir>/probe_<run>/probe.jsonl."""
    out = {}
    for d in sorted(glob.glob(os.path.join(probedir, "probe_" + PREFIX + "*"))):
        if not os.path.isdir(d):
            continue
        run = os.path.basename(d)[len("probe_"):]
        s = probe_summary_one(os.path.join(d, "probe.jsonl"))
        if s is not None:
            out[run] = s
    return out or None


def probes_from_json(path):
    try:
        with open(path) as fh:
            raw = json.load(fh)
    except (IOError, ValueError):
        return None
    out = dict((k, v) for k, v in raw.items() if str(k).startswith(PREFIX))
    return out or None


def reached(value, wall):
    """EXACT detector: |dbeta| <= ms per step bounds one stride by STEP_BOUND."""
    if wall < 0 and value <= wall + STEP_BOUND:
        return True
    return False


def reached_ceiling(value, ceil=CEIL):
    return value >= ceil - STEP_BOUND

class Report(object):
    def __init__(self):
        self.fail = 0

    def ok(self, label, cond, extra=""):
        tag = "PASS" if cond else "FAIL"
        if not cond:
            self.fail += 1
        print("  [%s] %-62s %s" % (tag, label, extra))
        return bool(cond)

    def info(self, label, extra=""):
        print("  [INFO] %-62s %s" % (label, extra))

    def note(self, s):
        print("       %s" % s)


def fmt(x, w=9, p=4):
    return ("%*.*f" % (w, p, x)) if x is not None and x == x else " " * (w - 2) + "--"

# =============================================================================
def verdict(gc, gr, wall_seeds):
    """Premise first (both halves), then the four branches on DID."""
    if gc is None or gr is None:
        return "UNRESOLVED-INCOMPLETE", "a cell mean is missing"
    if wall_seeds is not None and wall_seeds < MIN_WALL_SEEDS:
        return ("PREMISE-NOWALL-3E4-CLAMP-FREE",
                "only %d of %d CLAMPED LAYERWISE runs reached the -15 floor, "
                "below the registered %d.  THE DID IS NULL BY CONSTRUCTION AND "
                "IS NOT A MEASUREMENT OF A WALL'S EFFECT.  What IS measured, "
                "and is new -- the corpus holds ZERO probed scalar or layerwise "
                "runs at ms = %s -- is that the layerwise arm does not reach "
                "the floor at this rung.  The valid deduction is that the "
                "floor cannot be generating THIS BATCH'S %.4f pp gap; "
                "extending it to the `rs-` runs that supply the corpus's "
                "%.4f pp is an INFERENCE, not a replicate.  The honest move "
                "for row 24 is to SCOPE the clamp threat, not to bank this as "
                "a discharge"
                % (wall_seeds, len(SEEDS), MIN_WALL_SEEDS, MS, gc, CORPUS_GAP))
    if gc < PREMISE_BAR:
        return ("UNRESOLVED-PREMISE",
                "the in-batch CLAMPED granularity gap G_C = %.4f pp is below "
                "the premise bar %.4f pp (half the corpus's own %.4f pp at "
                "ms = %s); this rung's regime did not reproduce in this batch "
                "and no other batch's arms may be spliced in"
                % (gc, PREMISE_BAR, CORPUS_GAP, MS))
    did = gr - gc
    if abs(did) <= DID_BAR:
        return ("ROW24-3E4-SURVIVES",
                "DID = %+.4f pp, within the registered bar %.4f pp (2 SE_DID): "
                "at ms = %s -- the rung that already carries %.1f%% of the "
                "granularity rise across the decade -- releasing the floor "
                "does not move the gap, so the tolerance row 24 reports is a "
                "property of the PARTITION and not of the wall"
                % (did, DID_BAR, MS,
                   100.0 * (CORPUS_GAP - CORPUS_GAP_TUNED)
                   / (CORPUS_GAP_1E3 - CORPUS_GAP_TUNED)))
    if did >= DID_BAR:
        return ("ROW24-3E4-BOX-SUPPRESSED",
                "DID = %+.4f pp >= %.4f pp: the released box GROWS the gap at "
                "this rung, so the tolerance is real and the standard box was "
                "suppressing it; row 24 understates its own effect"
                % (did, DID_BAR))
    if gr >= PREMISE_BAR:
        return ("ROW24-3E4-ATTENUATED",
                "DID = %+.4f pp <= %.4f pp but the released gap G_R = %.4f pp "
                "still clears the premise bar %.4f pp: the wall carries PART "
                "of the gap at the rung where most of it switches on, and row "
                "24's MAGNITUDE must be restated with the released number "
                "beside it" % (did, -DID_BAR, gr, PREMISE_BAR))
    return ("ROW24-3E4-WALL-DRIVEN",
            "DID = %+.4f pp <= %.4f pp and the released gap G_R = %.4f pp "
            "falls below the premise bar %.4f pp: at the rung that carries "
            "most of the rise, the gap WAS the wall.  MASTER-TABLE row 24 must "
            "be REWRITTEN, and cfr1's ms=1e-3 null must be re-read as the top "
            "of a decade whose interior is an artefact"
            % (did, -DID_BAR, gr, PREMISE_BAR))


# =============================================================================
# SELFTEST -- a PRE-INGEST GATE.  See the header: the RULE 21 check below is
# conditional on the corpus state BY CONSTRUCTION and no claim is made that it
# passes after this batch lands.
# =============================================================================
def selftest():
    import numpy as _np
    R = Report()
    print("=" * 78)
    print("cO2_cfr2_score.py --selftest   (PRE-INGEST GATE)")
    print("=" * 78)

    print("\n-- RULE 21 premise (PRE-INGEST ONLY, conditional by design) ------")
    n = count_prefix_rows()
    if n == 0:
        R.ok("no cfr2- row exists in the corpus yet", True, "0 found")
    else:
        R.info("RULE 21 gate NOT APPLICABLE -- this batch has landed",
               "%d cfr2- rows in the corpus; this check is a PRE-INGEST GATE "
               "only and is NOT a failure" % n)

    print("\n-- the released floor at ms = %s, re-derived by arithmetic ----" % MS)
    b0 = float(_np.float32(_np.log(_np.float32(1e-3))))
    R.ok("beta init = float32 log(1e-3)", abs(b0 - BETA_INIT) < 5e-6, "%.6f" % b0)
    R.ok("the standard floor is %.6f nats below init" % (b0 - FLOOR_C),
         abs((b0 - FLOOR_C) - 8.092245) < 1e-4, "%.6f" % (b0 - FLOOR_C))
    R.ok("the ceiling is %.6f nats above init" % (CEIL - b0),
         abs((CEIL - b0) - 4.605155) < 1e-4, "%.6f" % (CEIL - b0))
    b = _np.float32(b0)
    ms = _np.float32(MS_NUM)
    for _ in range(META_STEPS):
        b = _np.float32(b - ms)
    R.ok("float32 worst case after %d monotone -%s steps" % (META_STEPS, MS),
         abs(float(b) - REACHABLE_MIN) < 5e-5, "%.6f" % float(b))
    R.ok("the RELEASED floor is strictly unreachable at this rung",
         FLOOR_R < REACHABLE_MIN, "%.1f < %.6f" % (FLOOR_R, REACHABLE_MIN))
    R.ok("margin REACHABLE_MIN - FLOOR_R",
         abs((REACHABLE_MIN - FLOOR_R) - FLOOR_MARGIN) < 1e-5,
         "%.6f nats = %d meta-steps that do not exist"
         % (REACHABLE_MIN - FLOOR_R, int((REACHABLE_MIN - FLOOR_R) / MS_NUM)))
    R.ok("the released floor is MORE unreachable here than at cfr1's rung",
         (REACHABLE_MIN - FLOOR_R) > (REACHABLE_MIN_1E3 - FLOOR_R),
         "%.4f nats vs %.4f nats at ms = %s"
         % (REACHABLE_MIN - FLOOR_R, REACHABLE_MIN_1E3 - FLOOR_R, MS_CFR1))
    R.ok("the CLAMPED floor IS reachable at ms = %s -- the batch has a wall "
         "to release" % MS,
         REACHABLE_MIN < FLOOR_C,
         "%.6f < %.1f, %.6f nats of travel to spare (%d meta-steps)"
         % (REACHABLE_MIN, FLOOR_C, FLOOR_HEADROOM,
            int(FLOOR_HEADROOM / MS_NUM)))
    R.ok("FLOOR_HEADROOM matches the arithmetic",
         abs((FLOOR_C - REACHABLE_MIN) - FLOOR_HEADROOM) < 1e-5,
         "%.6f" % (FLOOR_C - REACHABLE_MIN))
    R.ok("the floor is first attainable at meta-step %d" % FIRST_FLOOR_STEP,
         FIRST_FLOOR_STEP == int(math.ceil((b0 - FLOOR_C) / MS_NUM)),
         "%d of %d = %.2f%% of training; AT MOST %.2f%% of the run is exposed"
         % (FIRST_FLOOR_STEP, META_STEPS,
            100.0 * FIRST_FLOOR_STEP / META_STEPS,
            100.0 * (META_STEPS - FIRST_FLOOR_STEP) / META_STEPS))
    b4 = _np.float32(b0)
    ms4 = _np.float32(1e-4)
    for _ in range(META_STEPS):
        b4 = _np.float32(b4 - ms4)
    R.ok("at the tuned ms = %s the -15 floor is UNREACHABLE, so that rung "
         "needs no arm" % MS_TUNED,
         float(b4) > FLOOR_C and abs(float(b4) - REACHABLE_MIN_1E4) < 5e-5,
         "%.6f > %.1f by %.6f nats" % (float(b4), FLOOR_C, float(b4) - FLOOR_C))
    b3 = _np.float32(b0)
    ms3 = _np.float32(1e-3)
    for _ in range(META_STEPS):
        b3 = _np.float32(b3 - ms3)
    R.ok("cfr1's rung re-derives to the value cfr1 registered",
         abs(float(b3) - REACHABLE_MIN_1E3) < 5e-5, "%.6f" % float(b3))
    R.ok("alpha at the reachable minimum is a normal float32",
         math.exp(REACHABLE_MIN) > 1.18e-38,
         "exp(%.6f) = %.4e" % (REACHABLE_MIN, math.exp(REACHABLE_MIN)))
    R.ok("FROZEN_BETA is unreachable under the CLAMPED floor",
         FROZEN_BETA < FLOOR_C, "%.1f < %.1f" % (FROZEN_BETA, FLOOR_C))
    R.ok("FROZEN_BETA IS reachable under the RELEASED floor at this rung, so "
         "the freezing branch is live",
         REACHABLE_MIN < FROZEN_BETA,
         "%.6f < %.1f" % (REACHABLE_MIN, FROZEN_BETA))

    print("\n-- the PROBE interval makes the wall detector EXACT --------------")
    R.ok("one PROBE stride cannot move beta by more than STEP_BOUND",
         STEP_BOUND > PROBE_EVERY * MS_NUM,
         "%.4f > %.4f = ms * PROBE" % (STEP_BOUND, PROBE_EVERY * MS_NUM))
    R.ok("the detector is TIGHTER than cfr1's at the same PROBE and cost",
         STEP_BOUND < 0.1004,
         "%.4f nats vs 0.1004 at ms = %s -- a %.2fx tighter bound for the "
         "same 500 records" % (STEP_BOUND, MS_CFR1, 0.1004 / STEP_BOUND))
    R.ok("a wall touch at ANY meta-step is visible at the next record",
         reached(FLOOR_C + PROBE_EVERY * MS_NUM, FLOOR_C),
         "beta = %.4f one stride above the floor still detects"
         % (FLOOR_C + PROBE_EVERY * MS_NUM))
    R.ok("a coordinate a tenth of a nat clear of the wall does NOT detect",
         not reached(FLOOR_C + 0.1, FLOOR_C), "%.4f" % (FLOOR_C + 0.1))
    R.ok("the released floor detector fires only near -80",
         reached(FLOOR_R + 0.02, FLOOR_R) and not reached(REACHABLE_MIN, FLOOR_R),
         "reachable min %.4f is %.4f nats clear" % (REACHABLE_MIN,
                                                    REACHABLE_MIN - FLOOR_R))
    R.ok("MIN_RECORDS is below the %d records PROBE=%d writes"
         % (META_STEPS // PROBE_EVERY, PROBE_EVERY),
         MIN_RECORDS < META_STEPS // PROBE_EVERY, "%d" % MIN_RECORDS)
    R.ok("THIS RUNG'S floor-occupancy CEILING, registered so it is not read "
         "against cfr1's",
         MAX_LO_RECORDS == len([s for s in range(0, META_STEPS, PROBE_EVERY)
                                if s >= FIRST_FLOOR_STEP])
         and abs(MAX_LO_RATE - MAX_LO_RECORDS
                 / float(META_STEPS // PROBE_EVERY)) < 1e-9,
         "at most %d of %d records = %.2f%% (cfr1's ceiling was 83.80%%, and "
         "cfr1 measured 83.2-83.4%%)"
         % (MAX_LO_RECORDS, META_STEPS // PROBE_EVERY, 100.0 * MAX_LO_RATE))

    print("\n-- the noise floor, re-derived from the corpus ------------------")
    sd, df, nc = noise_floor_from_csv()
    R.ok("SIGMA_W matches the CSV", abs(sd - SIGMA_W) < 0.005,
         "%.4f pp over df %d, %d cells" % (sd, df, nc))
    R.ok("SIGMA_DF matches the CSV", df == SIGMA_DF, "%d" % df)
    R.ok("SIGMA_CELLS matches the CSV", nc == SIGMA_CELLS, "%d" % nc)
    R.note("SE(one cell mean, 3 seeds)   = sigma/sqrt(3)    = %.4f pp" % SE_ARM)
    R.note("SE(a gap, 2 cells)           = sigma*sqrt(2/3)  = %.4f pp" % SE_GAP)
    R.note("SE(the DID, 4 cells)         = sigma*sqrt(4/3)  = %.4f pp" % SE_DID)

    g = corpus_gap_from_csv(MS)

         g is not None and g[3] >= 3 and g[4] >= 3,
         "n = %s lay / %s sc" % ((g[3], g[4]) if g else ("-", "-")))
    if g:
        R.ok("CORPUS_LAY matches the CSV", abs(g[0] - CORPUS_LAY) < 0.005,
             "%.4f pp" % g[0])
        R.ok("CORPUS_SC matches the CSV", abs(g[1] - CORPUS_SC) < 0.005,
             "%.4f pp" % g[1])
        R.ok("CORPUS_GAP matches the CSV", abs(g[2] - CORPUS_GAP) < 0.005,
             "%.4f pp = %.2f SE_GAP" % (g[2], g[2] / SE_GAP))
    fam = corpus_families_at(MS)
    R.ok("THE CORPUS CELL AT THIS RUNG IS ONE BATCH FAMILY -- which is why "
         "cfr2 runs all four cells in batch",
         set(fam.get("scalar", {})) == set(fam.get("layerwise", {})) == {"rs"},
         "scalar %s, layerwise %s" % (dict(fam.get("scalar", {})),
                                      dict(fam.get("layerwise", {}))))
    g4 = corpus_gap_from_csv(MS_TUNED)
    g3 = corpus_gap_from_csv(MS_CFR1)
    R.ok("CORPUS_GAP_TUNED matches the CSV",
         g4 is not None and abs(g4[2] - CORPUS_GAP_TUNED) < 0.005,
         "%.4f pp at ms = %s" % (g4[2] if g4 else float("nan"), MS_TUNED))
    R.ok("CORPUS_GAP_1E3 matches the CSV",
         g3 is not None and abs(g3[2] - CORPUS_GAP_1E3) < 0.005,
         "%.4f pp at ms = %s" % (g3[2] if g3 else float("nan"), MS_CFR1))
    if g and g3 and g4:
        R.ok("THE HOLE: most of the ms = %s gap is already present at ms = %s"
             % (MS_CFR1, MS),
             g[2] / g3[2] > 0.9,
             "%.2f%% of the %s gap, and %.2f%% of the whole rise across the "
             "decade" % (100.0 * g[2] / g3[2], MS_CFR1,
                         100.0 * (g[2] - g4[2]) / (g3[2] - g4[2])))
        R.ok("this rung is well above the tuned rung, so there is an effect "
             "to audit", g[2] > 4 * g4[2],
             "%.4f pp vs %.4f pp at the optimum" % (g[2], g4[2]))

    print("\n-- power of the registered rule, at THIS rung's noise floor -----")
    stake = CORPUS_GAP - CORPUS_GAP_TUNED
    for lab, d in (("the wall carries the WHOLE %s gap" % MS, CORPUS_GAP),

                   ("the wall carries 25%", 0.25 * CORPUS_GAP),

               % (d, lab, power_against(d)))
    d80 = DID_BAR + 0.8416 * SE_DID
    R.note("80%% power against |DID| >= %.4f pp = %.2f%% of the corpus gap"

         power_against(stake) > 0.999,
         "%.4f pp stake vs %.4f pp bar, power %.4f"
         % (stake, DID_BAR, power_against(stake)))

    print("\n-- the blk6 REFUSAL at this rung, re-derived --------------------")
    nb = blk6_at_rung(MS)
    R.ok("blk6 has no usable corpus anchor at ms = %s" % MS, nb <= 2,
         "n = %d complete blk6 run(s) in this cell" % nb)
    tr = rs_truncation_from_csv()
    R.ok("scalar is 0/22 truncated in the rs- surface",
         tr.get("scalar") == (0, 22), str(tr.get("scalar")))
    R.ok("layerwise is 0/22 truncated in the rs- surface",
         tr.get("layerwise") == (0, 22), str(tr.get("layerwise")))
    R.ok("resnet18_blocks IS truncation-contaminated (MASTER-TABLE row 106)",
         tr.get("resnet18_blocks", (0, 0))[0] > 0,
         "%s -- row 24's blk6 falloff rests on this"
         % str(tr.get("resnet18_blocks")))
    R.ok("nodewise IS truncation-contaminated",
         tr.get("nodewise", (0, 0))[0] > 0, str(tr.get("nodewise")))

    print("\n-- every bar, quoted in SE units --------------------------------")
    R.ok("PREMISE_BAR is half the corpus's own clamped gap at this rung",
         abs(PREMISE_BAR - CORPUS_GAP / 2.0) < 0.005,
         "%.4f pp = %.2f SE_GAP" % (PREMISE_BAR, PREMISE_BAR / SE_GAP))
    R.ok("DID_BAR is 2 SE of the difference in differences",
         abs(DID_BAR - 2 * SE_DID) < 0.005,
         "%.4f pp = %.2f SE_DID" % (DID_BAR, DID_BAR / SE_DID))
    R.ok("CONTROL_BAR is 2 SE of a two-cell difference",
         abs(CONTROL_BAR - 2 * SE_GAP) < 0.005,
         "%.4f pp = %.2f SE_GAP" % (CONTROL_BAR, CONTROL_BAR / SE_GAP))
    R.ok("NOISY_BAR is 3 sigma_w", abs(NOISY_BAR - 3 * SIGMA_W) < 0.005,
         "%.4f pp" % NOISY_BAR)
    R.ok("DID_BAR is far below the effect at stake at this rung",
         DID_BAR < CORPUS_GAP - CORPUS_GAP_TUNED,
         "%.4f pp vs the %.4f pp of gap above the tuned rung"
         % (DID_BAR, CORPUS_GAP - CORPUS_GAP_TUNED))
    R.ok("DEAD_BAR is above CIFAR-10 chance and far below this cell",
         10.0 < DEAD_BAR < CORPUS_SC,
         "%.2f pp (chance 10.00, the clamped scalar arm sits at %.2f)"
         % (DEAD_BAR, CORPUS_SC))

    print("\n-- the design ---------------------------------------------------")
    R.ok("2 granularities x 2 boxes x 3 seeds", N_RUNS == 12, "%d runs" % N_RUNS)
    R.ok("the two boxes share a ceiling and differ only in the floor",
         CLIP_C.split(":")[1] == CLIP_R.split(":")[1]
         and CLIP_C.split(":")[0] != CLIP_R.split(":")[0],
         "%s vs %s" % (CLIP_C, CLIP_R))
    R.ok("the registered coordinate counts",
         ARM_COORDS["sc"] == 1 and ARM_COORDS["lay"] == N_TENSORS,
         "scalar %d, layerwise %d" % (ARM_COORDS["sc"], ARM_COORDS["lay"]))
    try:
        sh = open(BATCH_SH).read()
    except IOError:
        sh = ""
    R.ok("the launcher script is on disk", bool(sh), BATCH_SH)
    if sh:
        for lit in ('CLIP_C="%s"' % CLIP_C, 'CLIP_R="%s"' % CLIP_R,
                    'ARMS="sc lay"', 'BOXES="C R"', 'SEEDS="0 1 2"',
                    "PROBE=$PROBE_EVERY", "PROBE_EVERY=%d" % PROBE_EVERY,
                    "MST=%s" % MS, "ALPHA0=%s" % ALPHA0,
                    "EPOCHS=%d" % EPOCHS, "BATCH=%d" % BATCH,
                    "GAMMA=%s" % GAMMA, "AUG=%s" % AUG,
                    "DSET=%s" % DSET, "NET=%s" % NET,
                    "NTENS=%d" % N_TENSORS, "G_SC=scalar", "G_LAY=layerwise"):
            R.ok("launcher contains  %s" % lit, lit in sh)
        R.ok("the launcher names THIS scorer", os.path.basename(__file__) in sh)
        R.ok("the launcher names ONLY this account's workspace",
             "/data1" not in sh and "/cluster/account_b/metaopt" in sh)
        # Prose in the header legitimately NAMES other batches (cfr1, cts3,
        # ar1, rs-).  What must be true is that no ACTIVE shell line targets
        # any prefix but this batch's, so the test strips comment lines first.
        _body = "\n".join(ln for ln in sh.splitlines()
                          if not ln.lstrip().startswith("#"))
        _pref = set(re.findall(r"\b[a-z]{1,6}\d{1,3}-", _body))
        _pref -= {"a100-", "l4-", "beta2-"}   # partition names and a flag name
        R.ok("no ACTIVE line targets any batch prefix but cfr2-",
             _pref == {"cfr2-"}, "active-body batch prefixes: %s"
             % (sorted(_pref) or "none"))
        R.ok("the launcher declares the two box levels and nothing else",
             sh.count("BETA_CLIP=$CLIP") == 1)
        R.ok("the launcher runs ONLY ms = %s" % MS,
             sh.count("MST=") == 1 and ("MST=%s" % MS) in sh)

    print("\n-- argparse last-wins, on a synthetic line ----------------------")
    eff, dup = parse_args_line("--alg-meta RMSProp --seed 0 --alg-meta Lion")
    R.ok("last occurrence wins", eff["alg-meta"] == "Lion", eff["alg-meta"])
    R.ok("the repeat is reported", dup == ["alg-meta"], str(dup))

    print("\n-- the probe reducer, on a synthetic trace ----------------------")
    import tempfile
    fd, tmp = tempfile.mkstemp(suffix=".jsonl")
    with os.fdopen(fd, "w") as fh:
        fh.write(json.dumps({"step": 0, "beta_true_min": -6.9,
                             "beta_true_max": -6.9, "n_at_lo": 0,
                             "n_at_hi": 0, "n_beta": 62}) + "\n")
        fh.write(json.dumps({"step": 27000, "beta_true_min": -15.0,
                             "beta_true_max": -3.0, "n_at_lo": 7,
                             "n_at_hi": 0, "n_beta": 62}) + "\n")
        fh.write(json.dumps({"step": 27100, "beta_true_min": -12.0,
                             "beta_true_max": -2.3026, "n_at_lo": 0,
                             "n_at_hi": 1, "n_beta": 62}) + "\n")
    s = probe_summary_one(tmp)
    os.unlink(tmp)
    R.ok("the reducer takes the MIN over the whole trajectory",
         s is not None and abs(s["bmin"] + 15.0) < 1e-9, fmt(s["bmin"]))
    R.ok("it takes the MAX over the whole trajectory",
         abs(s["bmax"] + 2.3026) < 1e-9, fmt(s["bmax"]))
    R.ok("a wall touch at an interior record is NOT lost to the terminal one",
         s["last_min"] == -12.0 and s["bmin"] == -15.0,
         "terminal %.4f, trajectory %.4f -- CORRECTIONS 149.7"
         % (s["last_min"], s["bmin"]))
    R.ok("the exact per-coordinate counter is carried",
         s["n_at_lo_max"] == 7 and s["n_at_hi_max"] == 1,
         "n_at_lo %d, n_at_hi %d" % (s["n_at_lo_max"], s["n_at_hi_max"]))
    R.ok("occupancy is a RATE over records, not a terminal flag",
         abs(s["lo_rate"] - 1 / 3.0) < 1e-9, "%.4f" % s["lo_rate"])
    R.ok("the coordinate count is read from the probe, not assumed",
         s["n_beta"] == 62, "%d" % s["n_beta"])
    R.ok("the free-fall diagnostic records the FIRST arrival step",
         s["first_lo_step"] == 27000, str(s["first_lo_step"]))

    print("\n-- the verdict machine, on synthetic cells ----------------------")
    def _v(gc, gr, w=3):
        return verdict(gc, gr, w)[0]
    R.ok("an unmoved gap scores ROW24-3E4-SURVIVES",
         _v(3.18, 3.12) == "ROW24-3E4-SURVIVES")
    R.ok("a gap that vanishes when the floor is released scores WALL-DRIVEN",

         _v(1.00, 0.00) != "ROW24-3E4-WALL-DRIVEN")
    R.ok("no wall in the clamped fine arm scores PREMISE-NOWALL-3E4-CLAMP-FREE",
         _v(3.18, 3.12, 1) == "PREMISE-NOWALL-3E4-CLAMP-FREE")
    R.ok("the no-wall gate fires BEFORE the survives branch",
         _v(3.18, 3.12, 0) != "ROW24-3E4-SURVIVES")
    R.ok("the no-wall gate fires BEFORE the wall-driven branch too",

                                           R.fail))

    print("on the corpus state by construction; no claim is made beyond that.")
    print("=" * 78)
    return 0 if R.fail == 0 else 1


# =============================================================================
# SCORE
# =============================================================================
def score(runsdir, probedir, probejson):
    R = Report()
    print("=" * 78)
    print("cfr2 -- RELEASE THE FLOOR AT ms = %s, THE RUNG cfr1 LEFT OPEN." % MS)
    print("        registered scorer, run unedited (RULES 16 and 21).")
    print("  runs    %s" % runsdir)
    print("  probes  %s" % (probejson or probedir))
    print("=" * 78)

    recs = collect(runsdir)
    print("\n-- G0 PROVENANCE ------------------------------------------------")
    R.ok("%d cfr2 .out files" % N_RUNS, len(recs) == N_RUNS, "%d found" % len(recs))
    bad = [r for r in recs if r.get("bad")]
    R.ok("every .out has an ARGS line", not bad,
         ", ".join(r["base"] for r in bad) if bad else "")
    good = [r for r in recs if not r.get("bad")]
    dups = [r["base"] for r in good if r["dup"]]
    R.ok("no repeated flag on any ARGS line (RULE 20)", not dups, ", ".join(dups))
    jids = set(r["job_id"] for r in good if r["job_id"])
    R.ok("%d distinct job ids" % N_RUNS, len(jids) == N_RUNS, "%d" % len(jids))
    mism = [r["base"] for r in good
            if r["meas_arm"] != r["name_arm"] or r["meas_box"] != r["name_box"]
            or r["seed"] != r["name_seed"]]
    R.ok("run NAME agrees with its own ARGS and ENV", not mism, ", ".join(mism))
    wrongcfg = []
    for r in good:
        a = r["args"]
        for k, want in (("dataset", DSET), ("NN-name", NET),
                        ("alg-base", BASE_ALG), ("alg-meta", META_ALG),
                        ("gamma", GAMMA)):
            if a.get(k) != want:
                wrongcfg.append("%s %s=%s" % (r["base"], k, a.get(k)))
        for k, want in (("meta-stepsize", MS), ("alpha0", ALPHA0),
                        ("num-epochs", str(EPOCHS)), ("batch-size", str(BATCH)),
                        ("weight-decay-meta", "0")):
            if norm_num(a.get(k)) != norm_num(want):
                wrongcfg.append("%s %s=%s" % (r["base"], k, a.get(k)))
        if r["env"].get("AUGMENT") != AUG:
            wrongcfg.append("%s AUGMENT=%s" % (r["base"], r["env"].get("AUGMENT")))
        if r["env"].get("PROBE") != str(PROBE_EVERY):
            wrongcfg.append("%s PROBE=%s" % (r["base"], r["env"].get("PROBE")))
        if (r["env"].get("HIER") or "none") != "none":
            wrongcfg.append("%s HIER=%s" % (r["base"], r["env"].get("HIER")))
        if (r["env"].get("SCHED") or "none") != "none":
            wrongcfg.append("%s SCHED=%s" % (r["base"], r["env"].get("SCHED")))
    R.ok("every run's own ARGS/ENV matches the registered cell", not wrongcfg,
         "; ".join(wrongcfg[:4]))
    got = collections.Counter((r["meas_arm"], r["meas_box"]) for r in good)
    R.ok("all four cells have 3 seeds",
         all(got.get(c) == len(SEEDS) for c in CELLS), str(dict(got)))
    if R.fail:
        print("\nVOID -- G0 failed.  No number below may be reported.")
        return 2

    print("\n-- R1 MANIPULATION CHECK ----------------------------------------")
    print("       coordinate denominator, FULL trajectory, PROBE=%d, detector"
          % PROBE_EVERY)
    print("       bound %.4f nats = ms * PROBE + slack.  THIS RUNG'S occupancy"
          % STEP_BOUND)
    print("       ceiling is %.2f%% of records (floor unreachable before "
          "meta-step %d)." % (100.0 * MAX_LO_RATE, FIRST_FLOOR_STEP))
    pr = probes_from_json(probejson) if probejson else probes_from_dir(probedir)
    if pr is None:
        print("  [FAIL] no probe trace could be read from %s"
              % (probejson or probedir))
        print("\nUNRESOLVED-MANIPULATION-UNCHECKED -- the scorer fails closed.")
        return 3
    R.ok("a probe trace for every run", len(pr) >= N_RUNS
         or all(r["run"] in pr for r in good), "%d traces" % len(pr))
    manip_fail, frozen = [], []
    wall_lay_C = 0
    ceil_lay_C = 0
    arrivals = []
    rel_lay_min = []
    print("       %-18s %-3s %-4s %9s %9s %7s %7s %7s %6s"
          % ("run", "box", "arm", "min beta", "max beta", "n_lo", "n_hi",
             "lo_rate", "recs"))
    for r in sorted(good, key=lambda x: (x["meas_box"], x["meas_arm"], x["seed"])):
        s = pr.get(r["run"])
        if not s:
            manip_fail.append("%s: no probe" % r["run"])
            continue
        print("       %-18s %-3s %-4s %9.4f %9.4f %7d %7d %7.4f %6d"
              % (r["run"], r["meas_box"], r["meas_arm"], s["bmin"], s["bmax"],
                 s["n_at_lo_max"], s["n_at_hi_max"], s["lo_rate"], s["n"]))
        if s["n"] < MIN_RECORDS:
            manip_fail.append("%s: only %d probe records" % (r["run"], s["n"]))
        want_coords = ARM_COORDS[r["meas_arm"]]
        if s["n_beta"] is not None and s["n_beta"] != want_coords:
            manip_fail.append("%s: n_beta = %s, registered %d -- the reading is "
                              "not at the coordinate denominator"
                              % (r["run"], s["n_beta"], want_coords))
        fl = floor_of(r["meas_box"])
        if r["meas_box"] == "R":
            if reached(s["bmin"], fl):
                manip_fail.append("%s: beta reached %.4f, within %.4f of the "
                                  "RELEASED floor %.1f"
                                  % (r["run"], s["bmin"], STEP_BOUND, fl))
            if s["n_at_lo_max"] > 0:
                manip_fail.append("%s: n_at_lo = %d at the released floor"
                                  % (r["run"], s["n_at_lo_max"]))
            if s["last_max"] <= FROZEN_BETA:
                frozen.append(r["run"])
            if r["meas_arm"] == "lay":
                rel_lay_min.append((r["run"], s["bmin"]))
        else:
            if r["meas_arm"] == "lay":
                if reached(s["bmin"], fl):
                    wall_lay_C += 1
                    arrivals.append((r["run"], s.get("first_lo_step"),
                                     s["lo_rate"], s["n_at_lo_max"]))
                if s["n_at_hi_max"] > 0:
                    ceil_lay_C += 1
    R.ok("no RELEASED run came within %.4f nats of -80" % STEP_BOUND,
         not manip_fail, "; ".join(manip_fail[:3]))
    if manip_fail:
        print("\nUNRESOLVED-MANIPULATION -- the manipulation did not happen as "
              "registered.\nThis batch is NOT evidence about row 24, and no "
              "verdict may be reported.")
        return 3

    print("\n-- R2 TRAINING FAILURE ------------------------------------------")
    dead = []
    for r in good:
        if r["n_ep"] < EPOCHS:
            dead.append("%s: %d/%d epochs" % (r["base"], r["n_ep"], EPOCHS))
        elif r["p5"] is None or r["p5"] != r["p5"]:
            dead.append("%s: no plateau5" % r["base"])
        elif r["p5"] <= DEAD_BAR:
            dead.append("%s: plateau5 %.4f <= %.2f" % (r["base"], r["p5"], DEAD_BAR))
    R.ok("no run failed to train", not dead, "; ".join(dead[:3]))
    if dead:
        print("\nUNRESOLVED-DIVERGED -- at least one run did not train.  This is "
              "a REGISTERED\noutcome and is NOT scored as 'the tolerance "
              "collapsed'.")
        return 4
    if frozen:
        print("       FROZEN (terminal beta_true_max <= %.1f, every coordinate "
              "below alpha = %.1e): %s"
              % (FROZEN_BETA, math.exp(FROZEN_BETA), ", ".join(sorted(frozen))))

    cell = collections.defaultdict(list)
    tcell = collections.defaultdict(list)
    for r in good:
        cell[(r["meas_arm"], r["meas_box"])].append(r["p5"])
        if r["t5"] is not None:
            tcell[(r["meas_arm"], r["meas_box"])].append(r["t5"])

    print("\n-- THE ARMS (plateau5 PRIMARY; train5 reported alongside) --------")
    print("       %-4s %-10s %-9s %10s %8s %10s %8s"
          % ("arm", "spec", "box", "plateau5", "sd", "train5", "sd"))
    for c in CELLS:
        v, t = cell[c], tcell[c]
        print("       %-4s %-10s %-9s %10.4f %8.4f %10s %8s"
              % (c[0], ARM_SPEC[c[0]], "CLAMPED" if c[1] == "C" else "RELEASED",
                 statistics.mean(v), statistics.stdev(v) if len(v) > 1 else 0.0,
                 "%10.4f" % statistics.mean(t) if t else "        --",
                 "%8.4f" % (statistics.stdev(t) if len(t) > 1 else 0.0)
                 if t else "      --"))

    print("\n-- R3 NOISE BLOW-UP ---------------------------------------------")
    noisy = ["%s-%s sd %.4f" % (c[0], c[1], statistics.stdev(cell[c]))
             for c in CELLS if statistics.stdev(cell[c]) > NOISY_BAR]
    R.ok("no cell's SD exceeds 3 sigma_w = %.4f pp" % NOISY_BAR, not noisy,
         "; ".join(noisy))
    if noisy:
        print("\nUNRESOLVED-NOISY -- the registered noise floor does not "
              "transfer to this batch,\nso the bars do not apply.")
        return 5

    gc = statistics.mean(cell[("lay", "C")]) - statistics.mean(cell[("sc", "C")])
    gr = statistics.mean(cell[("lay", "R")]) - statistics.mean(cell[("sc", "R")])
    did = gr - gc
    tgc = (statistics.mean(tcell[("lay", "C")]) - statistics.mean(tcell[("sc", "C")])
           if tcell[("lay", "C")] and tcell[("sc", "C")] else None)
    tgr = (statistics.mean(tcell[("lay", "R")]) - statistics.mean(tcell[("sc", "R")])
           if tcell[("lay", "R")] and tcell[("sc", "R")] else None)
    ctl = statistics.mean(cell[("sc", "R")]) - statistics.mean(cell[("sc", "C")])
    lmv = statistics.mean(cell[("lay", "R")]) - statistics.mean(cell[("lay", "C")])

    print("\n-- THE CONTRASTS ------------------------------------------------")
    print("       G_C  (lay - sc, CLAMPED )   %9.4f pp  %7.2f SE_GAP  train %s"
          % (gc, gc / SE_GAP, fmt(tgc)))
    print("       G_R  (lay - sc, RELEASED)   %9.4f pp  %7.2f SE_GAP  train %s"
          % (gr, gr / SE_GAP, fmt(tgr)))
    print("       DID  (G_R - G_C)            %9.4f pp  %7.2f SE_DID"
          % (did, did / SE_DID))
    print("       95%% CI on DID              [%+.4f, %+.4f] pp"
          % (did - 1.96 * SE_DID, did + 1.96 * SE_DID))
    print("       corpus clamped gap, ms %-5s %9.4f pp  (DESCRIPTIVE, one "
          "family `rs-`, n=%d v %d, never spliced)"
          % (MS, CORPUS_GAP, 5, 5))

    print("\n-- DISCLOSED DIAGNOSTICS (pre-specified, non-gating) -------------")
    print("       NEGATIVE CONTROL  scalar R - scalar C  %+9.4f pp   bar "
          "+/-%.4f  %s" % (ctl, CONTROL_BAR,
                           "MOVED" if abs(ctl) > CONTROL_BAR else "unmoved"))
    print("       layerwise R - layerwise C              %+9.4f pp" % lmv)
    print("       CLAMPED layerwise runs that reached the -15 floor: %d of %d"
          % (wall_lay_C, len(SEEDS)))
    print("\n       FREE-FALL AT m = %d, ms = %s -- the corner the corpus has "
          "never probed:" % (N_TENSORS, MS))
    if arrivals:
        for run, st, rate, nlo in arrivals:
            if st is None:
                print("         %-18s arrival step unavailable; lo_rate %.4f"
                      % (run, rate))
                continue
            print("         %-18s first at -15 on meta-step %6d (earliest "
                  "possible %d, ratio %.4f);\n           occupancy %.4f of "
                  "records against this rung's ceiling %.4f; up to %d of %d "
                  "coordinates pinned"
                  % (run, st, FIRST_FLOOR_STEP,
                     FIRST_FLOOR_STEP / float(st) if st else float("nan"),
                     rate, MAX_LO_RATE, nlo, N_TENSORS))
    else:
        print("         no CLAMPED layerwise run reached the floor -- see the "
              "verdict below")
    for run, bmin in rel_lay_min:
        print("         %-18s RELEASED terminal-trajectory min beta %9.4f "
              "against the travel bound %.6f (%.2f%% of maximum descent)"
              % (run, bmin, REACHABLE_MIN,
                 100.0 * (bmin - BETA_INIT) / (REACHABLE_MIN - BETA_INIT)))
    if ceil_lay_C == 0:
        print("\n       CEILING SCOPE: no CLAMPED layerwise run put a coordinate "
              "on the -2.3026\n         ceiling at any record, so the FLOOR is "
              "the only wall at this cell and\n         a one-factor floor "
              "release is a COMPLETE box audit here.")
    else:
        print("\n       CEILING SCOPE: %d of %d CLAMPED layerwise runs reached "
              "the CEILING.  The\n         ceiling is held in both boxes, so "
              "this verdict is SCOPED TO THE FLOOR;\n         the ceiling "
              "remains an untested wall and is the next experiment."
              % (ceil_lay_C, len(SEEDS)))

    print("\n-- R4 PREMISE, THEN THE VERDICT ---------------------------------")
    v, why = verdict(gc, gr, wall_lay_C)
    if v == "ROW24-3E4-WALL-DRIVEN" and len(frozen) >= len(SEEDS):
        v = "COLLAPSED-BY-FREEZING"
        why += ("; and at least one released CELL is FROZEN, so the gap moved "
                "because releasing the floor drove every coordinate's stepsize "
                "to zero -- a statement about the floor AS A FLOOR, not about "
                "tolerance, and it must be written that way")
    print("       VERDICT  %s" % v)
    print("       %s" % why)
    print("\n       OUT OF SCOPE by registration: any meta-stepsize other than "
          "%s, and any\n       other alpha0, dataset, architecture, optimiser "
          "pair, granularity or box;\n       the CEILING as a wall beyond the "
          "diagnostic above; any splice with rs-,\n       ms-, mx-, cfr1, tc1, "
          "ub9 or any other batch; and row 24's FITTED pp/decade\n       slope, "
          "which is a multi-rung object this batch does not measure." % MS)
    print("=" * 78)
    return 0


def dump_probe(probedir, out):
    pr = probes_from_dir(probedir)
    if pr is None:
        print("could not read any probe under %s" % probedir)
        return 1
    with open(out, "w") as fh:
        json.dump(pr, fh, indent=1, sort_keys=True)
    print("wrote %d probe summaries to %s" % (len(pr), out))
    return 0

    ap = argparse.ArgumentParser()
    ap.add_argument("--runs", default="/cluster/account_b/metaopt/runs")
    ap.add_argument("--probes", default="/cluster/account_b/metaopt/runs/cfr2")
    ap.add_argument("--probe-json", default=None,
                    help="read probe summaries from a JSON written by --dump-probe")
    ap.add_argument("--dump-probe", default=None,
                    help="write the probe summaries to this JSON and exit")
    ap.add_argument("--selftest", action="store_true")
    a = ap.parse_args()
    if a.selftest:
        return selftest()
    if a.dump_probe:
        return dump_probe(a.probes, a.dump_probe)
    return score(a.runs, a.probes, a.probe_json)
