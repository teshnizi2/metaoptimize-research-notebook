#!/bin/bash
# =============================================================================
# c97_permnode_replication.sh -- `rp1`, THE PERMNODE REPLICATION AND THE
# TWO-WAY (PERMUTATION-DRAW x RUN-SEED) VARIANCE DECOMPOSITION OF THE
# ALIGNMENT NULL.  Runs on cluster_a ONLY (needs PATCH_PERMNODE).
# 24 jobs: nodewise x 6 seeds, plus permnode{101,202,303} x the same 6 seeds.
# ms=1e-4, 100 ep, box -15:-2.3026, probe ON -- the `cc1`/`pp1` configuration
# unchanged in every axis.
#
# **NO PATCH IS NEEDED.**  `permnode<S>` already takes an EXPLICIT permutation
# seed S: HF.py's PATCH_PERMNODE matches `^permnode(\d+)$`, stores
# `self.perm_seed = S`, and builds each tensor's permutation from
# `torch.Generator().manual_seed(S * 1000003 + tensor_index)`.  Nothing in that
# path reads the run seed.  Guard 1d and guard 4 assert all of it on the LIVE
# tree before a job is composed.
#
# WHY THIS BATCH EXISTS
#   `pp1`'s P2 is the campaign's SECOND HEADLINE -- "alignment is refuted as the
#   carrier": permuting WHICH weights share a group, at fixed group COUNT and
#   fixed per-tensor size MULTISET, moved plateau5 by A = -0.009 +- 0.157 pp.
#   THREE THINGS ARE WRONG WITH THAT NUMBER AND ALL THREE ARE FIXED HERE.
#
#   (1) **IT IS SEED-CONFOUNDED.**  `bin/c77_permuted_partition.sh`'s arm loop
#       passed `permnode${S}` where S = THE RUN SEED.  pp1's three permnode runs
#       are therefore three different permutations AND three different inits at
#       once; pp1's own header says the batch "CANNOT separate the two".
#       **THIS BATCH DECOUPLES THEM.  THE PERMUTATION SEED IS DECOUPLED FROM THE
#       RUN SEED:** three FIXED draws (101, 202, 303) fully crossed with six
#       fresh run seeds (6..11), so no run's permutation is a function of its
#       init and the 3x6 block is BALANCED.
#   (2) **IT IS n=3.**  se 0.157, 95% CI [-0.317, +0.299] -- roughly [-55%, +51%]
#       of the D it is meant to decompose, and an MDE of 0.440 pp = 76% of D.
#   (3) **THE REGISTRATION ITSELF WAS DEFECTIVE.**  pp1's NULL band half-width
#       is 0.15 pp while pp1's REALISED se was 0.157 pp: **the pre-registered
#       band was NARROWER than the realised se**, so landing inside it could
#       never have separated a true zero from an effect the size of the whole
#       band.  T1b below repairs that with an explicit equivalence rule and
#       PRINTS THE DEFECT EITHER WAY, for rp1 and for pp1.
#
#   Nothing else changes: same box, same ms, same base/meta, same epochs, same
#   architecture, same dataset, same probe, same runner.  `rp1` is pp1's
#   alignment leg re-measured with the confound removed and the n raised, plus
#   the decomposition pp1 was structurally unable to do.
#
# THE ARMS.  m = 14,420 on EVERY arm; there is no chunk arm in this batch.
#     node  nodewise      groups = output channels;  sizes HETEROGENEOUS
#     p101  permnode101   nodewise's group COUNT and per-tensor size MULTISET
#     p202  permnode202   EXACTLY; only WHICH weights share a group is
#     p303  permnode303   randomised, WITHIN each tensor, from an explicit seed
#   run seeds 6,7,8,9,10,11 on all four arms -> 6 + 3*6 = 24 runs, ONE batch.
#
# THE PRE-REGISTERED GATES.  Nothing below may be edited after the data lands.
# The scorer `analysis/c97_rp1_score.py` was written, selftested and placed on
# disk BEFORE this script composed a single job (STANDING RULE 21), and its
# selftest asserts every constant below against THIS FILE'S OWN TEXT.
#
#   V0    VALIDITY.  n_records == 10000; beta moved; epochs_done == requested
#         == 100.
#   V0.2  n_beta EXACT 14420 on EVERY record of EVERY arm.  Guard 4 MEASURES it
#         from the ALLOCATED beta on the real built network for nodewise and for
#         all three draws, and ALSO asserts, per draw, that the per-tensor
#         group-size multiset equals nodewise's, that the draw is a true
#         permutation of each tensor's flat indices, that it is not the
#         identity, that the three draws differ from EACH OTHER, and that none
#         of them coincides with pp1's draws 0/1/2.  Nothing is inherited from a
#         comment.
#   V0.3  THE INSTRUMENT FIRED.  neg_counts.json, n_tot == n_beta, npy shape
#         read from its HEADER == (n_tot,).  Header, never file size.
#   V0.4  BOX-FREE at BOTH guards, the published rec_-based 5% gate, UNCHANGED.
#         36 arms at this exact ms and box read rec_lo == rec_hi == 0.0000
#         EXACTLY, so a bind here would be NEW.  **A BIND DOES NOT VOID T1** --
#         T1 is an accuracy contrast -- but it withdraws comparability with
#         pp1's P2 and the scorer then prefixes T1's verdict BOX-BOUND.
#         **NO ARM IS EVER DROPPED POST HOC**, for a bind or for anything else.
#
#   T1    **THE PRIMARY.  THE ALIGNMENT LEG AT n=6, PAIRED WITHIN RUN SEED.**
#         For each run seed s: pbar_s = mean over the three draws of
#         plateau5(permnode); d_s = pbar_s - plateau5(nodewise at s).
#         A = mean_s d_s over the six seeds, se = sd(d_s)/sqrt(6), t on 5 df.
#         **THE BANDS ARE pp1's P2 BANDS, TRANSCRIBED UNCHANGED**, so the two
#         readings sit on one scale:
#           A >  +0.30      -> **ALIGNMENT HURTS.**  Grouping by output channel
#                is WORSE than grouping the same number of same-sized arbitrary
#                subsets of the same layer.
#           (+0.15, +0.30] -> **UNDECIDED**, registered in advance.
#           [-0.15, +0.15] -> **NULL.**  Alignment is not the carrier.
#           [-0.30, -0.15) -> **UNDECIDED**, registered in advance.
#           A <= -0.30      -> **ALIGNMENT HELPS.**  Channel structure is a
#                genuine benefit.
#         SYMMETRIC because no prior favours either sign.  T1 REQUIRES THE
#         COMPLETE 24; on a short batch the scorer prints what it has and
#         refuses the verdict rather than scoring a smaller design.
#
#   T1b   **THE EQUIVALENCE RULE.  THE REGISTRATION DEFECT, PRINTED EITHER WAY.**
#         pp1's band half-width 0.15 was NARROWER than the realised se 0.157.
#         A NULL is therefore only reported as **EQUIVALENT TO ZERO WITHIN
#         +-0.15** when the WHOLE two-sided 95% CI lies inside [-0.15, +0.15].
#         Otherwise it reads **CONSISTENT WITH NULL, UNDERPOWERED**, and the CI
#         is printed against the band.  The scorer ALWAYS prints se, the 95% CI,
#         the CI half-width, the ratio (CI half-width)/0.15, and the MDE at 80%
#         power two-sided = (z_.975 + z_.80) * se = 2.8016 * se -- the SAME
#         normal-approximation formula that produced pp1's quoted MDE of 0.440
#         pp, so the two are directly comparable.  **This gate fires whatever
#         rp1 returns; the defect in pp1's registration is on the record either
#         way.**
#
#   T2    **THE TWO-WAY DECOMPOSITION: PERMUTATION DRAW vs RUN SEED.  THE REASON
#         THE BATCH EXISTS.**  On the balanced 3 (draw) x 6 (seed) permnode
#         grid, one observation per cell, the additive random-effects model
#         y_ps = mu + a_p + b_s + e_ps gives SS_draw (df 2), SS_seed (df 5) and
#         SS_resid (df 10).  **The residual is interaction + noise and the two
#         are NOT separable at one observation per cell** -- stated here, before
#         the data exists, not discovered afterwards.  F_draw = MS_draw/MS_resid
#         on (2,10), F_seed = MS_seed/MS_resid on (5,10); variance components
#         from the balanced EMS, negative estimates TRUNCATED AT ZERO with the
#         truncation printed.
#         REGISTERED READINGS, BOTH DIRECTIONS FIXED IN ADVANCE:
#           F_draw p <  0.05 -> **THE PERMUTATION DRAW IS A REAL EFFECT.**  Which
#                arbitrary same-size partition you happen to draw changes
#                plateau5.  pp1 then folded a REAL effect into its seed
#                variance; every single-draw alignment measurement is a
#                statement about that draw; and the alignment null must be
#                stated over the permutation DISTRIBUTION or not at all.
#           F_draw p >= 0.05 -> **THE PERMUTATION DRAW IS EXCHANGEABLE AT THIS
#                RESOLUTION.**  pp1's confound inflated no variance it did not
#                already carry, and A may be read as a statement about the
#                permutation distribution rather than about one draw.
#                **REGISTERED AS A NULL WITH A STATED MDE, NEVER AS PROOF OF
#                ZERO** -- the smallest sigma_draw the design could have
#                resolved is printed with it.
#           The same two-way reading is registered for F_seed and is read
#           against the corpus METHODS finding that SEED is null (F 1.21,
#           p 0.213): agreement reproduces it, disagreement is reportable.
#
#   T3    THE PER-DRAW CONTRASTS.  A_p = mean_s (permnode_p - nodewise) for each
#         draw, with its own paired se on six seeds, plus the spread across the
#         three draws.  **NO INDEPENDENT VERDICT, AND THAT IS DELIBERATE:**
#         A = mean_p A_p algebraically, so scoring the three separately would
#         score one degree of freedom three times.  T3 exists so a reader can
#         see whether a SINGLE draw, run pp1-style, would have returned a
#         different verdict from the same experiment; if the three straddle a
#         registered band boundary that is printed, not buried.
#   T4    THE POWER RECEIPT.  se(A) here against pp1's realised 0.157 and
#         against the design's promised ~0.09.  A DESIGN RECEIPT, NOT A FINDING;
#         no threshold is applied to it.
#   T5    **A ON THE SCALE OF D.  CROSS-BATCH AND DESCRIPTIVE.  NO VERDICT.**
#         `rp1` has NO chunk777 arm -- it is the alignment leg only -- so D is
#         IMPORTED from the two batches that measured it WITHIN batch at this
#         exact configuration (pp1 seeds 0-2, cc1 seeds 3-5) and is RE-DERIVED
#         FROM THE CSV AT SCORE TIME, never quoted from prose.  The +-0.25 pp
#         unmodelled cross-batch offset applies to the import and is printed
#         with it.  Nothing in T5 carries a gate.
#
# WHAT THIS BATCH DELIBERATELY DOES NOT DO
#   * It does NOT add a chunk777 arm.  The design asked for is the alignment leg
#     at three draws x six seeds; adding a fourth arm would be a different batch
#     and a different registration.  The price is that D must be imported, and
#     T5 states that in the open rather than hiding a cross-batch ratio inside a
#     within-batch table.
#   * It does NOT sweep ms.  ms=1e-4 is held because that is where pp1's P2 was
#     measured and where the box is readable.  **THE RISK IS STATED AND IT IS
#     pp1's RISK INHERITED: nodewise is read at 1e-4, not at its own argmax of
#     3e-4, so every verdict here is a statement at ms=1e-4.**
#   * The permutation is WITHIN each tensor.  `rp1` asks whether an output
#     channel is special AMONG THE SAME-SIZED SUBSETS OF ITS OWN LAYER -- the
#     question the Adam-mini / Adalayer / SGG line asks -- and it does NOT test
#     whether LAYER boundaries matter.  No verdict here may be written as
#     "architecture is irrelevant".
#   * It does NOT pool its A with pp1's A.  A is a within-batch quantity and the
#     cross-batch offset does not cancel across two batches.
#
# THE BOX IS NOT NEW AND IS NOT REGISTERED AGAIN.  `rp1` uses pp1's and cc1's
# BETA_CLIP verbatim and registers no field / N_eff gate, so it is deliberately
# NOT added to `analysis/c55_neff_noise.BOXES`; guard 3 instead asserts equality
# against BOTH already-registered entries.  c55's `box_for` raises on an
# unregistered root rather than guessing, which is the safe failure.
#
# STRUCTURAL CHECKS BEFORE USING ANY NUMBER (Rule 4)
#   1. python3 tests/test_permnode.py                  (CPU, run by guard 1e)
#   2. python3 analysis/c97_rp1_score.py --selftest    (run by guard S)
#   3. python3 analysis/c52_boxfree.py --selftest
#   4. plateau5 is PRIMARY.  The CSV `plateau` column is mean-of-last-20 and is
#      BANNED as a primary.  best_test inflates ~0.37 pp.
#
# USAGE
#   bash c97_permnode_replication.sh            # dry run
#   bash c97_permnode_replication.sh --submit   # submits, ONLY if guards pass
# =============================================================================

    return [float(r['plateau5']) for r in rd
            if r['run'].startswith(prefix) and r.get('plateau5','').strip()]

# guard 2b: pp1's P2 is the quantity this batch re-measures.  Re-derive it NOW

    sys.exit("GUARD FAIL: expected pp1's 3+3 rows, found %d+%d" % (len(pm), len(nd)))

    sys.exit("GUARD FAIL: pp1's P2 reads A=%+.3f se=%.3f now, not the -0.009 +- "

def eff(line):
    """last-wins, exactly like argparse."""
    out, cur = {}, None
    for t in line.split():
        if t.startswith("--") and len(t) > 2:
            cur = t[2:]
            out[cur] = ""
        elif cur is not None:
