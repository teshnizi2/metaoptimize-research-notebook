#!/bin/bash
# =============================================================================
# Cycle 73 -- bf9: THE 80-EPOCH N_eff/m POINT, WITH THE INSTRUMENT ACTUALLY ON.
# cluster_b.  12 jobs.  Tag `bf9-*`.  80 epochs.  LO=-60 fixed, HI=+2.0 fixed.
# Rungs w / node / lay, seeds 0-3 (n=4, matching the bar's own n).
#
# WHY THIS EXISTS.  `bf8` ran correctly and measured NOTHING it was for.
#
#   `patches/patch_probe5.py:55` gates the entire per-coordinate sign-count
#   writer on   os.environ.get('PROBE5','') == '1'.
#   `bin/c71_floor_budget.sh:306` exports   PROBE=5   -- the probe STRIDE --
#   and never PROBE5=1, the INSTRUMENT.  bd7's `c54_budget_curve.sh:287` exports
#   PROBE=5,PROBE5=1,PROBE5_WRITE_EVERY=500 and its dirs do hold neg_counts.npy.
#   Two env vars one character apart.  bf8 wrote no neg_counts.npy, and
#   `neff_instrument.reduce_root:162` skips any dir without neg_counts.json, so
#   every N_eff/m cell came back MISSING and F0.5 / F1 / F2 were never scored.
#
#   bf8's guard 1 DID check that PATCH_PROBE5 is present in HF.py.  The patch was
#   present; the switch was off.  **A guard that checks the instrument EXISTS is
#   not a guard that it is ENABLED.**  That is guard 1b below, and STANDING RULE (19).
#
# WHAT bf8 DID ESTABLISH, AND WHY THIS BATCH IS SMALLER IN THE FLOOR AXIS.
# Re-scored by `analysis/c73_bf8_ceiling.py` (15/15 selftests), from probe.jsonl:
#
#   * F0 is 12/12, NOT 0/12.  `n_beta` is a probe.jsonl FIELD, present, correct
#     and constant across all 8000 records on every arm.  c72's "the batch is
#     VOID" was a file-presence test wearing an n_beta label.  bf8 is VALID DATA.
#   * THE FLOOR IS FULLY FREED.  0/12 arms touch LO (bd7: 10/12 at LO=-30).  The
#     deepest beta_true_min anywhere in the batch is **-46.744**, against guard 4's
#     projection of -46.4 -- the extrapolation was right to 0.35 log units.
#   * f60 and f90 give the SAME guard verdict on 6/6 (rung, seed) pairs.
#
# So the second floor is DROPPED and its six jobs become seeds 2-3.  This is not
# a convenience: at LO=-60 no coordinate ever reaches the floor (coord_lo =
# 0.0000% on 12/12), and a constraint that is never active cannot change the
# trajectory.  "Is N_eff/m floor-invariant between two floors both strictly below
# the path?" is an identity, not an experiment.  bf8 already verified the premise.
# THE COST IS STATED: bf9 does NOT measure floor-invariance at a BINDING floor.
#
# THE CEILING BIND IS REAL BUT SMALL, AND IS REPORTED AT BOTH RESOLUTIONS.
# c72's F0.3 called 2/12 arms BOUND off `rec_hi` (52.23% / 50.68% of records) and
# printed "AN ARM BINDS AT LO EVEN AT THIS FLOOR", pointing at `first_lo`.
# `first_lo` is None on all twelve.  The binding is at the CEILING, the other
# guard -- exactly what STANDING RULE (18) was written to catch, caught by the
# rule and then mislabelled by the prose.  At the resolution the clamp actually
# acts at, `coord_hi` is **0.0178%** and **0.0329%** of (record, coordinate)
# cells: ~2-4k of 11.17M weights pinned, in the second half only, first touched
# at epoch 38.2 / 39.5.  Both bound arms are seed 0; both seed-1 arms are clean at
# BOTH floors, and w-s0's beta_true_max runs away between ep30 and ep40 in both.
# That is seed-level bistability of the weightwise arm, reproduced across floors.
#
# HI IS NOT RAISED.  bd7's own evidence forbids it: at HI=+6.0 the weightwise arms
# COLLAPSED 2/2 to 10.000.  The ladder goes down, not up (CORRECTIONS 101.4).
# Seeds 2-3 are the answer to a bound seed, not a wider box.
#
# THE PRE-REGISTERED GATES, IN ORDER.  Nothing below may be edited after the data
# lands; that is the whole point of writing it here.
#
#   G0    VALIDITY.  n_records == 8000; n_beta == {w 11173962, node 14420, lay 62}
#         on EVERY record, not just record 0; beta moved.  Read from probe.jsonl.
#   G0.2  THE INSTRUMENT FIRED.  neg_counts.json exists, its n_tot equals n_beta
#         for the rung, and neg_counts.npy has shape (n_tot,).  **THIS IS THE GATE
#         bf8 HAD NO WAY TO FAIL, BECAUSE IT WAS NEVER WRITTEN.**  Any arm missing
#         it is dropped and NAMED; the batch is not re-scored around it.
#   G0.3  BOX-FREE at BOTH guards (STANDING RULE 18), per seed, via
#         c52_boxfree.occupancy -- UNCHANGED, the published rec_-based 5% gate is
#         PRIMARY.  coord_lo / coord_hi are reported ALONGSIDE and never averaged
#         with it.  The gate is not re-thresholded after seeing bf8; re-reading a
#         gate at a resolution that flatters the data is the failure this campaign
#         has repeated most.
#   G0.4  TRAINS AT ALL.  plateau5 > 40.0, collapsed false, per seed.
#   G1    THE 80-EPOCH POINT of the N_eff/m budget curve, which currently has TWO
#         points (20, 40).  55.6's POST-HOC expectation is w below 0.1509 and
#         still falling.  A confirmation REPLICATES a post-hoc window and is
#         NEVER a discovery -- label it so in FINDINGS or do not write it.
#   G2    **THE REGISTERED OUT-OF-SAMPLE TEST, CARRIED OVER FROM bf8 UNCHANGED.**
#         71.7's band: argmin of N_eff/m is `w` below span ~6.3, `node` in
#         ~[8.9,12.6], `w` above ~17.5.  br6 (same ms, HALF the budget) sits at
#         17.52 and reads `w`; this cell must sit further above the band.
#         **PREDICTION: argmin = `w`, gap/SE >= 2.**
#         REFUTES (argmin = `node`) -> the band is not a function of span alone
#         and 101.9's "one scalar" claim is WITHDRAWN.
#         It is carried over VERBATIM and is still out-of-sample: bf8 produced no
#         N_eff datum of any kind, so nothing about this cell has been seen.
#   G2b   THE BOUND-SEED POLICY, REGISTERED IN ADVANCE.  If any weightwise seed
#         fails G0.3, report the argmin BOTH ways -- all seeds, and bound seeds
#         dropped.  **The ALL-SEEDS version is PRIMARY.**  Dropping a seed after
#         seeing which way it moves the argmin is selection; deciding here is not.
#
# STRUCTURAL CHECKS BEFORE USING ANY NUMBER (Rule 4)
#   1. Register bf9:f60 -> (-60.0, 2.0) in c55_neff_noise.BOXES with this
#      script's path:line BEFORE scoring -- an unregistered root is SKIPPED.
#   2. python3 analysis/c73_bf8_ceiling.py --selftest      (15/15)
#   3. python3 analysis/c55_neff_noise.py --selftest       (51/51)
#   4. python3 analysis/c52_boxfree.py --selftest          (27/27)
#   5. Re-derive every number above from results/all_runs.csv and the probe dirs.
#
# USAGE
#   bash c73_bf9_probe5.sh            # dry run: prints every sbatch line
#   bash c73_bf9_probe5.sh --submit   # submits, ONLY if the guards pass
# =============================================================================
set -u

WS=/cluster/account_b/metaopt                          # cluster_b -- bf8's workspace
RUNNER=$WS/jobs/run_cifar.sh
HF=$WS/MetaOptimize/codes/Supervised_tasks/MetaOptimize/cifar10/Optimizers/HF.py
SAVE=$WS/runs/bf9
PARTS=gpu-short,gpu-l4-24g,gpu-2080ti-11g,gpu-mig-40g,gpu-a100-80g
USER_NAME=account_b
PEND_CAP=40
NJOBS=12
LO=-60                         # FIXED -- bf8's deepest beta_true_min is -46.744
HI=2.0                         # FIXED -- bd7's HI=+6.0 collapsed weightwise 2/2
EPOCHS=80
MST=1e-3
WALL=03:50:00
WRITE_EVERY=500                # 16 dumps over 8000 records, as bd7 used
SUBMIT=0
[ "${1:-}" = "--submit" ] && SUBMIT=1

echo "=== c73 bf9 -- the 80-epoch N_eff/m point WITH PROBE5 ON (cluster_b) ==="
echo "    LO=$LO fixed, HI=+$HI fixed, ms=$MST, ${EPOCHS}ep, rungs w/node/lay, seeds 0-3"
echo "    bf8 was VALID but MEASURED NOTHING: PROBE5=1 was never exported"
echo "    G2 carries bf8's registered band prediction over VERBATIM: argmin = w"
echo

# GUARD 1 -- the runner, the optimizer source, and the probe patches PRESENT.
[ -r "$RUNNER" ] || { echo "GUARD FAIL: $RUNNER not readable"; exit 1; }
[ -r "$HF" ]     || { echo "GUARD FAIL: $HF not readable"; exit 1; }
for P in PATCH_PROBE5 PATCH_PROBE5_FIX PATCH_CLIP PATCH_CLIPCOUNT; do
  grep -q "$P" "$HF" || { echo "GUARD FAIL: $P not present in $HF"; exit 1; }
done
echo "guard 1: runner readable; PATCH_PROBE5 + PATCH_PROBE5_FIX + PATCH_CLIP + PATCH_CLIPCOUNT present  OK"

# GUARD 1b -- **THE INSTRUMENT IS SWITCHED ON.**  THE GUARD bf8 DID NOT HAVE.
# Checked THREE ways, against the two files that actually decide it, and against
# THIS script's own text -- so the guard cannot pass while the export line drifts.
SELF="$0"
python3 - "$HF" "$SELF" "$WS" <<'PYEOF' || exit 1
import os, re, sys
hf, self_path, ws = sys.argv[1], sys.argv[2], sys.argv[3]

# (a) the writer in the SHIPPED source is gated on PROBE5, and we read the gate
#     out of HF.py itself rather than trusting patch_probe5.py's copy of it.
src = open(hf).read()
m = re.search(r"os\.environ\.get\(\s*['\"]PROBE5['\"]\s*,\s*['\"]['\"]\s*\)\s*==\s*['\"]1['\"]", src)
if not m:
    sys.exit("GUARD FAIL: the PROBE5 writer's env gate is not in HF.py in the form "
             "this guard knows how to check -- do NOT submit blind")
if "neg_counts.npy" not in src or "neg_counts.json" not in src:
    sys.exit("GUARD FAIL: HF.py does not emit neg_counts.{npy,json}")

# (b) THIS script's own --export line must set the INSTRUMENT, not just the STRIDE.
#     The line must BEGIN with the sbatch export form, not merely mention it, so
#     that this guard's own source -- which necessarily names both --export and
#     PROBE_DIR -- is not counted as a second export line.  It was, twice, on the
#     first two dry runs; a self-reading guard has to exclude itself explicitly.
me = open(self_path).read()
exp = [l for l in me.split("\n")
       if l.strip().startswith('--export="ALL,') and "PROBE_DIR" in l]
if len(exp) != 1:
    sys.exit(f"GUARD FAIL: expected exactly one --export line, found {len(exp)}")
line = exp[0]
for need in ("PROBE5=1", "PROBE5_WRITE_EVERY"):
    if need not in line:
        sys.exit(f"GUARD FAIL: --export line does not set {need}.  THIS IS THE bf8 BUG: "
                 f"PROBE=5 is the probe STRIDE, PROBE5=1 is the sign-count INSTRUMENT. "
                 f"line was: {line.strip()}")
if not re.search(r"[,\"]PROBE=5,", line):
    sys.exit("GUARD FAIL: --export line does not set the probe stride PROBE=5")

# (c) the batch this one is a re-run OF must show the SAME two vars, so the
#     operating point of the INSTRUMENT matches bd7's, not only the optimizer's.
bd7 = os.path.join(os.path.dirname(self_path), "c54_budget_curve.sh")
if os.path.exists(bd7):
    b = open(bd7).read()
    for need in ("PROBE5=1", "PROBE5_WRITE_EVERY=500"):
        if need not in b:
            sys.exit(f"GUARD FAIL: {need} absent from c54_budget_curve.sh -- the "
                     f"reference batch does not use the instrument this one claims to copy")
    print("guard 1b: PROBE5 gate found in HF.py; this script's --export sets "
          "PROBE=5 + PROBE5=1 + PROBE5_WRITE_EVERY; bd7 matches  OK")
else:
    sys.exit("GUARD FAIL: c54_budget_curve.sh not readable -- cannot diff the instrument")
PYEOF

python3 -c "import py_compile; py_compile.compile('$HF', doraise=True)" 2>/dev/null || {
  echo "GUARD FAIL: $HF does not compile"; exit 1; }
echo "guard 2: HF.py compiles  OK"

# GUARD 2b -- the clip parser must accept THIS batch's floor.
python3 - "$HF" "$LO" "$HI" <<'PYEOF' || exit 1
import re, sys
src = open(sys.argv[1]).read()
assert re.search(r"_bc\.split\('?:'?\)", src) or re.search(r'_bc\.split\(":"\)', src), \
    "BETA_CLIP is not parsed by splitting on ':' -- the format assumed here is wrong"
assert "float(lo)" in src, "BETA_CLIP bounds are not float()-parsed"
lo, hi = float(sys.argv[2]), float(sys.argv[3])
assert lo < hi, f"LO {lo} is not below HI {hi}"
print(f"guard 2b: BETA_CLIP parses as float(LO):float(HI); {lo}:{hi} representable  OK")
PYEOF

# GUARD 3 -- THE OPERATING POINT IS DIFFED AGAINST bd7 ITSELF, never asserted.
BD7=$(dirname "$0")/c54_budget_curve.sh
if [ -r "$BD7" ]; then
  for f in "ResNet18" "CIFAR10" "SGDm" "Lion" "--alpha0 1e-3" "--batch-size 100" \
           "--momentum-param-base 0.99" "--weight-decay-base 0.1" \
           "--momentum-param-meta 0.99" "--Lion-beta2-meta 0.9" "AUGMENT=1"; do
    grep -q -- "$f" "$BD7" || {
      echo "GUARD FAIL: '$f' absent from c54_budget_curve.sh -- bf9 is NOT bd7's"
      echo "            operating point, so G1 is not a re-run of D1.  STOP."; exit 1; }
  done
  grep -qE -- '(EPOCHS=80|--num-epochs 80)' "$BD7" || {
    echo "GUARD FAIL: bd7 is not an 80-epoch batch -- this is not its re-run"; exit 1; }
  grep -q -- "$MST" "$BD7" || { echo "GUARD FAIL: ms=$MST absent from bd7"; exit 1; }
  echo "guard 3: operating point byte-matches bd7 (11 fields + 80 ep + ms=$MST)  OK"
else
  echo "GUARD FAIL: c54_budget_curve.sh not readable -- cannot diff the operating point"; exit 1
fi

# GUARD 4 -- THE FLOOR, now sized from bf8's OWN 80-EPOCH MEASUREMENT rather than
# from the extrapolation bf8 had to use.  This is the one number bf8 bought us.
python3 - "$LO" <<'PYEOF' || exit 1
import sys
lo = float(sys.argv[1])
# MEASURED on bf8, all 12 arms, 80 epochs, by analysis/c73_bf8_ceiling.py.
deepest = -46.744            # probe_lay_f90_s0, the deepest beta_true_min in the batch
proj80  = -46.4              # bf8's guard-4 projection, for the record
assert abs(deepest - proj80) < 1.0, "the projection and the measurement disagree by >1 log unit"
assert lo < deepest, f"floor {lo} is ABOVE the measured deepest beta {deepest}"
margin = deepest - lo
assert margin > 10.0, f"only {margin:.1f} log units of margin below the measured path"
print(f"guard 4: floor {lo} sits {margin:.1f} log units below bf8's MEASURED deepest "
      f"beta_true_min {deepest} (projection was {proj80}, error {abs(deepest-proj80):.2f})  OK")
PYEOF

# GUARD 4b -- THE CEILING IS NOT RAISED, AND THE REASON IS bd7's OWN DATA.
python3 <<'PYEOF' || exit 1
hi = 2.0
bd7_hi_collapsed = 6.0       # bd7's HI=+6.0 weightwise arms collapsed 2/2 to 10.000
assert hi < bd7_hi_collapsed, "this batch would re-run the ceiling that collapsed weightwise"
# bf8's ceiling occupancy at the resolution the clamp acts at, MEASURED (c73).
for arm, coord_hi in (("w_f60_s0", 0.000178), ("w_f90_s0", 0.000329)):
    assert coord_hi < 0.01, f"{arm} coord_hi {coord_hi} is not a small bind after all"
print(f"guard 4b: HI=+{hi} held below bd7's collapsing +{bd7_hi_collapsed}; bf8's worst "
      f"measured ceiling occupancy is 0.0329% of coordinate-cells, on 1 of 2 seeds  OK")
PYEOF

# GUARD 5 -- queue depth.  12 jobs is inside the ~20-job / 0.5%-RawUsage rule.
FS=$(sshare -U -u "$USER_NAME" -n -o FairShare 2>/dev/null | tr -d ' ' | head -1)
PEND=$(squeue -h -u "$USER_NAME" -t PENDING 2>/dev/null | wc -l | tr -d ' ')
echo "guard 5: FairShare=${FS:-unknown} (informational), pending=$PEND, adding $NJOBS"
if [ "$SUBMIT" = "1" ]; then
  [ "$((PEND + NJOBS))" -le "$PEND_CAP" ] || {
    echo "ABORT: $PEND pending + $NJOBS would exceed the $PEND_CAP cap"; exit 1; }
fi

# GUARD 6 -- the wall-clock request must fit the TIGHTEST partition in $PARTS.
python3 - "$WALL" "$PARTS" <<'PYEOF' || exit 1
import subprocess, sys
def secs(t):
    d, _, rest = t.partition("-")
    if not rest: rest, d = d, "0"
    p = [int(x) for x in rest.split(":")]
    while len(p) < 3: p.insert(0, 0)
    return int(d) * 86400 + p[0] * 3600 + p[1] * 60 + p[2]
want, parts = sys.argv[1], sys.argv[2].split(",")
out = subprocess.run(["sinfo", "-h", "-o", "%P %l"], capture_output=True, text=True).stdout
lim = {}
for ln in out.split("\n"):
    f = ln.split()
    if len(f) == 2 and f[1] not in ("infinite", "n/a"):
        lim[f[0].rstrip("*")] = secs(f[1])
tight = [(p, lim[p]) for p in parts if p in lim]
if not tight:
    sys.exit("GUARD FAIL: sinfo returned no limit for any requested partition")
name, cap = min(tight, key=lambda kv: kv[1])
if secs(want) > cap:
    sys.exit(f"GUARD FAIL: --time={want} exceeds {name}'s MaxTime "
             f"({cap // 3600}:{cap % 3600 // 60:02d}) -- sbatch would reject the WHOLE batch")
print(f"guard 6: --time={want} fits the tightest partition {name} "
      f"({cap // 3600}:{cap % 3600 // 60:02d})  OK")
PYEOF

# GUARD 7 -- THROUGHPUT HEADROOM against bf8's OWN measured 80-epoch wallclock.
# THE CSV PATH IS PASSED IN FROM BASH, NOT DERIVED FROM __file__ (CORRECTIONS 101.11).
CSVP="$(cd "$(dirname "$0")/.." && pwd)/results/all_runs.csv"
[ -r "$CSVP" ] || { echo "GUARD FAIL: $CSVP not readable"; exit 1; }
python3 - "$WALL" "$CSVP" <<'PYEOF' || exit 1
import csv, sys
def secs(t):
    p = [int(x) for x in t.split(":")]
    while len(p) < 3: p.insert(0, 0)
    return p[0] * 3600 + p[1] * 60 + p[2]
wall_min = secs(sys.argv[1]) / 60.0
w = []
with open(sys.argv[2]) as f:
    for r in csv.DictReader(f):
        if r.get("run", "").startswith("bf8-"):
            for k in ("minutes", "wallclock_min", "elapsed_min", "runtime_min"):
                if r.get(k):
                    try: w.append(float(r[k]))
                    except ValueError: pass
                    break
if not w:
    sys.exit(f"GUARD FAIL: no completed 80-epoch bf8 wallclock in {sys.argv[2]} to size against")
slow = max(w)
if slow > wall_min:
    sys.exit(f"GUARD FAIL: bf8's slowest 80-epoch run took {slow:.0f} min but --time is "
             f"{wall_min:.0f} min -- would truncate")
print(f"guard 7: bf8 80-epoch wallclock n={len(w)}, median {sorted(w)[len(w)//2]:.0f} min, "
      f"slowest {slow:.0f} min, against a {wall_min:.0f} min wall "
      f"({wall_min / slow:.1f}x headroom on the slowest).  NOTE: PROBE5 adds ~16 x 45 MB "
      f"of writes on each weightwise arm, which bf8 did NOT pay  OK")
PYEOF

# GUARD 8 -- DISK.  Four weightwise neg_counts.npy are 44.7 MB each, and the
# twelve probe.jsonl are ~46 MB each.  bf8 did not pay the first of those.
python3 - "$WS" <<'PYEOF' || exit 1
import shutil, sys
need_gb = (4 * 44.7 + 12 * 46.0) / 1024.0     # ~0.71 GB
free_gb = shutil.disk_usage(sys.argv[1]).free / 1024.0 ** 3
if free_gb < need_gb * 20:
    sys.exit(f"GUARD FAIL: {free_gb:.1f} GB free, batch needs ~{need_gb:.2f} GB "
             f"and this guard wants 20x headroom")
print(f"guard 8: {free_gb:.0f} GB free vs ~{need_gb:.2f} GB needed  OK")
PYEOF

mkdir -p "$SAVE"
N=0
FAIL=0
SGDM=(--optimizer HF --alg-base SGDm --momentum-param-base 0.99 --weight-decay-base 0.1
      --alg-meta Lion --momentum-param-meta 0.99 --Lion-beta2-meta 0.9 --weight-decay-meta 0)
for G in weightwise nodewise layerwise; do
  if   [ "$G" = weightwise ]; then SHORT=w
  elif [ "$G" = nodewise ];   then SHORT=node
  else                             SHORT=lay
  fi
  for S in 0 1 2 3; do
    RN="bf9-${SHORT}-s${S}"
    CMD=(sbatch --job-name="$RN" --partition="$PARTS" --gres=gpu:1 --cpus-per-task=6
      --mem=14G --time="$WALL" --nice=0
      --export="ALL,AUGMENT=1,BETA_CLIP=${LO}:${HI},PROBE=5,PROBE5=1,PROBE5_WRITE_EVERY=${WRITE_EVERY},PROBE_DIR=$SAVE/probe_${SHORT}_f60_s${S}"
      "$RUNNER" "${SGDM[@]}"
      --dataset CIFAR10 --NN-name ResNet18 --batch-size 100
      --max-time 999:00:00 --gamma 1 --meta-stepsize "$MST" --alpha0 1e-3
      --num-epochs "$EPOCHS" --stepsize-groups "$G" --seed "$S"
      --save-directory "$SAVE" --run-name "$RN")
    # COUNT WHAT SLURM ACCEPTED, NOT WHAT WE TRIED (CORRECTIONS 71).
    if [ "$SUBMIT" = "1" ]; then
      if "${CMD[@]}" >/dev/null; then N=$((N+1)); else FAIL=$((FAIL+1)); fi
    else
      N=$((N+1)); printf '%s\n' "${CMD[*]}"
    fi
  done
done
echo "---- $N jobs ($( [ "$SUBMIT" = 1 ] && echo ACCEPTED BY SLURM || echo 'dry run, nothing submitted' )); $FAIL rejected ----"
[ "$N" = "$NJOBS" ] || echo "!!! expected $NJOBS jobs, built $N -- DO NOT TREAT AS SUBMITTED"
[ "$FAIL" -gt 0 ] && echo "!!! $FAIL sbatch calls FAILED -- do not treat this batch as submitted"
echo "reduce with, IN THIS ORDER:"
echo "  0. REGISTER THE BOX FIRST: add bf9:f60 -> (-60.0, 2.0) to c55_neff_noise.BOXES"
echo "     with this script's path:line, or the root is SKIPPED by design."
echo "  1. G0    n_records==8000, n_beta on EVERY record, beta moved, PER JOB"
echo "  2. G0.2  **THE INSTRUMENT FIRED**: neg_counts.json present, n_tot == n_beta,"
echo "           neg_counts.npy shape (n_tot,).  This is the gate bf8 could not fail."
echo "  3. G0.3  BOX-FREE at BOTH guards, rec_-based 5% gate PRIMARY and UNCHANGED;"
echo "           coord_lo/coord_hi reported alongside, never averaged in."
echo "  4. G0.4  plateau5 > 40 and collapsed false, per seed"
echo "  5. G1    the 80-epoch point.  55.6's w<0.1509 expectation is POST-HOC:"
echo "           a confirmation REPLICATES it and is NEVER a discovery."
echo "  6. G2    THE BAND OUT OF SAMPLE.  span must exceed br6's 17.52 (c55 defn)."
echo "           REGISTERED: argmin = w, gap/SE >= 2.  argmin = node REFUTES 71.7"
echo "           and WITHDRAWS 101.9's 'one scalar' claim."
echo "  7. G2b   bound weightwise seeds: report BOTH ways, ALL-SEEDS is PRIMARY."
