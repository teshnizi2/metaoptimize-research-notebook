#                               45..50 AT cts3's HORIZON.  ONE SUBMISSION,
#                               21 JOBS, 772 EPOCHS, SEEDS {6,7,8}.
#
# ACCOUNT: account_b (cluster_b).  WORKSPACE: /cluster/account_b/metaopt.
# Nothing here touches the other account, nothing is submitted to `cluster_a`, and
# every guard and scancel line below is filtered on the `cpk3-` prefix alone.
#
# REGISTERED SCORER: analysis/cS2_cpk3_score.py, git-committed BEFORE this
# batch is submitted (STANDING RULE 21).  Every bar, the noise floor (RE-DERIVED
# at registration time from the live corpus at BOTH horizons, never copied), the
# grid justification and the POINT PREDICTION are frozen there and its
# --selftest re-derives all of them from the corpus and from arithmetic rather
# than from prose.
#
# NO CODE PATCH.  The only things that differ from cpk2's arms are
# --stepsize-groups and --seed.  BETA_CLIP is left at the campaign standard.
# EVERY NON-AXIS FLAG IS BYTE-MATCHED TO bin/cR1_cut_position_horizon.sh, which
# was READ rather than reconstructed.
#
# -----------------------------------------------------------------------------
# THE QUESTION -- THE GAP cpk2's ADVERSARIAL ROUND LEFT OPEN
# -----------------------------------------------------------------------------
# cpk2 (CORRECTIONS 158) returned k*-UNMOVED | CONVERGED at 772 epochs with
# k49 ahead by 10.5140 pp = 14.04 SE.  The peak's IDENTITY is settled among the
# sampled cuts; its LOCATION is not.  k = 44, 46 and 48 have NEVER been run at
# ANY horizon in this cell -- the corpus holds ZERO rows at [44,18], [46,16] or
# [48,14] anywhere.  k is a 1-BASED INTEGER tensor index, so there is no
# interpolation between 49 and 50.
#
# -----------------------------------------------------------------------------
# THE DESIGN.  7 arms x 3 seeds = 21 jobs, ONE submission.
#   SWEEP (m = 2)   k45 [45,17]  k46 [46,16]  k47 [47,15]  k48 [48,14]
#                   k49 [49,13]  k50 [50,12]      <-- CONSECUTIVE 45..50
#   FLOOR ANCHOR    k01 scalar (m = 1), IN BATCH, at the horizon it is applied at
#   SEEDS {6,7,8} -- used NOWHERE in this cell, so ZERO duplicate rows.
#   HORIZON 772, the identical E cts3 and cpk2 registered.  The 100-epoch
#   control is read off epochs 95-99 of THESE SAME RUNS; no separate 100-epoch
#   jobs are submitted, and guard 4f proves the precondition on the LIVE
#   train.py.
#
# WHY A CONSECUTIVE GRID AND NOT JUST {46,48}.  On the LIVE model (guard 4
# measures this, it is not quoted from a document) the cuts 46 and 48 are
# exactly the indices that turn cpk2's TWO-TENSOR steps into SINGLE-TENSOR
# steps.  With 45..50 in ONE batch this measures FIVE consecutive single-tensor
# steps, all WITHIN batch:
#     45 -> 46  layer4.0.conv1.weight   1,179,648 params
#     46 -> 47  layer4.0.bn1.weight           512
#     47 -> 48  layer4.0.bn1.bias             512
#     48 -> 49  layer4.0.conv2.weight   2,359,296
#     49 -> 50  layer4.0.bn2.weight           512
# k50 is included specifically so that k49 is STRICTLY INTERIOR to the grid --
# without it the argmax would sit at the grid's right edge, which is the exact
# defect cpk2 was criticised for -- and so that the cliff premise (gate R1) is
# in batch.  k47 and k45 are included so the 47->48 and 45->46 steps are
# single-tensor IN BATCH rather than cross-batch.  k49 is included so that
# "k48 > k49 relocates the peak" is decided WITHIN batch: BATCH is the unit of
# replication here (F(62,85) = 5.47, p 6.9e-13).
#
# WHY k = 44 IS DECLINED.  It closes NO gap inside the bracket (46 and 48 are
# the only unsampled integers between 45 and 50) and it cannot move the peak:
# k45 measured 43.5140 at 772, 12.8987 pp below k49, and every left-flank arm
# is converged at 100 and gains about 1 pp over the extra 672 epochs.  COST
# WOULD BE 3 runs / ~16.5 GPU-h.  CONSEQUENCE, RECORDED: cpk3 may NOT claim the
# curve is monotone on 44 -> 49, nor that k* = 49 over any contiguous range
# wider than 45..50.
#
# WHY SEEDS {6,7,8}.  cpk3 re-runs k45/k47/k49/k50, which cpk2 ran at 772 on
# {3,4,5}.  At {3,4,5} TWELVE of these twenty-one runs would be
# exact-configuration RE-EXECUTIONS of existing corpus rows -- the CORRECTIONS
# 152 defect.  {6,7,8} appear nowhere in this cell (the only ResNet18_c100 rows
# carrying them are batch p7 at alpha0 = 1e-3, 20 epochs, named granularities),
# so cpk3 produces ZERO duplicates and buys a THIRD disjoint seed set for k49
# at 772.  PRICE: every level comparison to cpk2 is cross-batch AND cross-seed
# and is therefore DESCRIPTIVE.  Every gate in the scorer is within cpk3.
#
# THE PRE-REGISTERED POINT PREDICTION, frozen in the scorer and re-derived by
# its --selftest from cpk2's measured steps and the LIVE tensor sizes.
# H-MASS (registered): each tensor carries a share of a multi-tensor step
# proportional to its parameter count =>
#       k46 45.8976    k48 45.9009    (i.e. both land ON TOP OF k47 45.8987)
# H-EQUI (the named alternative, printed beside it): equal shares =>
#       k46 44.7063    k48 51.1557
# The two are 5.2547 pp = 6.60 SE_ARM_DIFF apart on k48, so this batch
# SEPARATES them.  PREDICTED BRANCH: PEAK-CONFIRMED-AT-49, margin 10.5117 pp
# = 13.20 SE_ARM_DIFF.  Registered branches: PEAK-CONFIRMED-AT-49 /
# PEAK-RELOCATES-TO-46 / PEAK-RELOCATES-TO-48 (or -45/-47/-50) / PEAK-PLATEAU /
# UNRESOLVED-NOT-CONVERGED (plus the provenance/noise/premise/control/floor
# UNRESOLVED branches).
#
# -----------------------------------------------------------------------------
# WALLTIME AND PARTITIONS -- MEASURED ON cpk2, NOT PROJECTED
# -----------------------------------------------------------------------------
# cpk2 ran this exact cell at this exact horizon on this account: 18 jobs,
# 99.84 GPU-h total, mean 5.546 h, MAX elapsed 06:20:34 against an 11:00:00
# request.  cts3 before it: 6 jobs, max 05:33:11.
#     PARTS = gpu-l4-24g,gpu-mig-40g,gpu-a100-80g   (all 7-day partitions)
#     WALL  = 11:00:00 -- 1.73x cpk2's worst run; cpk2's own request kept
#             UNCHANGED so this batch cannot be slower-scheduled than the one
#             it extends.
# gpu-short's 4 h ceiling excludes it by arithmetic (5.5 h needed).
# gpu-2080ti-11g is excluded because its measured 68-71 s/epoch would put 772
# epochs at ~15 h.
# QUEUE DEPTH, CHECKED BEFORE COMMITTING (guard 5b re-reads it at submit time):
# at design time the three partitions held 44 RUNNING (43 of them multi-day)
# and 10 PENDING, and this account's own queue was EMPTY.  An 11 h request
# backfills against 7-day neighbours.  This is the hz3 failure mode
# (unschedulable at 10 h) and it was measured, not assumed.
# COST: 21 jobs x ~5.55 h = ~117 GPU-hours at cpk2's measured mean.
#
# USAGE   bash bin/cS2_cut_position_infill.sh            # dry run, submits nothing
#         bash bin/cS2_cut_position_infill.sh --submit
# =============================================================================
set -u
SUBMIT=0; [ "${1:-}" = "--submit" ] && SUBMIT=1
FAIL=0; guard_fail() { echo "!!! GUARD FAIL: $*"; FAIL=1; }

USER_NAME="${USER:-$(whoami)}"
# bin/_lib_guards.sh re-assigns WS at source time from METAOPT_WS with a
# default pointing at the OTHER account; exporting it here is the documented
# work-around (RULE 20).  The library is NOT patched while jobs are queued.
export METAOPT_WS=${METAOPT_WS:-/cluster/account_b/metaopt}
WS=$METAOPT_WS
REPO="$(cd "$(dirname "$0")/.." && pwd)"
RUNNER=$WS/jobs/run_cifar.sh
SAVE=$WS/runs/cpk3
CIF=${CIFAR10_DIR:-$WS/MetaOptimize/codes/Supervised_tasks/MetaOptimize/cifar10}

module load Python/3.10.4-GCCcore-11.3.0 >/dev/null 2>&1 || true
# shellcheck disable=SC1091
[ -f "$WS/envs/mo/bin/activate" ] && . "$WS/envs/mo/bin/activate" 2>/dev/null || true

CLIP_C="-15:-2.3026"
MST=1e-3; ALPHA0=1e-6; EPOCHS=772; CTRL_EPOCHS=100; BATCH=100
GAMMA=1; AUG=1

NET=ResNet18_c100
SEEDS="6 7 8"
PARTS=gpu-l4-24g,gpu-mig-40g,gpu-a100-80g

NTENS=62

# ---- the registered grid and the registered specs, written out LITERALLY ----
# K_LIST is the grid the scorer cross-checks; the G_K* strings are the exact
# argv the jobs receive.  guard 4c proves they agree so neither can drift.
# NOTE: k is 1-BASED and is the SIZE of the first group -- group 1 is
# named_parameters()[0:k], so "the cut at k" means tensors 1..k (1-based).
K_LIST="45 46 47 48 49 50"
G_K45='[45,17]'
G_K46='[46,16]'
G_K47='[47,15]'
G_K48='[48,14]'
G_K49='[49,13]'
G_K50='[50,12]'
ARMS="k01 k45 k46 k47 k48 k49 k50"

echo "=============================================================="
echo " cpk3 -- WHERE IS THE CUT-POSITION PEAK?  CONSECUTIVE GRID 45..50"
echo " $DSET / $NET  ms $MST  alpha0 $ALPHA0  AUGMENT=$AUG  PROBE=0"
echo " clamp held at the campaign standard $CLIP_C"
echo " horizon $EPOCHS epochs; the ${CTRL_EPOCHS}-epoch control is the SAME runs'"
echo " own epoch-$((CTRL_EPOCHS-1)) readout (guard 4f proves the precondition)"
echo " cuts k = $K_LIST  + scalar floor anchor IN BATCH; seeds $SEEDS"
echo " 7 arms x 3 seeds = 21 jobs, ONE submission"
echo " partitions $PARTS   walltime $WALL"
echo " scorer: analysis/cS2_cpk3_score.py (registered before any run exists)"
echo "=============================================================="

# ---- guard 0: the corpus ----------------------------------------------------
CSVP="$REPO/results/all_runs.csv"
[ -f "$CSVP" ] || guard_fail "guard 0: no CSV"
[ -f "$CSVP" ] && echo "guard 0: CSV present ($(wc -l < "$CSVP") lines)"

# ---- guard 1: the registered scorer exists, is committed, and selftests ------
SC="$REPO/analysis/cS2_cpk3_score.py"
[ -f "$SC" ] || guard_fail "guard 1a: scorer missing"
if git -C "$REPO" rev-parse --git-dir >/dev/null 2>&1; then
  DIRTY=$(git -C "$REPO" status --porcelain -- analysis/cS2_cpk3_score.py bin/cS2_cut_position_infill.sh 2>/dev/null)
  [ -z "$DIRTY" ] && echo "guard 1b: scorer AND this script are committed (RULE 21)" \
                  || guard_fail "guard 1b: uncommitted -- RULE 21 requires the scorer committed BEFORE any run exists: $DIRTY"
else
  echo "guard 1b: NOTE -- no git repo at $REPO on this host; RULE 21 was verified"
  echo "          on the host that committed the scorer.  Not a pass, not a fail."
fi
python3 "$SC" --selftest >/tmp/cpk3_selftest.$$ 2>&1 \
  && echo "guard 1c: scorer --selftest PASSES" \
  || { guard_fail "guard 1c: scorer selftest FAILED"; tail -40 /tmp/cpk3_selftest.$$; }

# ---- guard 2: RULE 21 premise -- no run of this batch may exist yet ---------
grep -q '^cpk3-' "$CSVP" && guard_fail "guard 2: cpk3-* already in the CSV" \
                         || echo "guard 2: no cpk3-* name collision in the corpus"
if [ -d "$WS/runs" ]; then
  NOUT=$(ls "$WS/runs"/cpk3-*.out 2>/dev/null | wc -l | tr -d ' ')
  [ "${NOUT:-0}" = 0 ] && echo "guard 2b: no cpk3-*.out on disk" \
                       || guard_fail "guard 2b: $NOUT cpk3-*.out files already exist"
fi

# ---- guard 3: the CIFAR-100 data is actually staged on THIS account ---------
[ -d "$CIF/data/cifar-100-python" ] && echo "guard 3: cifar-100-python present under $CIF/data" \
  || guard_fail "guard 3: CIFAR-100 is not staged at $CIF/data/cifar-100-python"

# ---- guard 4c: the literal specs and the grid agree, before the model is built
mkdir -p "$SAVE"
MANIFEST="$SAVE/PARTITION-MANIFEST.txt"

SPECS=""
for K in $K_LIST; do
  eval "LIT=\${G_K$K:-}"
  WANT="[$K,$((NTENS-K))]"
  [ "$LIT" = "$WANT" ] || guard_fail "guard 4c: G_K$K is '$LIT', but the grid says '$WANT'"
  SPECS="$SPECS $LIT"
done
NK=$(echo $K_LIST | wc -w | tr -d ' ')
NA=$(echo $ARMS | wc -w | tr -d ' ')
[ "$NA" = "$((NK+1))" ] || guard_fail "guard 4c: $NA arms for $NK cut positions + 1 anchor"
# cpk3's grid is CONSECUTIVE by design -- that is the whole point, because a
# consecutive grid makes every step a SINGLE-TENSOR step.  cpk2's grid was not,
# so this check is STRONGER than cpk2's, not a relaxation of it.  It also
# requires k=49 to be STRICTLY INTERIOR, which cpk2's grid-edge criticism forces.
PREV=0; LEFT=0; RIGHT=0; HAS49=0; CONSEC=1
for K in $K_LIST; do
  [ "$K" -gt "$PREV" ] || guard_fail "guard 4c: the grid is not strictly increasing at $K"
  [ "$PREV" != 0 ] && [ "$K" != "$((PREV+1))" ] && CONSEC=0
  PREV=$K
  [ "$K" -lt 49 ] && LEFT=$((LEFT+1))
  [ "$K" -gt 49 ] && RIGHT=$((RIGHT+1))
  [ "$K" = 49 ] && HAS49=1
done
[ "$CONSEC" = 1 ] || guard_fail "guard 4c: the grid is NOT consecutive; every step must move exactly one tensor"
[ "$HAS49" = 1 ] || guard_fail "guard 4c: the incumbent argmax k=49 is not on the grid"
[ "$LEFT" -ge 1 ] && [ "$RIGHT" -ge 1 ] \
  || guard_fail "guard 4c: k=49 is not STRICTLY INTERIOR (left $LEFT, right $RIGHT)"
echo "guard 4c: $NK literal specs agree with the grid; $NA arms (1 scalar anchor);"
echo "          strictly increasing AND CONSECUTIVE, $LEFT left of k=49 and $RIGHT right of it"

# ---- guard 4: LIVE-MODEL partition manifest + the horizon's own arithmetic --
# shellcheck disable=SC2086
python3 - "$CIF" "$MANIFEST" "$NTENS" "$CLIP_C" "$EPOCHS" "$BATCH" $SPECS <<'PYEOF' \
  || guard_fail "guard 4: live partition / anchor / clamp / horizon check FAILED"
import sys, os, math, inspect, re as _re
cif, out, ntens = sys.argv[1], sys.argv[2], int(sys.argv[3])
clip_c = sys.argv[4]
epochs, bsz = int(sys.argv[5]), int(sys.argv[6])
specs = sys.argv[7:]
sys.path.insert(0, cif)
os.chdir(cif)
from build_network import build_network
from Optimizers.HF import HF
net = build_network("ResNet18_c100", "cpu")
nps = [(n, p.data.size()) for n, p in net.named_parameters()]
names = [n for n, _ in net.named_parameters()]
numel = [int(p.numel()) for _, p in net.named_parameters()]
tot = sum(numel)
T = len(nps)
lines = ["NUM_PARAM_TENSORS %d" % T, "TOTAL_PARAMS %d" % tot,
         "CLIP_C %s" % clip_c, "EPOCHS %d" % epochs]
print("guard 4: live ResNet18_c100 has %d parameter tensors, %d parameters"
      % (T, tot))
if T != ntens:
    print("!!! guard 4: the live model has %d tensors, the batch assumes %d"
          % (T, ntens))
    raise SystemExit(1)

# the structural landmarks, MEASURED on the live model (k is 1-BASED)
groups, cur = [], None
for i, (n, _) in enumerate(nps, 1):
    key = n.split(".")[0]
    if key.startswith("layer"):
        key = ".".join(n.split(".")[:2])
    if key != cur:
        groups.append([key, i, i]); cur = key
    else:
        groups[-1][2] = i
print("guard 4: named_parameters() structure (tensor numbers are 1-BASED):")
for name, lo, hi in groups:
    print("         %-12s tensors %2d..%-2d  params %9d"
          % (name, lo, hi, sum(numel[lo - 1:hi])))
print("guard 4: EVERY tensor the cpk3 cuts fall among, by name.  These are the")
print("         numbers the registered POINT PREDICTION is computed from, so")
print("         they are also written to the manifest as TENSOR lines:")
for i in range(42, 56):
    print("         %2d  %-34s %9d" % (i + 1, names[i], numel[i]))
    lines.append("TENSOR %d %s %d" % (i + 1, names[i], numel[i]))

bad = 0
seen = {}
for spec in specs:
    g = HF.polish_the_stepsize_groups(None, spec, nps)
    sizes = [len(x) for x in g]
    if sum(sizes) != T:
        print("!!! guard 4: %s does not cover the model (%d of %d)"
              % (spec, sum(sizes), T)); bad += 1; continue
    if len(g) != 2:
        print("!!! guard 4: %s composed to m=%d, but every sweep arm must be m=2"
              % (spec, len(g))); bad += 1; continue
    want = [int(x) for x in spec[1:-1].split(",")]
    if sizes != want:
        print("!!! guard 4: %s composed to sizes %s on the live model" % (spec, sizes))
        bad += 1; continue
    k = sizes[0]
    if list(g[0]) != names[:k] or list(g[-1]) != names[k:]:
        print("!!! guard 4: %s does not split named_parameters() at %d BY NAME"
              % (spec, k)); bad += 1; continue
    pc, i = [], 0
    for s in sizes:
        pc.append(sum(numel[i:i + s])); i += s
    lines.append("SPEC %s M %d SIZES %s PARAMS %s FIRSTGROUP %s LASTGROUP %s"
                 % (spec, len(g), ",".join(str(s) for s in sizes),
                    ",".join(str(s) for s in pc), " ".join(g[0]), " ".join(g[-1])))
    print("guard 4: %-9s m=2  sizes %-8s  params %9d / %-9d  share %.6f"
          % (spec, str(sizes), pc[0], pc[1], pc[0] / float(tot)))
    print("         group 1 ends at   tensor %2d  %s" % (k, g[0][-1]))
    print("         group 2 starts at tensor %2d  %s" % (k + 1, g[1][0]))
    print("         FULL first  = %s" % " ".join(g[0]))
    print("         FULL second = %s" % " ".join(g[1]))
    seen[k] = (set(g[-1]), pc[0])

ks = sorted(seen)
print("guard 4d: what moves between consecutive GRID points, on the live model.")
print("          EVERY ONE OF THESE MUST MOVE EXACTLY ONE TENSOR -- that is the")
print("          property that makes cpk3 a single-tensor decomposition:")
for a, b in zip(ks, ks[1:]):
    moved = [n for n in names if n in seen[a][0] and n not in seen[b][0]]
    dp = seen[b][1] - seen[a][1]
    print("         k=%d -> k=%d moves %d tensor(s) %-34s %8d params"
          % (a, b, len(moved), " ".join(moved), dp))
    if len(moved) != (b - a):
        print("!!! guard 4d: k=%d -> k=%d should move %d tensors, moved %d"
              % (a, b, b - a, len(moved))); bad += 1
    if len(moved) != 1:
        print("!!! guard 4d: cpk3 requires EVERY step to move exactly 1 tensor")
        bad += 1
    lines.append("STEP %d %d MOVED %s PARAMS %d" % (a, b, " ".join(moved), dp))

# guard 4g: the scalar ANCHOR is routed by exact string match in init_meta and
# never reaches polish_the_stepsize_groups.  It is a DIFFERENT CODE PATH from
# every sweep arm, which is a disclosed confound, so it is PROVEN on the live
# source rather than assumed.
src = inspect.getsource(HF.init_meta)
mm = _re.search(r"stepsize_groups\s+in\s+\[([^\]]*)\]", src)
if not mm:
    print("!!! guard 4g: could not find init_meta's exact-match routing list")
    bad += 1
else:
    named = [x.strip().strip("'\"") for x in mm.group(1).split(",")]
    print("guard 4g: init_meta routes these names away from blockwise: %s" % named)
    if "scalar" in named:
        print("guard 4g: the anchor `scalar` takes its OWN m=1 code path "
              "(DISCLOSED confound; it is a FLOOR reference, not a rung)")
        lines.append("ANCHOR scalar NAMED_PATH 1")
    else:
        print("!!! guard 4g: `scalar` is NOT in init_meta's named list")
        bad += 1
    for spec in specs:
        if spec in named:
            print("!!! guard 4g: sweep spec %s collides with a named granularity" % spec)
            bad += 1

# guard 4e: the CLAMP on the live source, and the horizon's own arithmetic.
src_init = inspect.getsource(HF.__init__)
if "BETA_CLIP" in src_init and "_beta_lo" in src_init and "split(':')" in src_init.replace('"', "'"):
    print("guard 4e: BETA_CLIP is parsed from the environment into "
          "(_beta_lo, _beta_hi) on the live source")
else:
    print("!!! guard 4e: the live HF.__init__ does not parse BETA_CLIP as assumed")
    bad += 1
src_step, _m = "", None
for _m in ("step", "update", "__call__"):
    if hasattr(HF, _m):
        _s = inspect.getsource(getattr(HF, _m))
        if "_beta_lo" in _s:
            src_step = _s
            break
if "clamp(self._beta_lo,self._beta_hi)" in "".join(src_step.split()):
    print("guard 4e: the clamp is applied to beta AFTER the meta update, in HF.%s" % _m)
else:
    print("!!! guard 4e: could not find beta.clamp(_beta_lo, _beta_hi) in the live update path")
    bad += 1
src_lion = inspect.getsource(HF.Lion_meta_update)
if "torch.sign" in src_lion and "meta_stepsize" in src_lion:
    steps = epochs * (50000 // bsz)
    lo = -13.815511 - 1e-3 * steps
    uf = math.log(1.401298464324817e-45)
    print("guard 4e: |dbeta| <= 1e-3 per meta-step; %d epochs = %d meta-steps,"
          % (epochs, steps))
    print("          worst-case reachable beta %.6f; float32 alpha underflows"
          % lo)
    print("          to EXACTLY 0 below %.6f, so no clamp-free arm exists at" % uf)
    print("          this horizon.  The standard floor %s is kept: alpha at the"
          % clip_c.split(":")[0])
    print("          floor is exp(-15) = %.4e, a normal float32." % math.exp(-15.0))
    lines.append("META_STEPS %d REACHABLE_MIN %.6f F32_UNDERFLOW_BETA %.6f"
                 % (steps, lo, uf))
    if not (lo < -80.0 and lo < uf):
        print("!!! guard 4e: the horizon arithmetic does not hold as registered")
        bad += 1
else:
    print("!!! guard 4e: Lion_meta_update is not the sign-bounded update assumed")
    bad += 1

# guard 4f: THE LOAD-BEARING CLAIM for the free in-run 100-epoch control.
tp = os.path.join(cif, "train.py")
src = open(tp).read().split("\n")
hits = [(i + 1, l.strip()) for i, l in enumerate(src)
        if "num_epochs" in l or "num-epochs" in l]
print("guard 4f: every occurrence of num_epochs in the LIVE %s:" % tp)
for ln, txt in hits:
    print("          %4d  %s" % (ln, txt))
decl = [h for h in hits if "add_argument" in h[1]]
loop = [h for h in hits if h[1].startswith("for epoch in range(")]
other = [h for h in hits if h not in decl and h not in loop]
if len(hits) == 2 and len(decl) == 1 and len(loop) == 1 and not other:
    print("          OK -- argparse declaration + loop bound ONLY.  The epoch-99")
    print("          readout of a %d-epoch run IS a 100-epoch run of the same" % epochs)
    print("          configuration, so the control is in batch and in run.")
    lines.append("NUM_EPOCHS_USES 2 DECL %d LOOP %d" % (decl[0][0], loop[0][0]))
else:
    print("!!! guard 4f: num_epochs is used somewhere other than the loop bound;")
    print("    the free in-batch 100-epoch control is NOT valid.  %d other uses."
          % len(other))
    bad += 1
sched = [(i + 1, l.strip()) for i, l in enumerate(src)
         if "scheduler" in l.lower() or "lr_scheduler" in l]
if sched:
    print("!!! guard 4f: train.py mentions a scheduler; check it is not epoch-keyed:")
    for ln, txt in sched:
        print("          %4d  %s" % (ln, txt))

if bad:
    raise SystemExit(1)
open(out, "w").write("\n".join(lines) + "\n")
print("guard 4: %d cut specs + 1 anchor verified; PARTITION-MANIFEST.txt -> %s"
      % (len(specs), out))
PYEOF
[ -s "$MANIFEST" ] && echo "guard 4b: manifest is non-empty" || guard_fail "guard 4b: no manifest"

# ---- guard 5: capacity, AND the walltime/partition arithmetic ---------------
FREE=$(df -BG "$WS" 2>/dev/null | tail -1 | awk '{print $4}' | tr -d 'G')
PEND=$(squeue -h -u "$USER_NAME" -t PENDING 2>/dev/null | wc -l | tr -d ' ')
echo "guard 5: ${FREE:-?} GB free on \$WS; $PEND jobs pending, adding 21"
[ "${PEND:-0}" -le 40 ] || guard_fail "guard 5: $PEND pending, over cap"
for P in $(echo "$PARTS" | tr ',' ' '); do
  TL=$(sinfo -h -p "$P" -o '%l' 2>/dev/null | head -1)
  R=$(squeue -h -p "$P" -t RUNNING 2>/dev/null | wc -l | tr -d ' ')
  D=$(squeue -h -p "$P" -t PENDING 2>/dev/null | wc -l | tr -d ' ')
  LONG=$(squeue -h -p "$P" -t RUNNING -o '%l' 2>/dev/null | grep -c -- '-' || true)
  echo "guard 5b: $P timelimit $TL   running $R (of which $LONG are multi-day)   pending $D"
  case "$TL" in
    *-*) : ;;   # a d-hh:mm:ss limit is necessarily above 11 h
    *) guard_fail "guard 5b: $P has a sub-day time limit ($TL) and cannot take $WALL" ;;
  esac
done

[ "$FAIL" = 1 ] && { echo "!!! SUBMIT ABORTED -- nothing submitted."; exit 2; }

# ---- compose, guard each line under RULE 20, then submit --------------------
. "$REPO/bin/_lib_guards.sh"
DESIGN=(alg-base=SGDm alg-meta=Lion meta-stepsize=$MST alpha0=$ALPHA0 \
        num-epochs=$EPOCHS batch-size=$BATCH gamma=$GAMMA dataset=$DSET NN-name=$NET)

N=0; REJ=0; BAD=0
for S in $SEEDS; do
  for ARM in $ARMS; do
    case $ARM in
      k01) G=scalar ;;
      k45) G=$G_K45 ;;
      k46) G=$G_K46 ;;
      k47) G=$G_K47 ;;
      k48) G=$G_K48 ;;
      k49) G=$G_K49 ;;
      k50) G=$G_K50 ;;
      *)   echo "!!! unknown arm $ARM"; exit 2 ;;
    esac
    # NOTE the single quotes around $G: "[50,12]" is a bash bracket GLOB.
    CMD="sbatch --job-name=cpk3-$ARM-s$S --partition=$PARTS --gres=gpu:1 --cpus-per-task=6 \
--mem=16G --time=$WALL --export=ALL,AUGMENT=$AUG,BETA_CLIP=$CLIP_C,HIER=none,SCHED=none,PROBE=0 \
$RUNNER --optimizer HF --alg-base SGDm --momentum-param-base 0.99 \
--weight-decay-base 0.1 --alg-meta Lion --momentum-param-meta 0.99 --Lion-beta2-meta 0.9 \
--weight-decay-meta 0 --dataset $DSET --NN-name $NET --batch-size $BATCH --max-time 999:00:00 \
--gamma $GAMMA --meta-stepsize $MST --alpha0 $ALPHA0 --num-epochs $EPOCHS \
--stepsize-groups '$G' --seed $S --save-directory $SAVE --run-name cpk3-$ARM-s$S"
    if guard_presubmit "$CMD" "${DESIGN[@]}" >/dev/null 2>&1; then :; else
      echo "!!! RULE 20 PRE-CHECK FAILED for cpk3-$ARM-s$S"
      guard_presubmit "$CMD" "${DESIGN[@]}"; BAD=$((BAD+1))
    fi
    if [ "$SUBMIT" = 1 ]; then eval "$CMD" >/dev/null 2>&1 && N=$((N+1)) || REJ=$((REJ+1))
    else echo "$CMD"; echo; N=$((N+1)); fi
  done
done
echo "guard 6: $N composed command lines, $BAD failed the RULE 20 pre-check"
[ "$BAD" = 0 ] || { echo "!!! composed lines are malformed"; exit 2; }
echo "---- $N jobs ($( [ "$SUBMIT" = 1 ] && echo 'ACCEPTED BY SLURM' || echo 'dry run, nothing submitted' )); $REJ rejected ----"

if [ "$SUBMIT" = 1 ]; then
  grep -qx 'cpk3-' "$REPO/bin/PROTECTED.txt" 2>/dev/null || echo "cpk3-" >> "$REPO/bin/PROTECTED.txt"
  echo "---- cpk3- present in bin/PROTECTED.txt ----"
  # jobs/run_cifar.sh hard-codes #SBATCH --output=$WS/runs/%x-%j.out, so the
  # .out files land in $WS/runs, NOT in --save-directory.
  guard_postlaunch "$WS/runs" "cpk3-" "${DESIGN[@]}"; RC=$?
  case $RC in
    0) echo "guard 7: RULE 20 post-launch check PASSED against a run's own ARGS line" ;;
    2) echo "guard 7: UNVERIFIED -- no cpk3 job started inside the window.  This is NOT"
       echo "         a mismatch.  Re-check once one starts with:"
       echo "         python3 $REPO/analysis/argsline_guard.py $WS/runs --name cpk3-" ;;
    *) echo "!!! guard 7: RULE 20 MISMATCH -- scancel THIS batch only:"
       echo "    squeue -h -u $USER_NAME -o '%i %j' | awk '\$2 ~ /^cpk3-/ {print \$1}' | xargs -r scancel" ;;
  esac
fi
