#!/bin/bash
# =============================================================================
# Cycle 54 -- THE AdamW RE-RUN AT A RAISED CEILING.  Does the nodewise minimum
# survive a different base optimizer?
# cluster_a.  12 jobs.  Tag `bo7-*`.
#
# THIS BATCH IS NOT A NEW IDEA.  It is the re-run `bo6`'s OWN registration
# prescribed, in its own words:
#
#     "(V0.3) ... If an arm binds, report first_hi and its epoch; that arm's V1
#      is UNINTERPRETABLE, and the batch is **re-run at a raised ceiling** rather
#      than reported."
#
# WHAT HAPPENED, and why the re-run is mandatory rather than optional.
#   `bo6-*` (AdamW base, Lion meta, BETA_CLIP=-30:0.0, 20 ep, n=2) landed this
#   tick.  V0 PASSED (n_beta byte-matched 6/6) and V0.4 PASSED (plateau 82.0-82.8,
#   trains fine).  **V0.3 FAILED on 2 of the 3 rungs, per seed:**
#
#       arm                 %rec at HI   %Q4 at HI   first_hi   epoch   box-free?
#       probe_lay_adw_s0/s1     0.00        0.00         -        -       yes 2/2
#       probe_node_adw_s0      19.85       79.40      1603      16.0      NO
#       probe_node_adw_s1       8.80       35.20      1824      18.2      NO
#       probe_w_adw_s0         23.45       93.80      1531      15.3      NO
#       probe_w_adw_s1         17.50       70.00      1650      16.5      NO
#
#   AdamW normalises its update, so alpha means something different and the beta
#   trajectory had no reason to match the SGDm arm's -- exactly the risk V0.3 was
#   written to catch, and it caught it.
#
#   `c54_score.py` nonetheless printed **"V2 REFUTED (argmin = w) ... the
#   Adam-mini sentence must be DELETED, not hedged."**  That verdict is NOT
#   ADOPTED, because V2's argmin is computed from the `node` and `w` rungs -- the
#   two that failed the gate -- while `lay`, the only rung that never binds, is the
#   one V2 calls the maximum.  The scorer applied the gate to V1 (which it marked
#   UNINTERPRETABLE) and not to V2, which is the FOURTH time this campaign a
#   summary statistic has been read past its own uncertainty flag (CORRECTIONS 75:
#   `s` in 51, the pooled clip fraction in 62, the argmin in 74, this).
#   **V2 is recorded UNINTERPRETABLE, not REFUTED.**  The scorer is fixed.
#
# THE POST-HOC DIAGNOSTIC THAT SIZES THIS BATCH, LABELLED AS POST-HOC.
#   The earliest bind anywhere in bo6 is record 1531, so records 1000-1500 are
#   box-free on ALL SIX arms and lie inside the steady half.  On that window
#   (`neff_instrument.py --window 0.5-0.75`):
#
#       rung    steady half (contaminated)    records 1000-1500 (box-free)   delta
#       lay              0.4290                        0.4097              -0.019
#       node             0.1199                        0.1183              -0.002
#       w                0.0200                        0.0182              -0.002
#
#   The ordering `w < node < lay` is IDENTICAL and the gap between the two
#   smallest is 0.100 against a 0.02 undecided bar.  So the binding does not
#   appear to have manufactured the ordering.
#   **THIS EARNS A GATE, NOT A PRESUMPTION** (STANDING RULE 7 COROLLARY).  It is
#   why the re-run is expected to confirm rather than overturn, and it is why W1
#   below is **LABELLED NOT INDEPENDENT** -- registering "argmin = w" after
#   computing it post-hoc makes a confirmation a REPLICATION, exactly as br6's C1
#   was labelled.  It is NOT a reason to skip the re-run: cycle 53 established
#   (CORRECTIONS 76(1)) that overturning a registered gate with a post-hoc rescue
#   is the move the gate exists to prevent, and that rule is symmetric -- it
#   applies to a post-hoc rescue that strengthens a REFUTATION just as much as one
#   that rescues a confirmation.
#
# WHAT IS AT STAKE.  CORRECTIONS 70 called the nodewise minimum "the most
# paper-relevant thing since the sign-agreement measurement":
#     "the Adam-mini / Adalayer / SGG line places its blocks at nodewise-or-coarser
#      on the premise that within-block averaging recovers independent information,
#      and at the operating point our headline is quoted at, that is the worst
#      available partition."
# It already carries THREE scopes (ms=1e-3; 20 epochs, from C2.5 this tick; and
# SGDm).  This batch decides the third.  Adam-mini and Adalayer partition an
# **Adam** second moment; if the nodewise minimum is an SGDm phenomenon the
# sentence must be DELETED, not hedged.  Until this batch scores, the sentence is
# **SUSPENDED**: it may not be written, and it may not be deleted either.
#
# WHAT THIS BATCH IS NOT.  Not a performance comparison.  ms and alpha0 are carried
# over from the SGDm ladder unchanged and are UNTUNED for AdamW, so no plateau here
# may be quoted against an SGDm plateau.  W0.4 is a trains-at-all gate, nothing more.
#
# THE DESIGN.  Byte-identical to `bo6-*` except BETA_CLIP:
#   R18/CIFAR-10, **AdamW** base (--normalizer-param-base 0.999,
#   --momentum-param-base 0.9, --weight-decay-base 0.1 -- 0.9 is AdamW's beta1 and
#   is DIFFERENT from the SGDm arm's 0.99 heavy-ball coefficient on purpose; they
#   share a flag name and are not the same parameter), Lion meta, ms=1e-3,
#   alpha0=1e-3, AUGMENT=1, 20 epochs, rungs w/node/lay, **HI in {2.0, 6.0}**,
#   LO fixed at -30, seeds 0-1.  3 x 2 x 2 = 12 jobs.
#
# WHY TWO CEILINGS AND NOT ONE RAISED CEILING.  bo6 pinned at exactly 0.000, so the
# unclipped trajectory is UNOBSERVABLE from it -- a clipped trajectory cannot tell
# you where it would have gone, which is the whole reason a single "raised enough"
# ceiling cannot be justified from bo6's own data.  Two ceilings MEASURE the
# box-dependence instead of assuming it, and if both are box-free and agree, the
# argmin is decided on a licence this campaign has verified rather than assumed
# (br6 vs bl5 at 40 ep agree to 0.0009 lay / 0.0022 node across a 2.0-log-unit
# ceiling change, both box-free).
#
# PRE-REGISTERED PREDICTIONS -- score against these, not against what lands.
#
#   (W0) VALIDITY.  n_records == 2000; n_beta byte-matches the SGDm ladder
#        (w 11,173,962 / node 14,420 / lay 62 -- the partition is a property of the
#        NETWORK); beta MOVED, 12/12.  A mismatch VOIDS the batch.
#
#   (W0.3) THE BOX-FREE GATE, SCORED FIRST, PER SEED, PER CEILING (STANDING RULE 8).
#        < 5% of records at either guard on EVERY seed, from beta_true_min/max AND
#        PATCH_CLIPCOUNT's per-coordinate counts.
#        With bo6's binds at epochs 15.3-18.2 under HI=0.0, this builds a
#        THREE-point curve of bind-epoch against ceiling if the +2.0 rung also
#        binds.  A bound arm's W1/W2 are UNINTERPRETABLE AT THAT CEILING; the +6.0
#        arm may still carry them.
#        **IF BOTH CEILINGS BIND ON node AND w**, the honest conclusion is that
#        AdamW-base beta is not confinable at this ms and the NEXT batch is an ms
#        ladder for AdamW, not a third ceiling.  Say that; do not report a number.
#
#   (W0.4) THE TRAINS-AT-ALL GATE, SCORED SECOND.  plateau > 40.0 and `collapsed`
#        false, per seed.  bo6 gave 82.0-82.8 at HI=0.0.  HI=+6.0 permits alpha up
#        to e^6 = 403 on a NORMALISED update, which is the arm most likely to
#        diverge in this batch.  A failure voids that arm and says the ceiling
#        ladder must go DOWN; it does NOT refute W1.
#
#   (W0.5) CEILING-INVARIANCE.  On any rung where BOTH ceilings are box-free,
#        |N_eff/m(+2.0) - N_eff/m(+6.0)| <= 0.06 (the nodewise per-rung bar, the
#        loosest of the two rungs that matter here; see c54_budget_curve.sh for the
#        measured per-rung sds).  FAIL -> N_eff/m depends on the box even where the
#        box never binds, which is a bigger result than this batch's own question
#        and must be reported as one rather than patched.
#
#   (W1) THE PRIMARY TEST -- THE ARGMIN.  argmin of N_eff/m over {lay, node, w},
#        VARIANCE instrument, STEADY half, on box-free arms only.
#        SGDm control (cl5 cU, n=3): lay 0.7258 / node 0.4016 / w 0.5045,
#        argmin **node**, gap 0.103 -- decided.
#        **PREDICTION: argmin = `w`, gap > 0.02.  LABELLED NOT INDEPENDENT** -- it
#        was computed post-hoc on bo6's box-free window (see above), so a
#        confirmation is a REPLICATION and must be written as one, never as a
#        discovery.
#          -> the nodewise minimum is an SGDm phenomenon.  CORRECTIONS 70 gains a
#             base-optimizer scope on top of its ms and budget scopes, and the
#             Adam-mini sentence is **DELETED, not hedged**.
#        REFUTATION: argmin = `node` with gap > 0.02.
#          -> bo6's ordering WAS the box, the post-hoc window misled, and
#             CORRECTIONS 70 transfers into the Adam family after all.  This is the
#             branch that matters most and is why the batch is worth 12 jobs: it is
#             the only way the Adam-mini sentence can be SAVED.
#        UNDECIDED: gap <= 0.02 between the two smallest -> say UNDECIDED and buy a
#             third seed (the ns5 -> ns6 pattern, CORRECTIONS 73).
#        If the layerwise rung is unresolved, the argmin is UNDECIDABLE for that arm
#        rather than defaulting to one of the other two.  Say which.
#
#   (W2) THE HEADLINE RANGE UNDER AdamW.  N_eff/m, weightwise, against the
#        published BOX-FREE 4-family range **[0.1571, 0.5474]** (CORRECTIONS 68,
#        RAW endpoints; the text rounds them to 15.7%-54.7% and 0.5474 falls
#        outside 0.547).
#        PASS: lands INSIDE -> the retained fraction is a property of the network
#              and task, and CORRECTIONS 59 needs no base-optimizer caveat.
#        REFUTATION: lands OUTSIDE -> the 16%-55% range is SGDm-specific and every
#              quotation needs a base-optimizer column, on top of the budget column
#              CORRECTIONS 73 already forced.
#        **NO DIRECTION IS REGISTERED**, deliberately and for the same reason bo6's
#        V1 registered none: there is no mechanism that predicts one, and inventing
#        one to collect a confirmation is the uc5 failure mode (CORRECTIONS 68).
#        The post-hoc bo6 window reads 0.0182, far below the range -- that is
#        recorded here so it cannot be presented later as a prediction, and it is
#        explicitly NOT registered as one.
#
#   (W3) ACCURACY, reported regardless and NOT a test.  See "WHAT THIS BATCH IS NOT".
#
#   RESOLUTION, per CORRECTIONS 33, computed BEFORE submission.  rho_min depends on
#   T and m, not on the base update, so the cl5/bo6 floors carry over; all six bo6
#   arms read resolved=True at T=2000:
#       weightwise  ~8.5e-09   RESOLVES
#       nodewise    ~7.0e-06   RESOLVES
#       layerwise   ~1.5e-03   MARGINAL at m=62 -- see W1's last clause.
#
# NOT INCLUDED, deliberately:
#   * An Adam META optimizer.  One axis at a time; the meta is held at Lion so a
#     W1/W2 failure is attributable to the base.  Adam-meta is the obvious next
#     batch and is NOT funded until this one scores.
#   * An ms ladder for AdamW.  That is the contingency W0.3 names if BOTH ceilings
#     bind; guessing a second ms now spends jobs on a contingency that has not
#     happened.
#   * A third seed.  n=2 per (rung, ceiling) buys the argmin against a control gap
#     of 0.103; the UNDECIDED branch says what to do if it comes back small.
#   * Other families.  R18 is where every control on this axis lives.
#
# WHY cluster_a.  bo6 is on cluster_a, so its probe root and comparators are local, and
# cluster_b is carrying `bd7-*` (12 jobs).  The cross-account comparison to `cl5-*`
# on cluster_b is via N_eff/m computed by a shared selftested instrument on probe
# files, not via raw accuracy, and both accounts' HF.py are byte-identical after
# PATCH_CLIPCOUNT (CORRECTIONS 63).  **If W0's n_beta byte-match fails, that
# assumption is wrong and the batch is VOID** -- the condition ns5 and bo6 both
# carried for the same reason.
#
# STRUCTURAL CHECKS BEFORE USING ANY NUMBER (Rule 4)
#   1. W0, W0.3, W0.4 above, run not assumed, W0.3 FIRST and PER SEED
#   2. python3 analysis/c54_score.py --selftest        (13/13 after this tick's fix)
#   3. python3 analysis/neff_instrument.py --selftest  (23/23)
#   4. python3 analysis/probe5_window.py --selftest    (41/41)
#   5. Window scan on every arm.
#
# USAGE
#   bash c54_adamw_ceiling.sh            # dry run: prints every sbatch line
#   bash c54_adamw_ceiling.sh --submit   # submits, ONLY if the guards pass
# =============================================================================
set -u

WS=/cluster/account_a/metaopt                   # cluster_a
RUNNER=$WS/jobs/run_cifar.sh
HF=$WS/MetaOptimize/codes/Supervised_tasks/MetaOptimize/cifar10/Optimizers/HF.py
SAVE=$WS/runs/bo7
PARTS=gpu-short,gpu-l4-24g,gpu-2080ti-11g,gpu-mig-40g,gpu-a100-80g
USER_NAME=account_a
PEND_CAP=40
NJOBS=12
EPOCHS=20
SUBMIT=0
[ "${1:-}" = "--submit" ] && SUBMIT=1

echo "=== c54 AdamW CEILING LADDER -- the re-run bo6's V0.3 prescribed (cluster_a) ==="
echo "    epochs=$EPOCHS  HI in {2.0, 6.0}  seeds 0-1  control = cl5-*-cU-* (SGDm, argmin node)"

for P in PATCH_PROBE5 PATCH_PROBE5_FIX PATCH_CLIPCOUNT; do
  grep -q "$P" "$HF" 2>/dev/null || { echo "GUARD FAIL: $P not present in $HF"; exit 1; }
done
echo "guard 1: PATCH_PROBE5 + PATCH_PROBE5_FIX + PATCH_CLIPCOUNT present  OK"

python3 -c "import py_compile; py_compile.compile('$HF', doraise=True)" 2>/dev/null || {
  echo "GUARD FAIL: $HF does not compile"; exit 1; }
echo "guard 2: HF.py compiles  OK"

# GUARD 3 -- "byte-identical to bo6 except BETA_CLIP" is a CLAIM and is DIFFED
# against bo6 itself, never asserted (the uc5 lesson, CORRECTIONS 71).
BO6=$(dirname "$0")/c53_base_optimizer.sh
if [ -r "$BO6" ]; then
  for f in "ResNet18" "CIFAR10" "AdamW" "Lion" "--meta-stepsize 1e-3" "--alpha0 1e-3" \
           "--normalizer-param-base 0.999" "--momentum-param-base 0.9" "--batch-size 100"; do
    grep -q -- "$f" "$BO6" || { echo "GUARD FAIL: '$f' absent from the bo6 control"; exit 1; }
  done
  grep -q -- 'EPOCHS=20' "$BO6" || {
    echo "GUARD FAIL: bo6 is not a 20-epoch batch -- this is not a matched re-run"; exit 1; }
  grep -q -- 'BOX=-30:0.0' "$BO6" || {
    echo "GUARD FAIL: bo6's box is not -30:0.0 -- the ceiling contrast is not what it claims"; exit 1; }
  echo "guard 3: bo6 control is R18/CIFAR10/AdamW/Lion/ms=1e-3 at 20 epochs, BOX=-30:0.0  OK"
else
  echo "GUARD FAIL: c53_base_optimizer.sh not readable -- cannot diff the claim"; exit 1
fi

# GUARD 4 -- both ceilings must be strictly above the MEASURED pin, or this batch
# is a rerun of bo6 under a different name.  bo6 pinned at exactly 0.000.
python3 - <<'PYEOF' || exit 1
ceilings = (2.0, 6.0)
pinned_at = 0.0     # bo6 probe_w_adw_s0/s1 and probe_node_adw_s0/s1: beta_true_max == 0.000
assert all(c > pinned_at for c in ceilings), "a ceiling is not above the measured pin"
assert ceilings[1] > ceilings[0], "the ladder is not ordered"
print(f"guard 4: ceilings {ceilings[0]:+.1f} / {ceilings[1]:+.1f} are "
      f"{ceilings[0] - pinned_at:.1f} / {ceilings[1] - pinned_at:.1f} log units above the "
      f"MEASURED pin {pinned_at:+.1f}  OK")
PYEOF

FS=$(sshare -U -u "$USER_NAME" -n -o FairShare 2>/dev/null | tr -d ' ' | head -1)
PEND=$(squeue -h -u "$USER_NAME" -t PENDING 2>/dev/null | wc -l | tr -d ' ')
echo "guard 5: FairShare=${FS:-unknown} (informational), pending=$PEND, adding $NJOBS"
if [ "$SUBMIT" = "1" ]; then
  [ "$((PEND + NJOBS))" -le "$PEND_CAP" ] || {
    echo "ABORT: $PEND pending + $NJOBS would exceed the $PEND_CAP cap"; exit 1; }
fi

mkdir -p "$SAVE"
N=0
FAIL=0
for G in layerwise nodewise weightwise; do
  case $G in
    layerwise)  TAG=lay  ;;
    nodewise)   TAG=node ;;
    weightwise) TAG=w    ;;
  esac
  for C in 2.0 6.0; do
    case $C in
      2.0) CTAG=c2 ;;
      6.0) CTAG=c6 ;;
    esac
    BOX="-30:$C"
    for S in 0 1; do
      RN="bo7-${TAG}-${CTAG}-s${S}"
      PD="$SAVE/probe_${TAG}_${CTAG}_s${S}"
      # --time=03:50:00: gpu-short caps below 5h and rejects the WHOLE batch with
      # "Requested time limit is invalid" (CORRECTIONS 71).  bo6's 20-epoch AdamW
      # runs took well under 20 min, so this is a >10x margin.
      CMD=(sbatch --job-name="$RN" --partition="$PARTS" --time=03:50:00
        --export="ALL,AUGMENT=1,BETA_CLIP=$BOX,PROBE=5,PROBE5=1,PROBE5_WRITE_EVERY=500,PROBE_DIR=$PD"
        "$RUNNER"
        --optimizer HF --alg-base AdamW --normalizer-param-base 0.999
        --momentum-param-base 0.9 --weight-decay-base 0.1
        --alg-meta Lion --momentum-param-meta 0.99 --Lion-beta2-meta 0.9 --weight-decay-meta 0
        --dataset CIFAR10 --NN-name ResNet18 --batch-size 100
        --max-time 999:00:00 --gamma 1 --meta-stepsize 1e-3 --alpha0 1e-3
        --num-epochs "$EPOCHS" --stepsize-groups "$G" --seed "$S"
        --save-directory "$SAVE" --run-name "$RN")
      # COUNT WHAT SLURM ACCEPTED, NOT WHAT WE TRIED (CORRECTIONS 71).
      if [ "$SUBMIT" = "1" ]; then
        if "${CMD[@]}" >/dev/null; then N=$((N+1)); else FAIL=$((FAIL+1)); fi
      else
        N=$((N+1)); printf '%s\n' "${CMD[*]}"
      fi
    done
  done
done
echo "---- $N jobs ($( [ "$SUBMIT" = 1 ] && echo ACCEPTED BY SLURM || echo 'dry run, nothing submitted' )); $FAIL rejected ----"
[ "$FAIL" -gt 0 ] && echo "!!! $FAIL sbatch calls FAILED -- do not treat this batch as submitted"
echo "reduce with, IN THIS ORDER:"
echo "  1. W0.3 PER SEED PER CEILING -- the box-free gate, on ../probes_bo7"
echo "  2. W0.4 stability, then W0.5 CEILING-INVARIANCE (pool only if it passes)"
echo "  3. W1  THE ARGMIN -- box-free arms only.  LABELLED NOT INDEPENDENT."
echo "  4. W2  neff_instrument.py ../probes_bo7   # vs [0.1571, 0.5474], NO direction registered"
echo "  5. Window scan: probe5_window.py ../probes_bo7"
