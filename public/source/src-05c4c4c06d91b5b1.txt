#!/usr/bin/env python3
"""c97_bm2_score.py -- score `bm2`.  IS THE BASE-OPTIMISER MODERATOR REPLICATED
AT SGD AND AT RMSProp, OR DOES EACH LEVEL REST ON ONE SUBMISSION?

REGISTERED GATES, transcribed from `bin/c97_basemod_replicate.sh`.  Every constant
below is asserted by the selftest against THAT SCRIPT'S OWN TEXT so the registration
and the batch cannot drift -- STANDING RULE 19.

WRITTEN, SELFTESTED AND REGISTERED WHILE **NO `bm2` RUN EXISTED ANYWHERE** -- not in
`results/all_runs.csv`, not on either cluster, and not in either queue.  Not merely
before the verdict was read: before the data could exist.  STANDING RULE 21.

WHY THIS BATCH EXISTS.  The cycle-98 review's blocking item #2 is that the paper's
NEW headline -- "the base optimiser accounts for ~75% of the total heterogeneity Q"
(between-base Q 32.1/3 of a total Q 43.01/11) -- rests, at two of its four levels, on
a SINGLE SUBMISSION.  `nl1` (bin/c92_norm_ladder.sh) is one sbatch loop that produced
both the SGD rungs and the RMSProp rungs; `sm3` accidentally replicated AdamW for free
(it ran Lion, so it is an independent replicate of `aw1`); and the GroupNorm cell
(`gn1`) is VOID at its own registered scorer.  So SGD and RMSProp are the flank.
The METHODS result the paper itself publishes -- BATCH is a large random effect,
F(62,85) = 5.47, p 6.9e-13, while SEED is null, F 1.21, p 0.213 -- is precisely the
reason a one-batch moderator level is not yet a moderator level.

THE BATCH.  ONE submission, FOUR arms, 3 FRESH seeds each, 12 jobs:
    sgd-node   SGD      nodewise   m = 14,420   |   sgd-ch   SGD      chunk777  m = 14,421
    rms-node   RMSProp  nodewise   m = 14,420   |   rms-ch   RMSProp  chunk777  m = 14,421
Everything else is `nl1`'s cell, read off `nl1`'s OWN ARGS line rather than off any
script header (STANDING RULE 20): ResNet18 / CIFAR10 / batch 100 / 100 epochs /
meta = Lion (momentum 0.99, Lion-beta2 0.9, weight-decay 0) / meta-stepsize 1e-4 /
alpha0 1e-3 / gamma 1 / AUGMENT=1 / BETA_CLIP=-15:-2.3026 / weight-decay-base 0.1,
plus --normalizer-param-base 0.999 on the RMSProp arms only.

INDEPENDENCE IS BOUGHT TWO WAYS, and both are needed.  (i) A SEPARATE SUBMISSION, so
the batch random effect is resampled -- that is the whole point.  (ii) FRESH SEEDS
3, 4, 5; `nl1` used 0, 1, 2.  `ml2` is the cautionary case: after argparse's last-wins
its two halves shared their seeds AND their command line, so what looked like two
independent 3v3 measurements was one measurement rerun.  Guard 5 of the script asserts
that no seed of 3/4/5 exists at this cell, before anything is submitted.

  R0    **VALIDITY, EVALUATED FIRST, PER RUN.**
        R0.1  epochs_done == epochs_requested == 100.
        R0.2  collapsed == 0 (aggregate.py:182 verbatim).
        R0.3  final_test > 60.0 AND plateau5 >= 85.0.
        R0.4  NO LATE BLOW-UP: best_test - plateau5 <= 2.0 pp.
        R0.5  BOX OCCUPANCY IN BOTH DIRECTIONS (RULE 13): rec_lo <= 0.05 AND
              rec_hi <= 0.05, from per-record rails, MEASURED ON THIS BATCH'S OWN
              probes and NEVER inherited from `nl1`.  Not the 62-element beta
              summary -- HOUSE RULE.
        FIRING: an arm failing R0.1-R0.4 on >= 2 of its 3 seeds is VOID; an arm
        failing R0.5 is UNINTERPRETABLE (RULE 5) and drops.  If EITHER arm of a base
        is void or dropped, THAT BASE'S D IS NOT READ.  Both bases lost => the batch
        is VOID and nothing below is printed as a result.

  R1    **THE PRIMARY, TWICE, BOTH WITHIN THIS BATCH.**
        D'_SGD = plateau5(sgd-ch) - plateau5(sgd-node),  Welch 3v3.
        D'_RMS = plateau5(rms-ch) - plateau5(rms-node),  Welch 3v3.
        Each is scored on the SAME three-way band, fixed before the data:
          REPLICATES            D' >= +0.30 AND t >= 2.0
          FAILS TO REPLICATE    D' <= +0.15 AND se <= 0.15
          UNDECIDED             everything else
        **THE POWER STATEMENT, REGISTERED IN ADVANCE, BECAUSE THE REVIEW KILLED A
        HEADLINE FOR NOT HAVING ONE.**  Planning se(D') = SIGMA*sqrt(2/3) = 0.194,
        where SIGMA = 0.2372 is the pooled within-arm sd of plateau5 over `nl1`'s
        four node/ch arms (8 df), re-derived from results/all_runs.csv at write time.
        Against `nl1`'s D of ~1.0 that is t ~ 5.3: the batch is amply powered to
        CONFIRM the effect.  It is NOT powered to establish a null -- the powered-null
        branch needs se <= 0.15 < 0.194, so on the planning noise THAT BRANCH IS
        UNREACHABLE and a small D' will read UNDECIDED.  This is stated here, before
        the data, so that a small D' can never be written as "the effect is absent
        under this base".  MDE at 80% power = 2.80 * 0.194 = 0.54 pp.

  R1b   **THE REPLICATION BAND** (`cc1`'s C2, transcribed unchanged).  Per base,
        |D' - D_nl1| <= 0.50 -> AGREES WITH nl1 WITHIN THE UNMODELLED CROSS-BATCH
        OFFSET (CORRECTIONS 106.3).  Larger -> the two batches disagree at this base,
        which is itself the reportable result and is NOT to be resolved by pooling.
        D_nl1, re-derived at write time from results/all_runs.csv, plateau5, 3v3:
            SGD      +1.0353 +- 0.1085   (t 9.54)
            RMSProp  +0.9733 +- 0.2515   (t 3.87)

  R2    **THE DELIVERABLE FOR SECTION 4.4: THE TWO-BATCH MODERATOR LEVEL.**
        Per base, inverse-variance pool of (nl1, bm2) and the between-batch
        Cochran Q on 2 studies, 1 df.
          Q <= 3.841  -> the level is REPLICATED; the pooled D may be quoted as that
                         base's moderator level, with its two-batch se.
          Q >  3.841  -> the level is HETEROGENEOUS ACROSS BATCHES at p < 0.05.  The
                         base-level D is then NOT a stable quantity, the pooled point
                         estimate MAY NOT be quoted as if it were, and section 4.4's
                         between-base Q must be reported knowing that at least part of
                         it is the batch effect the paper's own METHODS result names.
        **THIS IS A CROSS-BATCH QUANTITY.**  It is the reason the batch exists, but it
        carries the batch floor by construction and it CANNOT gate R1.

  R3    **THE WITHIN-BATCH BASE CONTRAST.**  dD' = D'_SGD - D'_RMS, both legs from
        this one submission, so no batch floor at all.
          |dD'| <= 0.40                    -> SGD AND RMSProp AGREE WITHIN RESOLUTION
          |dD'| >  0.40 AND |t| >= 2.0     -> RESOLVED DIFFERENCE between the two
          otherwise                        -> UNRESOLVED
        Planning se(dD') = 0.274, so the 0.40 band is 1.46 se wide.  "AGREE WITHIN
        RESOLUTION" is therefore NOT an equivalence claim and may not be written as
        "identical".  `nl1`'s reading was dD = +0.062 +- 0.274 (t 0.23).

  R4    **SECONDARY, CROSS-BATCH, DESCRIPTIVE, GATES NOTHING.**  D' minus the
        published 8-cell SGDm+BatchNorm pool, +0.555 +- 0.045 (CORRECTIONS 125.1
        item 2).  `nl1` put SGD +0.480 above that pool (z 4.07) and RMSProp +0.418
        above it (z 1.64); whether bm2 reproduces the SIGN and rough SIZE of those
        deviations is the moderator claim in its most direct form.  Printed AFTER
        R1-R3 and explicitly labelled as carrying the batch floor
        (F(62,85) = 5.47) that neither pairing nor Welch removes.

  R5    **ANTI-NARRATION.**
        R5.1  bm2 does not amend `nl1`.  `nl1`'s verdict stands as read, whatever
              this batch returns; R2 combines them, it does not overwrite one.
        R5.2  No argmax harvesting.  All four arms are reported whole, in a fixed
              order, whichever way they fall.  RULE 11: no argmax is located under
              SGD or RMSProp, so no arm's number is a tuned number.
        R5.3  NO G STATEMENT.  This batch runs NO nodewise1d and NO chunk2325 arm.
              G = plateau5(chunk2325) - plateau5(nodewise1d) is therefore not
              measurable here and no sentence about the degenerate size-1 tail,
              D-G, or the tail mechanism may be sourced to bm2.
        R5.4  NO POOLING ACROSS BASES.  D'_SGD and D'_RMS are never averaged into a
              single "unnormalised-base D"; the batch exists to keep them apart.
        R5.5  Says nothing about AdamW, SGDm, GroupNorm, ResNet34, ResNet50,
              CIFAR-100, any budget other than 100 epochs, or any meta-optimiser
              other than Lion.
        R5.6  `plateau` (mean of last 20) is BANNED as primary.  plateau5 only.

WHAT THIS SCORER WILL NOT DO
  * It will not read a base's D if either of that base's arms is void or dropped.
    A void cell is not a null.
  * It will not report an underpowered null as "no gap" -- see the R1 power statement.
  * It will not let R2 or R4, both cross-batch, gate or reorder R1 or R3.
  * It will not compute any field / N_eff statistic.  At this cell no coordinate
    reaches either guard, so the clip-severity channel yields nothing; rec_lo/rec_hi
    are the R0.5 gate and nothing else.
  * It will not silently substitute `plateau` for `plateau5`.
  * It will not read a run whose ARGS line carries a repeated flag (STANDING RULE 20);
    with --outs it re-audits every ARGS line itself and refuses the batch if any
    flag repeats.

USAGE

                                    --outs /cluster/account_a/metaopt/runs \

# --- statistics -------------------------------------------------------------
def _sem(v):
    return statistics.stdev(v) / math.sqrt(len(v)) if len(v) > 1 else float("nan")


def _welch(a, b):
    """(difference, se, t).  Unpaired -- seeds do not pair, RULE 14."""
    d = statistics.mean(a) - statistics.mean(b)
    se = math.sqrt(_sem(a) ** 2 + _sem(b) ** 2)
    return d, se, (d / se if se > 0 else float("nan"))


def band(d, se, t):
    """THE THREE REGISTERED OUTCOMES for D'.  No reinterpretable middle.

    `se` is carried in for one reason only: an underpowered null is UNDECIDED, never
    "no gap".  That is the exact failure the cycle-98 review used to kill the
    alignment headline (NULL_HALF 0.15 < realised se 0.157).
    """
    if d >= DECIDE and t >= RESOLVED_T:
        return "REPLICATES"
    if d <= NULL_HALF and se <= SE_MAX:
        return "FAILS TO REPLICATE"
    return "UNDECIDED"


def offset_band(d, base):
    if abs(d - D_NL1[base]) <= OFFSET_BAR:
        return "AGREES WITH nl1 WITHIN THE CROSS-BATCH OFFSET"
    return "DISAGREES WITH nl1 BEYOND THE CROSS-BATCH OFFSET"


def dd_band(dd, t):
    if abs(dd) <= DD_BAND:
        return "AGREE WITHIN RESOLUTION"
    if abs(dd) > DD_BAND and abs(t) >= RESOLVED_T:
        return "RESOLVED DIFFERENCE"
    return "UNRESOLVED"


def iv_pool(pairs):
    """Inverse-variance pool + Cochran Q.  pairs = [(estimate, se), ...]."""
    ws = [1.0 / (se * se) for _, se in pairs]
    tot = sum(ws)
    m = sum(w * d for w, (d, _) in zip(ws, pairs)) / tot
    se = math.sqrt(1.0 / tot)
    q = sum(w * (d - m) ** 2 for w, (d, _) in zip(ws, pairs))
    return m, se, q, len(pairs) - 1

def _f(r, k, default=float("nan")):
    v = (r.get(k) or "").strip()

ARGS_RE = re.compile(r"^ARGS: (.+)$", re.M)


def parse_flags(line):
    """argparse semantics, shared in spirit with analysis/argsline_guard.py: the LAST
    occurrence of a flag wins, and every repeat is reported."""
    toks = line.split()
    occ = []
    i = 0
    while i < len(toks):
        t = toks[i]
        if t.startswith("--") and len(t) > 2:
            f = t.lstrip("-")
            vals = []
            j = i + 1
            while j < len(toks) and not (toks[j].startswith("--") and len(toks[j]) > 2):
                vals.append(toks[j])
                j += 1
            occ.append((f, " ".join(vals)))
            i = j
            continue
        i += 1
    dup = collections.OrderedDict()
    eff = collections.OrderedDict()
    for f, v in occ:
        dup.setdefault(f, []).append(v)
        eff[f] = v
    return eff, collections.OrderedDict((f, v) for f, v in dup.items() if len(v) > 1)


def rows_from_outs(outdir):
    """Build the same row dicts straight from the .out files, so the batch can be
    scored before aggregate.py has run -- and so STANDING RULE 20 is enforced HERE,
    on the runs' own ARGS lines, not on any script header."""
    out = []
    for p in sorted(glob.glob(os.path.join(outdir, TAG + "-*.out"))):
        txt = open(p, errors="replace").read()
        m = ARGS_RE.search(txt)
        if not m:
            continue
        eff, dup = parse_flags(m.group(1))
        tests = [float(x) for x in re.findall(r"Test Accuracy: ([0-9.]+)", txt)]
        if not tests:
            continue
        env = re.search(r"^ENV: (.+)$", txt, re.M)
        e = dict(kv.split("=", 1) for kv in env.group(1).split()) if env else {}
        out.append({
            "run": eff.get("run-name", os.path.basename(p)),
            "network": eff.get("NN-name", "?"), "dataset": eff.get("dataset", "?"),
            "batch_size": eff.get("batch-size", ""),
            "granularity": eff.get("stepsize-groups", "?"),
            "base": eff.get("alg-base", "?"), "meta": eff.get("alg-meta", "?"),
            "meta_stepsize": eff.get("meta-stepsize", ""),
            "alpha0": eff.get("alpha0", ""), "gamma": eff.get("gamma", ""),
            "augment": e.get("AUGMENT", "?"), "beta_clip": e.get("BETA_CLIP", "?"),
            "seed": eff.get("seed", ""), "epochs_done": str(len(tests)),
            "epochs_requested": eff.get("num-epochs", ""),
            "best_test": max(tests), "final_test": tests[-1],
            "collapsed": str(int(tests[-1] <= 11.0 and max(tests) > 20.0)),
            "plateau5": round(sum(tests[-5:]) / 5.0, 3) if len(tests) >= 5 else "",
            "_dup": dup, "_path": p,
        })
    return out


def arm_of_run(name):
    """bm2-<bt>-<sh>-s<seed>  ->  '<bt>-<sh>'."""
    parts = name.split("-")
    if len(parts) < 4 or parts[0] != TAG:
        return None
    return "%s-%s" % (parts[1], parts[2])


def probe_dirs(root):
    """Every probe dir belonging to this batch, wherever the mirror is rooted."""
    hits = set()
    for pat in ("probe_*_%s_s*" % TAG, os.path.join("*", "probe_*_%s_s*" % TAG)):
        hits.update(d for d in glob.glob(os.path.join(root, pat)) if os.path.isdir(d))
    return sorted(hits)


def arm_of_dir(d):
    """probe_<bt>_<sh>_bm2_s<seed>  ->  '<bt>-<sh>'."""
    parts = os.path.basename(d).split("_")
    if len(parts) < 5 or parts[0] != "probe" or parts[3] != TAG:
        return None
    return "%s-%s" % (parts[1], parts[2])


# --- R0 --------------------------------------------------------------------
def r0_of_row(r):
    bad = []
    ed = str(r.get("epochs_done") or "").strip()
    er = str(r.get("epochs_requested") or "").strip()
    if ed != str(EPOCHS) or (er and er != str(EPOCHS)):
        bad.append("R0.1 epochs %s/%s" % (ed or "?", er or "?"))
    if str(r.get("collapsed") or "0").strip() not in ("0", ""):
        bad.append("R0.2 collapsed")
    ft, p5, bt = _f(r, "final_test"), _f(r, "plateau5"), _f(r, "best_test")
    if not (ft > FINAL_FLOOR):
        bad.append("R0.3 final_test %.3f" % ft)
    if not (p5 >= PLATEAU_FLOOR):
        bad.append("R0.3 plateau5 %.3f" % p5)
    if not (bt - p5 <= LATE_BLOWUP):
        bad.append("R0.4 best-plateau5 %.3f" % (bt - p5))
    return (not bad), bad


def axis_of_row(r):
    """The cell signature every bm2 run must carry.  A run that drifted off the nl1
    cell is not a replication of it."""
    bad = []
    for k, want in (("network", NET), ("dataset", DSET), ("batch_size", BATCH),
                    ("meta", META), ("meta_stepsize", MST), ("alpha0", ALPHA0),
                    ("gamma", GAMMA), ("augment", AUG),
                    ("beta_clip", "%g:%s" % (LO, "-2.3026"))):
        got = str(r.get(k) or "").strip()
        if k in ("meta_stepsize", "alpha0"):
            try:
                if float(got) == float(want):
                    continue
            except ValueError:
                pass
        if got != want:
            bad.append("%s=%s (want %s)" % (k, got or "?", want))
    return bad


# --- the report ------------------------------------------------------------
def score(rows, root):
    print("=" * 78)
    print(" bm2 -- BASE-MODERATOR REPLICATION.  Second INDEPENDENT batch at SGD and")
    print(" RMSProp, fresh seeds %s.  Registered scorer, run UNEDITED (RULE 16)." %
          ",".join(str(s) for s in SEEDS))
    print("=" * 78)

    by_arm = collections.defaultdict(list)
    for r in rows:
        a = arm_of_run(r["run"])
        if a in ARMS:
            by_arm[a].append(r)

    # --- R0.0 STANDING RULE 20, if we have the .out files -------------------
    dupes = [(r["run"], r["_dup"]) for r in rows if r.get("_dup")]
    if dupes:
        print("\n!!! STANDING RULE 20: repeated flags in the runs' OWN ARGS lines:")
        for name, d in dupes:
            for f, v in d.items():
                print("      %-18s --%-22s x%d -> EFFECTIVE '%s'"
                      % (name, f, len(v), v[-1]))
        print("!!! THE BATCH IS VOID AS DESIGNED.  No verdict is issued.")
        return 2

    # --- R0 per run ---------------------------------------------------------
    print("\n--- R0  VALIDITY, per run ---")
    bad_seeds = collections.Counter()
    for a in ARMS:
        for r in sorted(by_arm.get(a, []), key=lambda r: r["run"]):
            ok, why = r0_of_row(r)
            drift = axis_of_row(r)
            if drift:
                why = why + ["R0.axis " + "; ".join(drift)]
                ok = False
            if not ok:
                bad_seeds[a] += 1
            print("    %-16s plateau5 %7s  final %7s  best %7s  %s"
                  % (r["run"], r.get("plateau5"), r.get("final_test"),
                     r.get("best_test"), "ok" if ok else "FAIL: " + "; ".join(why)))
        n = len(by_arm.get(a, []))
        if n != len(SEEDS):
            print("    !!! arm %-9s has %d runs, expected %d" % (a, n, len(SEEDS)))
            bad_seeds[a] += (len(SEEDS) - n)

    # --- R0.5 the box, measured on THIS batch's probes ----------------------
    print("\n--- R0.5  BOX OCCUPANCY, measured on bm2's own probes (box %g:%g) ---"
          % (LO, HI))
    dropped = set()
    dirs = probe_dirs(root) if root else []
    if not dirs:
        print("    !!! NO PROBE DIR FOUND under %s -- R0.5 is UNMEASURED." % root)
        print("    !!! An unmeasured box gate is a FAILED gate (RULE 5).  Every arm drops.")
        dropped = set(ARMS)
    else:
        occ_by_arm = collections.defaultdict(list)
        for d in dirs:
            a = arm_of_dir(d)
            if a not in ARMS:
                continue
            try:
                o = occupancy(d, LO, HI)
            except Exception as ex:                       # noqa: BLE001
                print("    %-40s UNREADABLE (%s)" % (os.path.basename(d), ex))
                dropped.add(a)
                continue
            occ_by_arm[a].append(o)
            flag = "" if (o["rec_lo"] <= REC_MAX and o["rec_hi"] <= REC_MAX) else "  <-- BOUND"
            if flag:
                dropped.add(a)
            print("    %-40s T %5d  rec_lo %.4f  rec_hi %.4f%s"
                  % (os.path.basename(d), o["T"], o["rec_lo"], o["rec_hi"], flag))
            if o["T"] != N_RECORDS:
                print("       !!! %d records, expected %d" % (o["T"], N_RECORDS))
        for a in ARMS:
            if a not in occ_by_arm:
                print("    !!! arm %-9s has NO readable probe -- R0.5 unmeasured, arm drops" % a)
                dropped.add(a)

    void = {a for a in ARMS if bad_seeds[a] >= VOID_SEEDS} | dropped
    if void:
        print("\n    VOID / DROPPED ARMS: %s" % ", ".join(sorted(void)))

    # --- R1 -----------------------------------------------------------------
    print("\n--- R1  THE PRIMARY: D' = plateau5(chunk%d) - plateau5(nodewise), WITHIN batch ---"
          % CHUNK_K)
    print("    power, registered in advance: planning se %.3f, MDE(80%%) %.2f pp;"
          % (SE_D_PLAN, MDE80))
    print("    the powered-null branch needs se <= %.2f and is UNREACHABLE on that noise," % SE_MAX)
    print("    so a small D' reads UNDECIDED and MAY NOT be written as 'no effect'.")
    got = {}
    for label, hi_arm, lo_arm, base in PAIRS:
        if hi_arm in void or lo_arm in void:
            print("    %-8s NOT READ -- %s void/dropped" % (label, hi_arm if hi_arm in void else lo_arm))
            continue
        A = [_f(r, "plateau5") for r in by_arm.get(hi_arm, [])]
        B = [_f(r, "plateau5") for r in by_arm.get(lo_arm, [])]
        if len(A) < 2 or len(B) < 2:
            print("    %-8s NOT READ -- n(%s)=%d n(%s)=%d" % (label, hi_arm, len(A), lo_arm, len(B)))
            continue
        d, se, t = _welch(A, B)
        got[base] = (d, se, t)
        print("    %-8s base %-8s %+.4f +- %.4f  t %5.2f   %dv%d   -> %s"
              % (label, base, d, se, t, len(A), len(B), band(d, se, t)))
        print("             R1b vs nl1 %+.4f: delta %+.4f  -> %s"
              % (D_NL1[base], d - D_NL1[base], offset_band(d, base)))

    # --- R2 -----------------------------------------------------------------
    print("\n--- R2  TWO-BATCH MODERATOR LEVEL (CROSS-BATCH; carries the batch floor) ---")
    for base in ("SGD", "RMSProp"):
        if base not in got:
            print("    %-8s NOT POOLED -- bm2's D' was not read" % base)
            continue
        d, se, _ = got[base]
        m, pse, q, df = iv_pool([(D_NL1[base], SE_NL1[base]), (d, se)])
        verdict = ("REPLICATED (Q <= %.3f)" % Q_CRIT if q <= Q_CRIT
                   else "HETEROGENEOUS ACROSS BATCHES (Q > %.3f) -- the pooled point"
                        " estimate may NOT be quoted as a stable level" % Q_CRIT)
        print("    %-8s nl1 %+.4f+-%.4f | bm2 %+.4f+-%.4f -> pool %+.4f +- %.4f   Q %.3f on %d df"
              % (base, D_NL1[base], SE_NL1[base], d, se, m, pse, q, df))
        print("             -> %s" % verdict)

    # --- R3 -----------------------------------------------------------------
    print("\n--- R3  THE WITHIN-BATCH BASE CONTRAST  dD' = D'_SGD - D'_RMS ---")
    if "SGD" in got and "RMSProp" in got:
        ds, ss, _ = got["SGD"]
        dr, sr, _ = got["RMSProp"]
        dd = ds - dr
        sd = math.sqrt(ss * ss + sr * sr)
        t = dd / sd if sd > 0 else float("nan")
        print("    dD' %+.4f +- %.4f  t %5.2f  -> %s" % (dd, sd, t, dd_band(dd, t)))
        print("    (nl1's reading of the same contrast: %+.4f +- %.4f)"
              % (D_NL1["SGD"] - D_NL1["RMSProp"],
                 math.sqrt(SE_NL1["SGD"] ** 2 + SE_NL1["RMSProp"] ** 2)))
        print("    band %.2f is %.2f x the planning se -- AGREE WITHIN RESOLUTION is NOT"
              % (DD_BAND, DD_BAND / SE_DD_PLAN))
        print("    an equivalence claim and may not be written as 'identical'.")
    else:
        print("    NOT READ -- both bases must be read for a within-batch contrast")

    # --- R4 -----------------------------------------------------------------
    print("\n--- R4  DESCRIPTIVE: deviation from the 8-cell SGDm+BatchNorm pool %+.3f +- %.3f ---"
          % (POOL, POOL_SE))
    print("    CROSS-BATCH.  Carries the batch floor F(62,85)=5.47, p 6.9e-13, which")
    print("    neither pairing nor Welch removes.  GATES NOTHING.")
    for base in ("SGD", "RMSProp"):
        if base not in got:
            continue
        d, se, _ = got[base]
        dev = d - POOL
        z = dev / math.sqrt(se * se + POOL_SE * POOL_SE)
        nl1_dev = D_NL1[base] - POOL
        print("    %-8s bm2 dev %+.4f (z %5.2f)   |   nl1 dev %+.4f   sign %s"
              % (base, dev, z, nl1_dev,
                 "REPRODUCED" if dev * nl1_dev > 0 else "NOT reproduced"))

    print("\n--- R5  what this batch may NOT say ---")
    print("    no G / tail statement (no nodewise1d, no chunk2325 arm here);")
    print("    no pooling of SGD with RMSProp; nl1 is combined with, never overwritten;")
    print("    nothing about AdamW, SGDm, GroupNorm, R34/R50, CIFAR-100, or any other budget.")
    return 0 if got else 1


# --- selftest ---------------------------------------------------------------
def selftest():
    p = n = 0

    def ck(name, cond):
        nonlocal p, n
        n += 1
        p += bool(cond)
        print("    %-76s %s" % (name, "ok" if cond else "FAIL"))

    print("c97_bm2_score selftest")
    src = open(SCRIPT).read() if os.path.exists(SCRIPT) else ""

    # --- the batch script exists and this scorer matches ITS OWN TEXT -------
    ck("the batch script exists at bin/c97_basemod_replicate.sh", bool(src))
    ck("script TAG= is %s" % TAG, "TAG=%s" % TAG in src)
    ck("script CLIP= is this scorer's box", "CLIP=-15:-2.3026" in src)
    ck("script MST= is %s" % MST, "MST=%s" % MST in src)
    ck("script ALPHA0= is %s" % ALPHA0, "ALPHA0=%s" % ALPHA0 in src)
    ck("script EPOCHS= is %d" % EPOCHS, "EPOCHS=%d" % EPOCHS in src)
    ck("script BATCH= is %s" % BATCH, "BATCH=%s" % BATCH in src)
    ck("script NET= is %s" % NET, "NET=%s" % NET in src)
    ck("script DSET= is %s" % DSET, "DSET=%s" % DSET in src)
    ck("script GAMMA= is %s" % GAMMA, "GAMMA=%s" % GAMMA in src)
    ck("script AUG= is %s" % AUG, "AUG=%s" % AUG in src)
    ck("script NJOBS= is %d" % NJOBS, "NJOBS=%d" % NJOBS in src)
    ck("script CHUNK_K= is %d" % CHUNK_K, "CHUNK_K=%d" % CHUNK_K in src)
    ck("script SEEDS= is the three FRESH seeds this scorer scores",
       'SEEDS="%s"' % " ".join(str(s) for s in SEEDS) in src)
    ck("script BASES= is exactly SGD and RMSProp", 'BASES="SGD RMSProp"' in src)
    ck("script M_NODE= matches the two node arms", "M_NODE=%d" % M_NODE in src)
    ck("script M_CHUNK= matches the two chunk arms", "M_CHUNK=%d" % M_CHUNK in src)
    ck("script writes run names bm2-<bt>-<sh>-s<seed>",
       'RN="${TAG}-${BT}-${SH}-s${S}"' in src)
    ck("script exports PROBE=5-style probing AND PROBE5=1",
       "PROBE=5" in src and "PROBE5=1" in src)
    ck("script pins HIER=none and SCHED=none in --export",
       "HIER=none" in src and "SCHED=none" in src)
    ck("script pins --max-time 999:00:00", "--max-time 999:00:00" in src)
    ck("script's BETA_CLIP carries a COLON (HOUSE RULE)", ":" in "-15:-2.3026")
    ck("script defaults to a DRY RUN", "SUBMIT=0" in src and '--submit" ] && SUBMIT=1' in src)
    ck("script sources the STANDING RULE 20 guard library", "_lib_guards.sh" in src)
    ck("script calls guard_presubmit on the EXACT string it will eval",
       'guard_presubmit "$CMD"' in src)
    ck("script calls guard_postlaunch after submitting", "guard_postlaunch" in src)
    ck("script registers this scorer BEFORE composing anything (RULE 21)",
       "guard_scorer_registered" in src and "c97_bm2_score.py" in src)
    ck("script MEASURES m per granularity from the ALLOCATED beta on the LIVE tree",
       "ALLOCATED beta m=" in src)

    # --- THE ml2/sm3 DEFECT, CHECKED AT THE SOURCE -------------------------
    ck("the meta flags are NOT inside $BFLAGS (the exact ml2/sm3 shape)",
       "alg-meta" not in src.split("BFLAGS=")[1].split("\n")[0] if "BFLAGS=" in src else False)
    ck("the emitter carries exactly ONE --alg-meta occurrence",
       src.count("--alg-meta") == 1)
    ck("the emitter carries exactly ONE --weight-decay-meta occurrence",
       src.count("--weight-decay-meta") == 1)
    ck("the emitter carries exactly ONE --momentum-param-meta occurrence",
       src.count("--momentum-param-meta") == 1)
    ck("--alg-meta is Lion, matching nl1's OWN ARGS line", "--alg-meta Lion" in src)
    ck("no --normalizer-param-meta anywhere (the inert residual that broke sm3's claim)",
       "--normalizer-param-meta" not in src)

    # --- the thresholds, asserted against the script's own registered values
    for label, val in (("NULL_HALF", NULL_HALF), ("DECIDE", DECIDE),
                       ("SE_MAX", SE_MAX), ("DD_BAND", DD_BAND),
                       ("OFFSET_BAR", OFFSET_BAR)):
        ck("script %s=%s matches this scorer" % (label, val), "%s=%s" % (label, val) in src)
    ck("script SIGMA= matches", "SIGMA=%s" % SIGMA in src)
    ck("script SE_D= matches the planning se", "SE_D=%s" % SE_D_PLAN in src)
    ck("script SE_DD= matches", "SE_DD=%s" % SE_DD_PLAN in src)
    ck("script D_NL1_SGD= matches", "D_NL1_SGD=%s" % D_NL1["SGD"] in src)
    ck("script D_NL1_RMS= matches", "D_NL1_RMS=%s" % D_NL1["RMSProp"] in src)
    ck("script SE_NL1_SGD= matches", "SE_NL1_SGD=%s" % SE_NL1["SGD"] in src)
    ck("script SE_NL1_RMS= matches", "SE_NL1_RMS=%s" % SE_NL1["RMSProp"] in src)
    ck("script POOL= matches", "POOL=%s" % POOL in src)
    ck("script POOL_SE= matches", "POOL_SE=%s" % POOL_SE in src)

    # --- the arithmetic of the plan ----------------------------------------
    ck("the planning se follows from SIGMA and n=3",
       abs(SE_D_PLAN - SIGMA * math.sqrt(2 / 3)) < 0.002)
    ck("se(dD') is sqrt(2) x se(D')",
       abs(SE_DD_PLAN - SE_D_PLAN * math.sqrt(2)) < 0.002)
    ck("MDE(80%) is 2.80 x the planning se", abs(MDE80 - 2.80 * SE_D_PLAN) < 0.005)
    ck("the batch is powered to CONFIRM nl1's SGD effect (t >= 4)",
       D_NL1["SGD"] / SE_D_PLAN >= 4.0)
    ck("the batch is powered to CONFIRM nl1's RMSProp effect (t >= 4)",
       D_NL1["RMSProp"] / SE_D_PLAN >= 4.0)
    ck("THE POWERED-NULL BRANCH IS UNREACHABLE ON THE PLANNING NOISE, and is "
       "registered as such", SE_MAX < SE_D_PLAN)
    ck("2 bases x 2 granularities x %d seeds == NJOBS" % len(SEEDS),
       2 * 2 * len(SEEDS) == NJOBS)
    ck("every arm has a base and a granularity",
       all(a in BASE_OF_ARM and a in GRAN_OF_ARM for a in ARMS))
    ck("each pair varies GRANULARITY at FIXED base",
       all(BASE_OF_ARM[h] == BASE_OF_ARM[l] and GRAN_OF_ARM[h] != GRAN_OF_ARM[l]
           for _, h, l, _ in PAIRS))
    ck("the two pairs sit at DIFFERENT bases (the batch is not two copies of one cell)",
       BASE_OF_ARM[PAIRS[0][1]] != BASE_OF_ARM[PAIRS[1][1]])
    ck("both pairs are count-matched to <= 1 group",
       abs(M_CHUNK - M_NODE) <= 1)
    ck("bm2's seeds are DISJOINT from nl1's -- the batch is independent, not a rerun",
       not (set(SEEDS) & set(SEEDS_NL1)))

    # --- the box, registered before any run --------------------------------
    import c55_neff_noise as c55
    ck("bm2's box is cc1's REGISTERED box -- not a new box",
       c55.BOXES.get("cc1", (0, 0, ""))[:2] == (LO, HI))
    ck("bm2's box is gn1's registered box too (the same ms=1e-4 anchor box)",
       c55.BOXES.get("gn1", (0, 0, ""))[:2] == (LO, HI))

    # --- the band, exhaustive ----------------------------------------------
    ck("+1.00 with t 5 -> REPLICATES", band(1.00, 0.19, 5.0) == "REPLICATES")
    ck("+0.30 with t 3 -> REPLICATES (the line is CLOSED on the replicate side)",
       band(0.30, 0.10, 3.0) == "REPLICATES")
    ck("+0.30 with t 1.5 -> UNDECIDED (the t requirement really binds)",
       band(0.30, 0.20, 1.5) == "UNDECIDED")
    ck("+0.20 -> UNDECIDED", band(0.20, 0.10, 2.0) == "UNDECIDED")
    ck("+0.10 at the PLANNING se -> UNDECIDED, not a null",
       band(0.10, SE_D_PLAN, 0.5) == "UNDECIDED")
    ck("+0.10 at se 0.14 -> FAILS TO REPLICATE (powered)",
       band(0.10, 0.14, 0.7) == "FAILS TO REPLICATE")
    ck("-0.50 at se 0.14 -> FAILS TO REPLICATE", band(-0.50, 0.14, -3.6) == "FAILS TO REPLICATE")
    ck("-0.50 at the planning se -> UNDECIDED (an unpowered negative is not a null)",
       band(-0.50, SE_D_PLAN, -2.6) == "UNDECIDED")
    ck("the offset band is centred on nl1's own value per base",
       offset_band(D_NL1["SGD"], "SGD").startswith("AGREES")
       and offset_band(D_NL1["SGD"] + 0.60, "SGD").startswith("DISAGREES"))
    ck("dD' 0.06 -> AGREE WITHIN RESOLUTION (nl1's own reading)",
       dd_band(0.062, 0.23) == "AGREE WITHIN RESOLUTION")
    ck("dD' 0.80 with t 3 -> RESOLVED DIFFERENCE", dd_band(0.80, 3.0) == "RESOLVED DIFFERENCE")
    ck("dD' 0.80 with t 1.2 -> UNRESOLVED", dd_band(0.80, 1.2) == "UNRESOLVED")

    # --- the pool arithmetic ------------------------------------------------
    m, se, q, df = iv_pool([(1.0, 0.1), (1.0, 0.1)])
    ck("two identical studies pool to themselves with Q = 0",
       abs(m - 1.0) < 1e-9 and abs(q) < 1e-9 and df == 1)
    ck("the pooled se beats both inputs", se < 0.1)
    _, _, q2, _ = iv_pool([(1.0, 0.1), (0.0, 0.1)])
    ck("two studies 10 se apart are HETEROGENEOUS (Q > chi2(1))", q2 > Q_CRIT)

    # --- the anti-narration clauses are actually enforceable -----------------
    ck("no nodewise1d or chunk2325 arm exists, so no G can be computed here",
       all(GRAN_OF_ARM[a] in ("nodewise", "chunk%d" % CHUNK_K) for a in ARMS))
    # The banned column is spelled by construction so this check cannot match its own
    # source text -- a literal here would make the assertion self-defeating.
    me = open(os.path.abspath(__file__)).read()
    banned = '_f(r, "%s")' % ("plat" + "eau")
    ck("plateau5 is the only accuracy column this scorer reads (mean-of-last-20 "
       "`plateau` is BANNED as primary)", "plateau5" in me and banned not in me)

    print("  %d/%d checks pass" % (p, n))
    return 0 if p == n else 1


def main(argv=None):
    ap = argparse.ArgumentParser(prog="c97_bm2_score.py")
    ap.add_argument("--selftest", action="store_true")
    ap.add_argument("--root", default=None,
                    help="directory holding bm2's probe_* dirs (the box gate)")
    ap.add_argument("--outs", default=None,
                    help="directory holding bm2-*.out (scores straight from the runs, "
                         "and re-audits every ARGS line -- STANDING RULE 20)")
    ap.add_argument("--csv", default=os.path.join(REPO, "results", "all_runs.csv"))
    a = ap.parse_args(argv)
    if a.selftest:
        return selftest()
    if a.outs:
        rows = rows_from_outs(a.outs)
        print("read %d bm2 runs straight from %s" % (len(rows), a.outs))
    else:
        rows = rows_from_csv(a.csv)
        print("read %d bm2 rows from %s" % (len(rows), a.csv))
    if not rows:
        print("!!! NO bm2 RUN FOUND.  Nothing to score; no verdict is issued.")
        return 2
    return score(rows, a.root)


if __name__ == "__main__":
    sys.exit(main())
