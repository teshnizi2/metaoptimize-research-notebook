# batch is submitted (STANDING RULE 21).  Every bar, the noise floor
# (RE-DERIVED at registration time from the live corpus with cru1's own rows
# EXCLUDED, never copied), the reachability arithmetic, both point-predictors,
# the branch map and the floor proof are frozen there, and its --selftest
# re-derives all of them from the corpus and from arithmetic, never from prose.
#
# THE DOCUMENTED SCORER INVOCATION -- there is no second argument to forget:
#     python3 analysis/cY1_cru1_score.py <runsdir>
# `--probe-dir` is OPTIONAL and DEFAULTED; guard 8 below imports the scorer and
# proves the default resolver finds the probe root before any job can finish
# (CORRECTIONS 164.2: cpr1 was scored without --manifest and a WRONG verdict
# stood for an hour).

# -----------------------------------------------------------------------------
# THE QUESTION
# -----------------------------------------------------------------------------
# RULE 11 -- compare tuned arms at their own optima -- is OPEN on the exact cell
# every recent headline comes from, and CORRECTIONS 160 measured why a naive
# fix cannot work: on CIFAR-100 the meta-stepsize axis is PERFECTLY ALIASED with
# alpha0.  The scorer's --selftest section A re-derives that from the live CSV:
# CIFAR-100 carries EXACTLY TWO ms levels; all 42 scalar, all 101 layerwise and
# all 38 resnet18_blocks rows sit at ms=1e-3; and the ENTIRE ms=1e-4 stratum is
# 20 rows, ALL at alpha0=1e-3, containing no scalar, no layerwise, no blk6 and
# no cut-position arm.
#
# WHY THE ALIAS IS MECHANICALLY FORCED, NOT A SCHEDULING ACCIDENT.  In
# Optimizers/HF.py, `Lion_meta_update` is
#
#     self.beta[i] = (1-ms*wd_meta)*self.beta[i] - ms*torch.sign(...)
#
# and every job below passes `--weight-decay-meta 0`, so |dbeta| = ms EXACTLY,
# once per minibatch.  100 epochs x 500 minibatches = 50,000 meta-steps, so
# beta's TOTAL travel is 50000*ms whatever the loss surface does.  With
# BETA_CLIP=-15:-2.3026 the ceiling is D_up = -2.3026 - ln(alpha0) above the
# start.  At alpha0=1e-6, D_up = 11.513 and ms=1e-4 buys TRAVEL = 5.0: alpha can
# NEVER exceed 1.484e-4 in the whole run.  That is why no such row exists.
# A LADDER THAT VARIES ONLY ms CANNOT BREAK THIS ALIAS.  This batch crosses both
# axes: FOUR ms levels {1e-4, 3e-4, 1e-3, 3e-3} appear at BOTH alpha0 for BOTH
# arms.  Guard 4a re-derives the whole reachability table and guard 4b proves
# the update rule is what is claimed, ON THE LIVE SOURCE.
#
# WHY IT MATTERS.  The best CIFAR-100 plateau5 anywhere in the corpus is 72.408
# and the entire top of that table sits at ms=1e-4 / alpha0=1e-3 -- the same
# cell in every other respect -- where chunk771 = 71.995, chunk2293 = 72.000,
# nodewise1d = 71.932 and nodewise = 70.422, EVERY ONE above the headline
# layerwise 69.5945 / 69.5321 at ms=1e-3.  The headline arms have never been run
# there.  And on CIFAR-10, the only place this contrast HAS been laddered, the
# gap goes +3.371 pp at the shared ms=1e-3 -> +0.624 pp at ms=1e-4 where BOTH
# arms peak: a 5.40x SHRINK under per-arm tuning.
#
# -----------------------------------------------------------------------------
# THE DESIGN.  2 arms x 10 (ms, alpha0) cells x 3 seeds = 60 jobs, ONE
# submission.  CIFAR-100 / ResNet18_c100, 100 epochs, PROBE=100.
#   sc   `scalar`     m = 1
#   lay  `layerwise`  m = 62
#   LADDER A, alpha0 = 1e-3 : ms in {1e-5, 3e-5, 1e-4, 3e-4, 1e-3, 3e-3}
#   LADDER B, alpha0 = 1e-6 : ms in {      1e-4, 3e-4, 1e-3, 3e-3}
#   SEEDS {15,16,17} -- ZERO rows anywhere on ResNet18_c100 carry them.
#
# WHAT WAS DROPPED AND WHAT IT COSTS.  `resnet18_blocks` (m=6, the parent
# paper's own partition) and the `k49` cut-position arm are NOT here.  Either at
# the full ladder is 30 more jobs and ~22 more GPU-hours, which does not fit a
# three-way-shared window; the standing instruction is to prioritise BRACKETING
# each arm's optimum over adding arms.  CONSEQUENCE, REGISTERED IN ADVANCE AND
# BINDING: this batch closes RULE 11 for the scalar-vs-layerwise contrast ONLY.
# NOT for blk6, NOT for cut position, NOT for class count, NOT for ImageNet.
#
# WHY PROBE=100.  Lowering ms does TWO things at once -- it tunes the
# meta-optimiser AND it mechanically limits how far beta can descend.  That is
# this design's central confound and it is named in the registration rather than
# discovered afterwards.  CORRECTIONS 155 measured on CIFAR-10 at ms=3e-4 that
# the scalar arm's single beta reaches -15 at meta-step ~34,100 and sits pinned
# 31.8% of the time while layerwise pins ~5.5% of coordinates.  PROBE=100 gives
# 500 beta snapshots per run so a GAP-SHRINKS result at a low rung can be
# ATTRIBUTED rather than merely reported.  The scorer treats the probe as a
# SKIP, never a FAIL: no verdict depends on it.
#
# RULE 20.  Every value composed below is ONE shell token of [A-Za-z0-9_.,:/-]
# -- no space, no quote, no `=`, no leading dash, no glob character -- so
# analysis/argsline_guard.py tokenises and attributes it AS-IS with NO change to
# that file.  argsline_guard.py IS NOT EDITED.  BETA_CLIP and PROBE are
# ENVIRONMENT variables and cannot ride the ARGS line; they get their own audit
# after launch and the scorer's G1 re-checks them from every run's ENV line.
#
# -----------------------------------------------------------------------------
# WALLTIME, PARTITIONS AND COST -- MEASURED, NOT PROJECTED
# -----------------------------------------------------------------------------
# The corpus's 274 CIFAR-100 / ResNet18_c100 / 100-epoch runs have wallclock
# median 42.0 min, mean 43.8 min, max 119 min.  PROBE=100 cost cfr2 about 7%
# over cfr1 on the same cell (53.5 vs 49.9 min).  So 60 x ~45 min ~= 45
# GPU-hours.  WALL = 03:00:00 is 1.51x the slowest run ever observed on this
# cell.  PARTS are the three cpg1/cpr1 used on 2026-09-07, unchanged.
#
# USAGE   bash bin/cY1_rule11_ms_alpha0.sh            # dry run, submits nothing
#         bash bin/cY1_rule11_ms_alpha0.sh --submit

echo " $DSET / $NET   AUGMENT=$AUG  PROBE=$PROBE  clamp $CLIP_C"
echo " horizon $EPOCHS epochs; seeds $SEEDS"
echo " LADDER A  alpha0=$A0_A  ms: $MS_A"
echo " LADDER B  alpha0=$A0_B  ms: $MS_B"
echo " arms: sc=$G_SC   lay=$G_LAY"
echo " 10 cells x 2 arms x 3 seeds = 60 jobs, ONE submission"
echo " partitions $PARTS   walltime $WALL"
echo " scorer: analysis/cY1_cru1_score.py (registered before any run exists)"
echo " DOCUMENTED INVOCATION: python3 analysis/cY1_cru1_score.py <runsdir>"

# ---- guard 0: the corpus ----------------------------------------------------

[ -f "$CSVP" ] || guard_fail "guard 0: no CSV at $CSVP"
[ -f "$CSVP" ] && echo "guard 0: CSV present ($(wc -l < "$CSVP") lines)"

if git -C "$REPO" rev-parse --git-dir >/dev/null 2>&1; then
  DIRTY=$(git -C "$REPO" status --porcelain -- \
      analysis/cY1_cru1_score.py bin/cY1_rule11_ms_alpha0.sh 2>/dev/null)
  [ -z "$DIRTY" ] && echo "guard 1b: scorer AND this script are committed (RULE 21)" \
                  || guard_fail "guard 1b: uncommitted -- RULE 21 requires them committed BEFORE any run exists: $DIRTY"
  # RULE 16: git diff over analysis/ must be ADDITIONS ONLY.
  DEL=$(git -C "$REPO" diff HEAD --numstat -- analysis/ 2>/dev/null | awk '$2+0>0{print}')
  [ -z "$DEL" ] && echo "guard 1b2: no uncommitted DELETIONS under analysis/ (RULE 16)" \
               || guard_fail "guard 1b2: analysis/ has uncommitted deletions: $DEL"
else
  echo "guard 1b: NOTE -- no git repo at $REPO on this host; RULE 21 was verified"
  echo "          on the host that committed the scorer, by wall clock against"
  echo "          the earliest sacct Submit.  Not a pass, not a fail."

  && echo "guard 1c: scorer --selftest PASSES ($(grep -c '^  PASS' /tmp/cru1_selftest.$$) checks, $(grep -c '^  FAIL' /tmp/cru1_selftest.$$) failures)" \
  || { guard_fail "guard 1c: scorer selftest FAILED"; tail -40 /tmp/cru1_selftest.$$; }
echo "guard 1c: scorer sha256 $( (sha256sum "$SC" 2>/dev/null || shasum -a 256 "$SC") | awk '{print $1}')"

# ---- guard 2: RULE 21 premise -- no run of this batch may exist yet ---------
grep -q '^cru1-' "$CSVP" && guard_fail "guard 2: cru1-* already in the CSV" \
                         || echo "guard 2: no cru1-* name collision in the corpus"
if [ -d "$WS/runs" ]; then
  NOUT=$(ls "$WS/runs"/cru1-*.out 2>/dev/null | wc -l | tr -d ' ')
  [ "${NOUT:-0}" = 0 ] && echo "guard 2b: no cru1-*.out on disk" \
                       || guard_fail "guard 2b: $NOUT cru1-*.out files already exist"
fi
NDUP=$(python3 - "$CSVP" "$NET" <<'PYEOF'
import sys, csv
n = 0
for r in csv.DictReader(open(sys.argv[1])):
    if r.get("network") == sys.argv[2] and str(r.get("seed")) in ("15", "16", "17"):

PYEOF

                     || guard_fail "guard 2c: $NDUP $NET rows already carry seed 15/16/17"

# ---- guard 3: the CIFAR-100 data is actually staged on THIS account ---------
[ -d "$CIF/data/cifar-100-python" ] && echo "guard 3: cifar-100-python present under $CIF/data" \
  || guard_fail "guard 3: CIFAR-100 is not staged at $CIF/data/cifar-100-python"

# ---- guard 4: THE LIVE SOURCE, THE LIVE MODEL, AND THE REACHABILITY TABLE ---
mkdir -p "$SAVE"
python3 - "$CIF" "$CLIP_C" "$EPOCHS" "$BATCH" "$A0_A" "$A0_B" "$MS_A" "$MS_B" \
  <<'PYEOF' || guard_fail "guard 4: live-source / live-model / reachability check FAILED"
import sys, os, inspect, math, re
cif, clip_c = sys.argv[1], sys.argv[2]
epochs, bsz = int(sys.argv[3]), int(sys.argv[4])
a0a, a0b = sys.argv[5], sys.argv[6]
msa, msb = sys.argv[7].split(), sys.argv[8].split()
sys.path.insert(0, cif); os.chdir(cif)
from build_network import build_network
from Optimizers.HF import HF
bad = 0

# ---- 4a: the model this batch will actually train --------------------------
net = build_network("ResNet18_c100", "cpu")
names = [n for n, _ in net.named_parameters()]
tot = sum(int(p.numel()) for _, p in net.named_parameters())
print("guard 4a: live ResNet18_c100 -- %d parameter tensors, %d parameters"
      % (len(names), tot))
if len(names) != 62 or tot != 11220132:
    print("!!! guard 4a: live model is %d / %d, the batch assumes 62 / 11220132"
          % (len(names), tot)); bad += 1
print("          arm `layerwise` = m %d;  arm `scalar` = m 1" % len(names))

# ---- 4b: THE UPDATE RULE, QUOTED OFF THE LIVE SOURCE.  The whole design
# ---- rests on |dbeta| = ms EXACTLY, so it is verified, not assumed.
src = inspect.getsource(HF.Lion_meta_update)
print("guard 4b: HF.Lion_meta_update, verbatim from the LIVE source:")
for ln in src.rstrip().split("\n"):
    print("          %s" % ln)
if "torch.sign(" not in src:
    print("!!! guard 4b: the meta update is NOT sign-based"); bad += 1
m = re.search(r"self\.beta\[i\]\s*=\s*\(1-self\.args_meta\['meta_stepsize'\]"
              r"\*self\.args_meta\['weight_decay'\]\)\*self\.beta\[i\]\s*-\s*"
              r"self\.args_meta\['meta_stepsize'\]\s*\*\s*torch\.sign", src)
if not m:
    print("!!! guard 4b: the update is not the registered "
          "(1-ms*wd)*beta - ms*sign(...) form"); bad += 1
else:
    print("guard 4b: CONFIRMED -- with --weight-decay-meta 0 this is exactly")
    print("          beta <- beta - ms*sign(.), so |dbeta| = ms PER META-STEP.")

# ---- 4b2: block_product's scalar branch is the UNNORMALISED SUM ------------
sbp = inspect.getsource(HF.block_product)
first = [l for l in sbp.split("\n") if "stepsize_type == 'scalar'" in l]
after = sbp.split("stepsize_type == 'scalar'", 1)[1].split("\n")[1].strip()
print("guard 4b2: block_product's scalar branch, verbatim:")
print("           %s" % after)
if "sum(" not in after:
    print("!!! guard 4b2: the scalar branch is not a sum"); bad += 1

# ---- 4c: BETA_CLIP is parsed from the environment --------------------------
si = inspect.getsource(HF.__init__)
if "BETA_CLIP" in si and "_beta_lo" in si:
    print("guard 4c: BETA_CLIP is parsed from the environment into "
          "(_beta_lo,_beta_hi)")
else:
    print("!!! guard 4c: live HF.__init__ does not parse BETA_CLIP as assumed")
    bad += 1

# ---- 4d: `scalar` and `layerwise` are BOTH named granularities -------------
im = inspect.getsource(HF.init_meta)
mm = re.search(r"stepsize_groups\s+in\s+\[([^\]]*)\]", im)
named = [x.strip().strip("'\"") for x in mm.group(1).split(",")] if mm else []
print("guard 4d: init_meta's exact-match routing list: %s" % named)
for g in ("scalar",):
    if g not in named:
        print("!!! guard 4d: `%s` is NOT in init_meta's named list" % g); bad += 1
print("guard 4d: DISCLOSED CONFOUND, registered in advance -- `scalar` takes its")
print("          OWN m=1 code path (block_product's scalar branch), `layerwise`")
print("          takes the layerwise branch.  This is a property of the CONTRAST")
print("          itself, is identical at EVERY rung of the ladder, and therefore")
print("          cannot produce a ms-dependence.  It is exactly what the ladder")
print("          holds fixed while ms and alpha0 move.")

# ---- 4e: THE REACHABILITY TABLE, the arithmetic the whole design rests on ---
lo, hi = [float(x) for x in clip_c.split(":")]
steps = epochs * (50000 // bsz)
print("guard 4e: %d epochs x %d meta-steps/epoch = %d meta-steps; clip [%g, %g]"
      % (epochs, 50000 // bsz, steps, lo, hi))
print("          %-6s %-6s %9s %8s %8s %11s %11s  %s"
      % ("ms", "a0", "TRAVEL", "D_up", "T/D_up", "alpha_max", "alpha_min", "status"))
frozen = []
for a0, mss in ((a0a, msa), (a0b, msb)):
    for ms in mss:
        b0 = math.log(float(a0)); T = steps * float(ms); du = hi - b0
        amax = math.exp(min(hi, b0 + T)); amin = math.exp(max(lo, b0 - T))
        st = ("FROZEN" if T < 0.5 * du else "STARVED" if T < du
              else "ADEQUATE" if T < 3 * du else "FREE")
        if st == "FROZEN":
            frozen.append((ms, a0))
        print("          %-6s %-6s %9.2f %8.3f %8.3f %11.4e %11.4e  %s"
              % (ms, a0, T, du, T / du, amax, amin, st))
want = [("1e-5", a0a), ("3e-5", a0a), ("1e-4", a0b)]
if sorted(frozen) != sorted(want):
    print("!!! guard 4e: FROZEN rungs %s, registered %s" % (frozen, want))
    bad += 1
else:
    print("guard 4e: the FROZEN rungs are exactly the registered three.")
    print("          ms=1e-4 at alpha0=1e-6 can NEVER exceed alpha = %.4e -- that"
          % math.exp(math.log(float(a0b)) + steps * 1e-4))
    print("          is WHY the corpus has no such row, and it is why a ladder")
    print("          in ms alone cannot break CORRECTIONS 160's alias.")

# ---- 4f: the crossing, and the free-horizon precondition -------------------
shared = sorted(set(msa) & set(msb), key=float)
print("guard 4f: ms levels present at BOTH alpha0: %s (%d of %d)"
      % (shared, len(shared), len(msa)))
if len(shared) < 4:
    print("!!! guard 4f: fewer than four crossed ms levels -- the alias is not "
          "broken"); bad += 1
tp = os.path.join(cif, "train.py")
srcl = open(tp).read().split("\n")
hits = [(i + 1, l.strip()) for i, l in enumerate(srcl)
        if "num_epochs" in l or "num-epochs" in l]
decl = [h for h in hits if "add_argument" in h[1]]
loop = [h for h in hits if h[1].startswith("for epoch in range(")]
other = [h for h in hits if h not in decl and h not in loop]
print("guard 4f: num_epochs in the LIVE train.py: %d (decl %d, loop %d, other %d)"
      % (len(hits), len(decl), len(loop), len(other)))
if not (len(decl) == 1 and len(loop) == 1 and not other):
    print("!!! guard 4f: num_epochs is used somewhere other than the loop bound")
    bad += 1
sched = [(i + 1, l.strip()) for i, l in enumerate(srcl) if "scheduler" in l.lower()]
if sched:
    print("!!! guard 4f: train.py mentions a scheduler:")
    for ln, txt in sched:
        print("          %4d  %s" % (ln, txt))

# ---- 4g: PROBE actually needs PROBE_DIR ------------------------------------
sp = inspect.getsource(HF._probe_init) if hasattr(HF, "_probe_init") else ""
whole = open(os.path.join(cif, "Optimizers", "HF.py")).read()
if "PROBE_DIR" in whole and "os.environ.get('PROBE'" in whole:
    print("guard 4g: PROBE and PROBE_DIR are BOTH read from the environment;")
    print("          the launcher sets both, so the probe is not a silent no-op.")
else:
    print("!!! guard 4g: PROBE/PROBE_DIR are not read as assumed"); bad += 1

raise SystemExit(1 if bad else 0)
PYEOF

# ---- guard 4h: the launcher's ladders and the scorer's LADDER agree --------
python3 - "$SC" "$A0_A" "$MS_A" "$A0_B" "$MS_B" "$G_SC" "$G_LAY" <<'PYEOF' \
  || guard_fail "guard 4h: the launcher's ladders and the scorer's LADDER disagree"
import sys, importlib.util
spec = importlib.util.spec_from_file_location("cy1", sys.argv[1])
m = importlib.util.module_from_spec(spec); spec.loader.exec_module(m)
mine = {sys.argv[2]: tuple(sys.argv[3].split()),
        sys.argv[4]: tuple(sys.argv[5].split())}
bad = 0
if mine != dict(m.LADDER):
    print("!!! guard 4h: launcher %r vs scorer %r" % (mine, dict(m.LADDER))); bad += 1
if m.GRAN != {"sc": sys.argv[6], "lay": sys.argv[7]}:
    print("!!! guard 4h: arm specs differ: scorer %r" % (m.GRAN,)); bad += 1
if m.N_JOBS != 60 or m.SEEDS != (15, 16, 17) or m.EPOCHS != 100 \
   or m.PROBE_EVERY != 100 or m.CLIP_C != "-15:-2.3026":
    print("!!! guard 4h: scorer design constants differ"); bad += 1
if bad:
    raise SystemExit(1)
print("guard 4h: launcher and scorer agree on both ladders, both arm specs,")
print("          60 jobs, seeds (15,16,17), 100 epochs, PROBE=100, clip %s"
      % m.CLIP_C)
print("          SIGMA_W %.6f  SE_GAP %.6f  BAR_GAP %.6f  BAR_DGAP %.6f"
      % (m.SIGMA_W, m.SE_GAP, m.BAR_GAP, m.BAR_DGAP))
PYEOF

# ---- guard 4i: THE LIVE HF.py's IDENTITY IS PINNED, AND A SIBLING BATCH'S
# ---- OPT-IN PATCH IS PROVED INERT FOR THIS BATCH'S SPECS --------------------
# A sibling batch in this same 24 h window ships patches/patch_rednorm.py, which
# rewrites HF.block_product's reduction.  That patch is OPT-IN BY SPEC PREFIX:
# it sets self._rednorm = stepsize_groups.startswith('tn:'), and its own header
# records that every pre-existing spec "fails the test and gets _rednorm =
# False, which is the state every prior run was in implicitly."  NONE of this
# batch's 60 command lines carries a `tn:` prefix -- both specs are the bare
# words `scalar` and `layerwise`, and the scorer's G1 re-checks every landed
# run's own ARGS line against exactly those two strings.  So a mid-flight
# application of PATCH_REDNORM is BEHAVIOURALLY INERT here.  The sha256 below
# pins what was live at submit time so the claim is checkable afterwards.
HFLIVE="$CIF/Optimizers/HF.py"
PROV="$SAVE/PROVENANCE.txt"
mkdir -p "$SAVE"
if [ -f "$HFLIVE" ]; then
  HFSHA=$( (sha256sum "$HFLIVE" 2>/dev/null || shasum -a 256 "$HFLIVE") | awk '{print $1}')
  NRED=$(grep -c 'PATCH_REDNORM' "$HFLIVE" 2>/dev/null); NRED=${NRED:-0}
  echo "guard 4i: live HF.py sha256 $HFSHA"
  echo "guard 4i: PATCH_REDNORM markers in the live HF.py at submit time: $NRED"
  echo "          (inert for this batch either way -- no spec here starts with tn:)"
  { echo "HF_SHA256 $HFSHA"; echo "PATCH_REDNORM_MARKERS $NRED";
    echo "SUBMIT_UTC $(date -u +%Y-%m-%dT%H:%M:%SZ)";
    echo "SPECS scalar layerwise"; } > "$PROV"
  echo "guard 4i: provenance written to $PROV"
else
  guard_fail "guard 4i: no live HF.py at $HFLIVE"
fi

# ---- guard 5: capacity, walltime and partitions -----------------------------
FREE=$(df -BG "$WS" 2>/dev/null | tail -1 | awk '{print $4}' | tr -d 'G')
PEND=$(squeue -h -u "$USER_NAME" -t PENDING 2>/dev/null | wc -l | tr -d ' ')
echo "guard 5: ${FREE:-?} GB free on \$WS; $PEND jobs pending, adding 60"
[ "${PEND:-0}" -le 40 ] || guard_fail "guard 5: $PEND pending, over cap"
for P in $(echo "$PARTS" | tr ',' ' '); do
  TL=$(sinfo -h -p "$P" -o '%l' 2>/dev/null | head -1)

  D=$(squeue -h -p "$P" -t PENDING 2>/dev/null | wc -l | tr -d ' ')

  case "$TL" in

# ---- compose, guard each line under RULE 20, then submit --------------------
. "$REPO/bin/_lib_guards.sh"
DESIGN=(alg-base=SGDm alg-meta=Lion num-epochs=$EPOCHS batch-size=$BATCH \
        gamma=$GAMMA dataset=$DSET NN-name=$NET weight-decay-meta=0)

N=0; REJ=0; BAD=0
for S in $SEEDS; do
  for LAD in A B; do
    case $LAD in
      A) A0=$A0_A; MSS="$MS_A" ;;
      B) A0=$A0_B; MSS="$MS_B" ;;
    esac
    for MST in $MSS; do
      for ARM in sc lay; do
        case $ARM in
          sc)  G=$G_SC ;;
          lay) G=$G_LAY ;;
        esac
        RN="cru1-$ARM-m$MST-a$A0-s$S"
        PDIR="$SAVE/probe_$RN"
        CMD="sbatch --job-name=$RN --partition=$PARTS --gres=gpu:1 --cpus-per-task=6 \

$RUNNER --optimizer HF --alg-base SGDm --momentum-param-base 0.99 \
--weight-decay-base 0.1 --alg-meta Lion --momentum-param-meta 0.99 --Lion-beta2-meta 0.9 \
--weight-decay-meta 0 --dataset $DSET --NN-name $NET --batch-size $BATCH --max-time 999:00:00 \
--gamma $GAMMA --meta-stepsize $MST --alpha0 $A0 --num-epochs $EPOCHS \
--stepsize-groups $G --seed $S --save-directory $SAVE --run-name $RN"
        if guard_presubmit "$CMD" "${DESIGN[@]}" >/dev/null 2>&1; then :; else
          echo "!!! RULE 20 PRE-CHECK FAILED for $RN"
          guard_presubmit "$CMD" "${DESIGN[@]}"; BAD=$((BAD+1))

        # the three AXES must round-trip as ONE value each
