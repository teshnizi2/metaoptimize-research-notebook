# Nothing here touches the other account and nothing is submitted to cluster_a.

# REGISTERED SCORER: analysis/cO1_cfr1_score.py, git-committed BEFORE this
# batch is submitted (STANDING RULE 21).  Every bar is frozen there, and its
# --selftest re-derives the noise floor, the corpus's own clamped gap, the
# released floor's float32 arithmetic and MASTER-TABLE row 106's truncation
# asymmetry from the corpus, and asserts each constant against THIS FILE'S own
# text.
#
# NO CODE PATCH.  BETA_CLIP and PROBE are already environment variables read by
# Optimizers/HF.py; guard 4e below re-derives that from the LIVE source on this
# account rather than assuming it, and submits nothing if it is not true.
#
# -----------------------------------------------------------------------------
# THE THREAT
# -----------------------------------------------------------------------------
# MASTER-TABLE row 24 is the LAST UNDISCHARGED THREAT to a MASTER-TABLE row:
#
#   "Falloff above the peak: scalar 5.871 vs blk6 1.060, layerwise 1.801,
#    nodewise 2.593 pp/decade.  THE CORRECT SENTENCE: partitioning buys
#    TOLERANCE to an over-large meta-stepsize, not peak accuracy."   CONFIRMED
#
# Every number in it lives ABOVE each arm's meta-stepsize optimum, and the
# corpus-wide clamp census (CORRECTIONS 148) measured that region to be the
# CLAMPED region for the partitioned arm and the INTERIOR region for scalar:
# at ms = 1e-3 scalar binds 0/33 corpus-wide while every layerwise rung on
# R10, R18 and ResNet18_c100 binds 100%.  The -15 floor is a stabiliser that
# catches exactly the runaway groups an over-large meta-stepsize produces, so
# "the fine arm degrades more slowly" and "the fine arm's runaway groups hit a
# wall the scalar arm never reaches" are the SAME observation until something
# separates them.  Row 24 has no clamp-free replicate: of the 24 non-canonical
# -box cells in the corpus only `tc1` and `ub9` contain a scalar arm, `tc1` was
# measured NOT clamp-free (CORRECTIONS 149) and `ub9` gave a two-wall
# ambiguous, cross-batch, cross-account null at 0.22 SE.
#
# -----------------------------------------------------------------------------
# THE DESIGN.  2 granularities x 2 boxes x 3 seeds = 12 jobs, ONE submission.
#
#   factor A  granularity  sc  = scalar     (m = 1  beta coordinate)
#                          lay = layerwise  (m = 62 beta coordinates)
#   factor B  box          C = CLAMPED  -15:-2.3026  (campaign standard)
#                          R = RELEASED -80:-2.3026  (floor released, SAME
#                                                     ceiling -- ONE FACTOR)
#
#   ResNet18 / CIFAR-10 / SGDm base / Lion meta / meta-stepsize 1e-3 /
#   alpha0 1e-3 / 100 ep / batch 100 / gamma 1 / AUGMENT=1 / HIER unset /
#   SCHED none / PROBE=100 with a per-run PROBE_DIR.
#
#   ESTIMAND  DID = [lay - sc]_RELEASED - [lay - sc]_CLAMPED, all four cells
#   IN BATCH so the cross-batch floor cancels outright.  BATCH is the unit of
#   replication (F(62,85) = 5.47, p 6.9e-13; seed is null, F(11,1976) = 0.152),
#   so no other batch's arms are spliced in -- not the c40 `rs-` surface row 24
#   is built on, not `tc1`, not `ub9`.
#
#   THE PREVIOUSLY WRITTEN "Step 1" IN docs/STATUS.md IS NOT INHERITED.  It
#   specified box {-15:-2.3026, -30:6.0}, which moves BOTH walls -- exactly the
#   defect that made CORRECTIONS 149's null ambiguous.  The ceiling is held.
#
# -----------------------------------------------------------------------------
# ONLY ms = 1e-3 IS RUN, AND THAT IS ARITHMETIC, NOT THRIFT
# -----------------------------------------------------------------------------
# With --weight-decay-meta 0 the Lion meta-update is beta <- beta - ms*sign(.)
# with sign(.) in {-1,0,+1}, so |dbeta| <= ms EXACTLY per meta-step and over T
# meta-steps beta is confined to [ln a0 - ms*T, ln a0 + ms*T].  At alpha0=1e-3
# (beta init = float32 log(1e-3) = -6.907755) and T = 50000 (100 epochs x 500
# iterations of CIFAR-10 at batch 100, no drop_last):
#
#   ms = 1e-4   beta >= -11.914545 in float32, i.e. 3.085455 nats ABOVE the -15
#               floor.  THE FLOOR IS UNREACHABLE AT THE TUNED META-STEPSIZE, so
#               releasing it there is a null BY CONSTRUCTION.  No arm is needed.
#   ms = 1e-3   beta >= -56.888439 in float32.  The floor is reachable with
#               8092 meta-steps to spare, and the census measures layerwise
#               binding it 100% of the time.
#
# So the entire box-dependence of row 24's falloff lives at ms = 1e-3 and the
# four cells run here capture all of it.  guard 4e re-derives both bounds from
# the live source; the scorer's --selftest re-derives them again in float32.
#
# -----------------------------------------------------------------------------
# WHY THE RELEASED FLOOR IS -80
# -----------------------------------------------------------------------------
# -80.0 is 23.111561 nats below -56.888439 -- 23111 meta-steps that do not
# exist.  It is non-binding BY CONSTRUCTION, not merely by observation, and the
# scorer's R1 still checks it EMPIRICALLY on every released run's own probe,
# treating any run that comes within 0.1004 nats of -80 as a FAILED
# MANIPULATION and the batch as UNRESOLVED, not as evidence.
# alpha = exp(-56.888439) = 1.96e-25 is a normal float32 (smallest normal
# 1.18e-38), so releasing the floor introduces no underflow.
#
# THE CEILING IS HELD AT -2.3026 IN BOTH BOXES.  The price is a declared scope
# limit -- a SURVIVES verdict discharges the FLOOR half of the threat only --
# and that half is MEASURED HERE FOR FREE: the probe reports per-coordinate
# ceiling occupancy, so if no clamped layerwise run ever puts a coordinate on
# the ceiling then the floor is the only wall at this cell and the audit is
# complete.  Releasing the ceiling as a third level was considered and REFUSED:
# FINDINGS 6190-6215 measured 2/2 FATAL COLLAPSES on releasing the ceiling to
# +6.0, and a diverged arm is UNRESOLVED-DIVERGED by the scorer's R2 -- it
# would cost 6 GPU-hours and could answer nothing.
#
# -----------------------------------------------------------------------------
# NO blk6 ARM -- A REFUSAL WITH A REASON, RE-DERIVED FROM THE CSV
# -----------------------------------------------------------------------------
# Row 24's blk6 (1.060) and nodewise (2.593) falloffs come from the c40 `rs-`
# response surface, and MASTER-TABLE row 106 measured that surface's truncation
# to be GRANULARITY-ASYMMETRIC.  Re-derived over the 67 `rs-` rows: scalar
# 0/22 truncated, layerwise 0/22, resnet18_blocks 6/13, nodewise 6/10.  A blk6
# arm here would audit a falloff number row 106 has already REFUTED, at +50%
# cost and with a second, uncorrected estimand.  scalar and layerwise are
# exactly the two arms of row 24 whose numbers survive that audit.  If the
# verdict comes back WALL-DRIVEN, blk6 (censused at 68.8% binding, between
# scalar's 0% and layerwise's 100%) is the registered dose-response follow-up.
#
# -----------------------------------------------------------------------------
# PROBE=100, AND WHY THE INTERVAL IS EXACT RATHER THAN A SAMPLE
# -----------------------------------------------------------------------------
# The manipulation check must be at the COORDINATE denominator (FINDINGS 51.1)
# and over the FULL trajectory (CORRECTIONS 149.7: sampled occupancy rates are
# LOWER BOUNDS).  TensorBoard cannot supply either here: HF.py emits beta
# scalars only for stepsize_type in {scalar, blockwise} and `layerwise` EMITS
# NONE, so the fine arm is unauditable without the probe.  PROBE is therefore
# not optional for this batch, and it is set IDENTICALLY on all 12 runs so it
# cannot enter the contrast.
#
# PROBE is an INTERVAL, not a flag (_probe_every = int(PROBE)).  PROBE=1 writes
# a record on every one of the 50000 meta-steps, each doing ~62 device-to-host
# syncs for h_absmax.  PROBE=100 writes 499 records per run (~2 MB) for ~3 s of
# syncs against a ~45 min run.
#
# THE COARSE INTERVAL COSTS NOTHING IN RESOLUTION.  |dbeta| <= ms per meta-step
# bounds the movement over one stride by ms*PROBE = 0.1 nats, so if a
# coordinate touches a wall at ANY meta-step it is still within 0.1 nats of
# that wall at the next sampled record.  The detector
#       REACHED(wall) := min over records of beta_true_min <= wall + 0.1004
# therefore has NO FALSE NEGATIVES -- it is EXACT for "some coordinate reached
# the wall at some meta-step", not a lower bound.  That is the direct answer to
# CORRECTIONS 149.7.  The exact-equality counter n_at_lo (PATCH_CLIPCOUNT,
# tolerance 1e-6) has no FALSE POSITIVES and is reported beside it as the lower
# bound; both are printed for every run.
#
# The probe fields the scorer reads are written by PATCH_CLIP / PATCH_CLIPCOUNT
# in HF._probe and none is derived at score time: beta_true_min, beta_true_max,
# n_at_lo, n_at_hi, n_beta.  n_beta is checked against the registered
# coordinate count (1 for scalar, 62 for layerwise) so a per-tensor-MEAN
# reading can never be mistaken for a coordinate one.
#
# -----------------------------------------------------------------------------
# THE PRE-REGISTRATION lives in analysis/cO1_cfr1_score.py and is summarised
# here.  Gates fire IN ORDER; the first failure decides.
#   G0 provenance: 12 runs, 4 cells x 3 seeds, 12 job ids, 100/100 epochs, no
#      repeated flag, and every run's NAME agreeing with its own ARGS and ENV.
#      BETA_CLIP and PROBE cannot ride the ARGS line and are audited from the
#      ENV line.
#   R1 MANIPULATION: every RELEASED run must stay strictly above -80 + 0.1004
#      with n_at_lo = 0 at every record; every run must carry >= 400 records
#      and the registered coordinate count.  Unreadable probes fail CLOSED to
#      UNRESOLVED-MANIPULATION-UNCHECKED.
#   R2 DIVERGENCE: any run with < 100 epochs, non-finite metrics or
#      plateau5 <= 15.00 pp (CIFAR-10 chance is 10.00) is DEAD ->
#      UNRESOLVED-DIVERGED.  Registered in advance precisely so that "the
#      released arms failed to train" can NEVER be scored as "the tolerance
#      collapsed".
#   R3 NOISE: any cell SD above 3*sigma_w = 0.6480 pp -> UNRESOLVED-NOISY.
#   R4 PREMISE, both halves: G_C >= 1.6792 pp (half the corpus's own clamped
#      gap 3.3585 pp) AND at least 2 of 3 CLAMPED LAYERWISE runs must actually
#      have reached the -15 floor.  If the clamped fine arm never binds there
#      is no wall to release and a null is null BY CONSTRUCTION ->
#      UNRESOLVED-PREMISE-NOWALL.
#   VERDICT on DID = G_R - G_C at the registered bar 2*SE_DID = 0.4988 pp:
#      |DID| <= 0.4988                    ROW24-SURVIVES     (tolerance is the
#                                         PARTITION; row 24 stands)
#      DID <= -0.4988, G_R >= 1.6792      ROW24-ATTENUATED   (magnitude
#                                         restated with the released number)
#      DID <= -0.4988, G_R <  1.6792      ROW24-WALL-DRIVEN  (row 24 REWRITTEN)
#      DID >= +0.4988                     ROW24-BOX-SUPPRESSED
#   NOISE FLOOR re-derived from results/all_runs.csv, not quoted: pooled within
#   (batch family x granularity x meta-stepsize) SD of plateau5 over the
#   canonical-box ResNet18/CIFAR-10/SGDm+Lion/alpha0=1e-3/AUGMENT=1 stratum
#   restricted to scalar and layerwise = 0.2160 pp, df 76, 30 cells.
#   SE(gap) = sigma*sqrt(2/3) = 0.1764; SE(DID) = sigma*sqrt(4/3) = 0.2494.
#
# MAY NOT CLAIM: anything about any other meta-stepsize, alpha0, dataset,
# architecture, optimiser pair, granularity or box; the CEILING as a wall
# beyond the disclosed diagnostic; any splice with another batch's arms; or
# row 24's FITTED pp/decade slope, which is a multi-rung object this batch does
# not measure.  What is measured is the GAP one decade above the shared
# optimum, under two boxes.
#
# WALLTIME, MEASURED not guessed.  On THIS account the corpus holds 191
# completed 100-epoch ResNet18/CIFAR-10 layerwise runs (mean 42.9 min, max

# USAGE   bash bin/cO1_floor_release_row24.sh            # dry run, submits nothing
#         bash bin/cO1_floor_release_row24.sh --submit

# ---- guard 2: RULE 21 premise -- no run of this batch may exist yet ---------
grep -q '^cfr1-' "$CSVP" && guard_fail "guard 2: cfr1-* already in the CSV" \

# ---- guard 4: THE LIVE MODEL AND THE LIVE OPTIMISER SOURCE ------------------

# real network on this account, not by parsing a string: the coordinate count
# each arm actually gets is read off HF.beta, the per-tensor names and sizes
# are printed, and the clamp/meta-update arithmetic the released floor rests on
# is re-derived from the live source.  Nothing is submitted if any of it fails.
mkdir -p "$SAVE"
MANIFEST="$SAVE/PARTITION-MANIFEST.txt"

NA=$(echo $ARMS | wc -w | tr -d ' ')

[ "${CLIP_C#*:}" = "${CLIP_R#*:}" ] \
  && echo "guard 4c: both boxes share the ceiling ${CLIP_C#*:}" \
  || guard_fail "guard 4c: the two boxes differ in the CEILING as well as the floor"

  || guard_fail "guard 4c: the two boxes have the SAME floor; there is no manipulation"

python3 - "$CIF" "$MANIFEST" "$NTENS" "$CLIP_C" "$CLIP_R" "$G_SC" "$G_LAY" \
         "$ALPHA0" "$MST" "$EPOCHS" "$BATCH" <<'PYEOF' \
  || guard_fail "guard 4: live model / optimiser / clamp check FAILED"
import sys, os, inspect, math
cif, out, ntens = sys.argv[1], sys.argv[2], int(sys.argv[3])
clip_c, clip_r = sys.argv[4], sys.argv[5]
g_sc, g_lay = sys.argv[6], sys.argv[7]
alpha0, mst = float(sys.argv[8]), float(sys.argv[9])
epochs, bs = int(sys.argv[10]), int(sys.argv[11])
sys.path.insert(0, cif)
os.chdir(cif)
os.environ['BETA_CLIP'] = clip_c
import numpy as np
from build_network import build_network
from Optimizers.HF import HF
net = build_network("ResNet18", "cpu")
nps = [(n, p.data.size()) for n, p in net.named_parameters()]
names = [n for n, _ in net.named_parameters()]
numel = [int(p.numel()) for _, p in net.named_parameters()]
tot = sum(numel)
T = len(nps)
bad = 0
lines = ["NUM_PARAM_TENSORS %d" % T, "TOTAL_PARAMS %d" % tot,
         "CLIP_C %s" % clip_c, "CLIP_R %s" % clip_r]
print("guard 4: live ResNet18 (CIFAR-10 head) has %d parameter tensors, "
      "%d parameters" % (T, tot))
if T != ntens:
    print("!!! guard 4: the live model has %d tensors, the batch assumes %d"
          % (T, ntens))
    raise SystemExit(1)

print("guard 4: the full tensor manifest -- index, name, parameter count:")
for i in range(T):
    print("         %2d  %-34s %9d" % (i + 1, names[i], numel[i]))
    lines.append("TENSOR %d %s %d" % (i + 1, names[i], numel[i]))

# ---- guard 4a: the coordinate count each arm ACTUALLY gets, from HF.beta ----
ab = dict(alg='SGDm', weight_decay=0.1, momentum_param=0.99)
am = dict(alg='Lion', meta_stepsize=mst, momentum_param=0.99,
          Lion_beta2=0.9, weight_decay=0)
want = {g_sc: 1, g_lay: T}
for spec in (g_sc, g_lay):
    o = HF(net, spec, alpha0, ab, am, 1, writer=None)
    coords = sum(int(b.numel()) for b in o.beta)
    binit = float(o.beta[0].reshape(-1)[0])
    okt = (o.stepsize_type == spec)
    okc = (coords == want[spec])
    print("guard 4a: %-10s stepsize_type=%-10s beta blocks %d  COORDINATES %d "
          "(want %d)  beta init %.6f  box (%.4f, %.4f)"
          % (spec, o.stepsize_type, len(o.beta), coords, want[spec], binit,
             o._beta_lo, o._beta_hi))
    lines.append("ARM %s TYPE %s COORDS %d PARAMS %d BETA_INIT %.6f"
                 % (spec, o.stepsize_type, coords, tot, binit))
    if not (okt and okc):
        print("!!! guard 4a: %s did not compose to the registered granularity"
              % spec)
        bad += 1
    if abs(binit - float(np.float32(np.log(np.float32(alpha0))))) > 5e-6:
        print("!!! guard 4a: beta init %.8f is not float32 log(alpha0)" % binit)
        bad += 1
    if o._beta_lo != float(clip_c.split(':')[0]) or \
       o._beta_hi != float(clip_c.split(':')[1]):
        print("!!! guard 4a: the live optimiser did not parse BETA_CLIP=%s"
              % clip_c)
        bad += 1

# ---- guard 4e: the clamp and the meta update, ON THE LIVE SOURCE ------------
src_init = inspect.getsource(HF.__init__)
if "BETA_CLIP" in src_init and "_beta_lo" in src_init and \
        "split(':')" in src_init.replace('"', "'"):
    print("guard 4e: BETA_CLIP is parsed from the environment into "
          "(_beta_lo, _beta_hi) on the live source")
else:
    print("!!! guard 4e: the live HF.__init__ does not parse BETA_CLIP as assumed")
    bad += 1
src_step = ""
_m = None
for _cand in ("step", "update", "__call__"):
    if hasattr(HF, _cand):
        _s = inspect.getsource(getattr(HF, _cand))
        if "_beta_lo" in _s:
            src_step, _m = _s, _cand
            break
_flat = "".join(src_step.split())
if "clamp(self._beta_lo,self._beta_hi)" in _flat:
    print("guard 4e: the clamp is applied to beta AFTER the meta update, in "
          "HF.%s" % _m)
else:
    print("!!! guard 4e: could not find beta.clamp(_beta_lo, _beta_hi) in the "
          "live update path")
    bad += 1
src_lion = inspect.getsource(HF.Lion_meta_update)
if "torch.sign" in src_lion and "meta_stepsize" in src_lion:
    print("guard 4e: Lion_meta_update moves beta by meta_stepsize * sign(.)")
else:
    print("!!! guard 4e: Lion_meta_update is not the sign-bounded update the "
          "released floor's justification assumes")
    bad += 1

# ---- guard 4f: the travel bound, in float32, for THIS cell ------------------
# The meta-step COUNT is the whole basis of the floor arithmetic, so it is
# MEASURED off the staged dataset rather than assumed.  DataLoader is built
# with no drop_last, so iterations per epoch = ceil(len(trainset)/batch_size).
_ntrain, _ntrain_src = None, "assumed"
try:
    from torchvision import datasets as _ds
    _ntrain = len(_ds.CIFAR10(root='./data', train=True, download=False))
    _ntrain_src = "measured on the staged dataset"
except Exception as _e:
    _ntrain = 50000
    print("    guard 4f: NOTE -- could not read the staged CIFAR-10 (%s); "
          "falling back to 50000" % repr(_e)[:80])
iters = -(-_ntrain // bs)
print("guard 4f: train set %d images (%s), batch %d, no drop_last -> %d "
      "iterations/epoch" % (_ntrain, _ntrain_src, bs, iters))
steps = epochs * iters
b0 = np.float32(np.log(np.float32(alpha0)))
lo = np.float32(b0)
for _ in range(steps):
    lo = np.float32(lo - np.float32(mst))
hi = np.float32(b0)
for _ in range(steps):
    hi = np.float32(hi + np.float32(mst))
fl_c = float(clip_c.split(':')[0]); ce = float(clip_c.split(':')[1])
fl_r = float(clip_r.split(':')[0])
print("guard 4f: %d meta-steps (%d epochs x %d iterations); float32 travel "
      "bound [%.6f, %.6f]" % (steps, epochs, iters, float(lo), float(hi)))
print("          the CLAMPED floor %.1f IS reachable  (%.6f nats of headroom, "
      "%d meta-steps)" % (fl_c, float(b0) - fl_c, int((fl_c - float(lo)) / mst)))
print("          the RELEASED floor %.1f is NOT reachable: %.6f nats below the "
      "bound = %d meta-steps that do not exist"
      % (fl_r, float(lo) - fl_r, int((float(lo) - fl_r) / mst)))
print("          alpha at the reachable minimum exp(%.6f) = %.3e, a normal "
      "float32" % (float(lo), math.exp(float(lo))))
lines.append("META_STEPS %d TRAVEL_LO %.6f TRAVEL_HI %.6f" % (steps, float(lo), float(hi)))
if not (fl_r < float(lo) < fl_c):
    print("!!! guard 4f: the released floor is NOT strictly unreachable, or the "
          "clamped floor is NOT reachable, at this cell")
    bad += 1
# and the same at the tuned meta-stepsize, which is why no arm is run there

    lo4 = np.float32(lo4 - np.float32(1e-4))

if float(lo4) <= fl_c:
