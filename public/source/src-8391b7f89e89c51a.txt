#       --weight-decay-meta 0 the Lion meta-update is beta <- beta - ms*sign(.)
#       with sign(.) in {-1,0,+1}, so |dbeta| <= ms EXACTLY per meta-step and
#       over T meta-steps beta lies in [ln a0 - ms*T, ln a0 + ms*T].  At
#       alpha0 = 1e-3 (beta init = float32 log(1e-3) = -6.907755) and
#       T = 50000 (100 epochs x 500 iterations of CIFAR-10 at batch 100, no
#       drop_last), simulated in float32:
#         ms = 1e-4  beta >= -11.914545 -- the -15 floor is UNREACHABLE, so
#                    releasing it at the tuned rung is a null BY CONSTRUCTION
#                    and no arm is run there (cfr1 made the same call).
#         ms = 3e-4  beta >= -21.907576 -- the -15 floor IS reachable, with
#                    6.907576 nats (23025 meta-steps) of travel to spare.  It
#                    is first attainable at meta-step 26975 = 53.95% of
#                    training, so AT MOST 46.05% of a run can be exposed to it,
#                    against 83.81% at cfr1's rung.

#       do not exist, against 23111 at cfr1's rung.  THE RELEASED FLOOR IS MORE
#       UNREACHABLE HERE, NOT LESS, so the one-factor instrument transfers with
#       a wider margin.  alpha = exp(-21.907576) = 3.06e-10 is a normal float32
#       (smallest normal 1.18e-38); no underflow.

#       ms=3e-4 runs above, 15/15 reach exactly -15.0000, first arrival at
#       meta-step 27005-27395 against the theoretical earliest 26975 (i.e. the
#       fastest coordinate falls at 98.5-99.9% of the maximum rate) and floor
#       occupancy 45.2-46.0% of records against the 46.05% ceiling.
#   (c) MEASURED AT m = 62, on cfr1's rung: cfr1's three RELEASED layerwise
#       runs bottom at -56.60 / -56.51 / -56.57 against the -56.888439 bound --
#       99.4-99.6% of maximum descent, monotone, first crossing -15 at
#       meta-step 8300-8400 against the earliest possible 8093.
#   (b) and (c) bracket the untested corner (m = 62 AT ms = 3e-4); neither
#   measures it.  This batch's clamped layerwise arm measures it, and that
#   measurement is a deliverable WHATEVER the DID does.
#
# -----------------------------------------------------------------------------
# THE DESIGN.  2 granularities x 2 boxes x 3 seeds = 12 jobs, ONE submission.
#
#   factor A  granularity  sc  = scalar     (m = 1  beta coordinate)
#                          lay = layerwise  (m = 62 beta coordinates)
#   factor B  box          C = CLAMPED  -15:-2.3026  (campaign standard)
#                          R = RELEASED -80:-2.3026  (floor released, SAME
#                                                     ceiling -- ONE FACTOR)

#   ResNet18 / CIFAR-10 / SGDm base / Lion meta / meta-stepsize 3e-4 /
#   alpha0 1e-3 / 100 ep / batch 100 / gamma 1 / AUGMENT=1 / HIER unset /
#   SCHED none / PROBE=100 with a per-run PROBE_DIR.
#   ONLY `--meta-stepsize` DIFFERS FROM cfr1.  Every other flag and every
#   environment variable is byte-identical to bin/cO1_floor_release_row24.sh,
#   so ms is the only thing that separates the two rungs of one audit.
#
#   ESTIMAND  DID = [lay - sc]_RELEASED - [lay - sc]_CLAMPED, all four cells
#   IN BATCH so the cross-batch floor cancels outright.  BATCH is the unit of
#   replication (F(62,85) = 5.47, p 6.9e-13; seed is null, F(11,1976) = 0.152),
#   so no other batch's arms are spliced in -- not `rs-`, which is this rung's
#   ENTIRE corpus cell at n = 5 v 5 in a single family, and not `cfr1`.
#
# -----------------------------------------------------------------------------
# NO blk6 ARM AT THIS RUNG -- A REFUSAL WITH THREE REASONS, RE-DERIVED
# -----------------------------------------------------------------------------
#  (i)  THE DOSE-RESPONSE IS NOT DEFINED HERE.  The 0% / 68.8% / 100%
#       scalar/blk6/layerwise binding ladder is CORRECTIONS 148.5's
#       `Core set, ms=1e-3` table.  At ms=3e-4 blk6's binding rate is
#       UNMEASURED -- zero of the 15 probed runs at this rung is blk6.  Adding

#       ms=1e-3, registered at CORRECTIONS 153.9, is where that arm belongs.
#  (ii) THERE IS NO CORPUS ANCHOR AT THIS RUNG.  blk6 at ms=3e-4 in this
#       stratum has n = 1 complete run (`rs-blk6-3e4-s0`, plateau5 92.02); its
#       siblings sit inside MASTER-TABLE row 106's truncation contaminant,
#       re-derived over the 67 `rs-` rows: scalar 0/22 truncated, layerwise

# -----------------------------------------------------------------------------

# INTERVAL (_probe_every = int(PROBE)), set IDENTICALLY on all 12 runs so it

#
#   |dbeta| <= ms per meta-step bounds movement over one stride by ms*PROBE:
#       cfr1, ms = 1e-3, PROBE = 100  ->  0.1  nats, detector bound 0.1004
#       cfr2, ms = 3e-4, PROBE = 100  ->  0.03 nats, detector bound 0.0304

#   beta_true_min <= wall + 0.0304  still has NO FALSE NEGATIVES, and it is

    print("         %2d  %-34s %9d" % (i + 1, names[i], numel[i]))
    lines.append("TENSOR %d %s %d" % (i + 1, names[i], numel[i]))

# ---- guard 4a: the coordinate count each arm ACTUALLY gets, from HF.beta ----
ab = dict(alg='SGDm', weight_decay=0.1, momentum_param=0.99)
am = dict(alg='Lion', meta_stepsize=mst, momentum_param=0.99,
          Lion_beta2=0.9, weight_decay=0)
want = {g_sc: 1, g_lay: T}
for spec in (g_sc, g_lay):
    o = HF(net, spec, alpha0, ab, am, 1, writer=None)
    coords = sum(int(b.numel()) for b in o.beta)
    binit = float(o.beta[0].reshape(-1)[0])
    okt = (o.stepsize_type == spec)
    okc = (coords == want[spec])
    print("guard 4a: %-10s stepsize_type=%-10s beta blocks %d  COORDINATES %d "
          "(want %d)  beta init %.6f  box (%.4f, %.4f)"
          % (spec, o.stepsize_type, len(o.beta), coords, want[spec], binit,
             o._beta_lo, o._beta_hi))
    lines.append("ARM %s TYPE %s COORDS %d PARAMS %d BETA_INIT %.6f"
                 % (spec, o.stepsize_type, coords, tot, binit))
    if not (okt and okc):
        print("!!! guard 4a: %s did not compose to the registered granularity"
              % spec)
        bad += 1
    if abs(binit - float(np.float32(np.log(np.float32(alpha0))))) > 5e-6:
        print("!!! guard 4a: beta init %.8f is not float32 log(alpha0)" % binit)
        bad += 1
    if o._beta_lo != float(clip_c.split(':')[0]) or \
       o._beta_hi != float(clip_c.split(':')[1]):
        print("!!! guard 4a: the live optimiser did not parse BETA_CLIP=%s"
              % clip_c)
        bad += 1

# ---- guard 4e: the clamp and the meta update, ON THE LIVE SOURCE ------------
src_init = inspect.getsource(HF.__init__)
if "BETA_CLIP" in src_init and "_beta_lo" in src_init and \
        "split(':')" in src_init.replace('"', "'"):
    print("guard 4e: BETA_CLIP is parsed from the environment into "
          "(_beta_lo, _beta_hi) on the live source")
else:
    print("!!! guard 4e: the live HF.__init__ does not parse BETA_CLIP as assumed")
    bad += 1
src_step = ""
_m = None
for _cand in ("step", "update", "__call__"):
    if hasattr(HF, _cand):
        _s = inspect.getsource(getattr(HF, _cand))
        if "_beta_lo" in _s:
            src_step, _m = _s, _cand
            break
_flat = "".join(src_step.split())
if "clamp(self._beta_lo,self._beta_hi)" in _flat:
    print("guard 4e: the clamp is applied to beta AFTER the meta update, in "
          "HF.%s" % _m)
else:
    print("!!! guard 4e: could not find beta.clamp(_beta_lo, _beta_hi) in the "
          "live update path")
    bad += 1
src_lion = inspect.getsource(HF.Lion_meta_update)
if "torch.sign" in src_lion and "meta_stepsize" in src_lion:
    print("guard 4e: Lion_meta_update moves beta by meta_stepsize * sign(.)")
else:
    print("!!! guard 4e: Lion_meta_update is not the sign-bounded update the "
          "released floor's justification assumes")
    bad += 1

# ---- guard 4f: the travel bound, in float32, AT THIS BATCH'S OWN ms ---------
# The meta-step COUNT is the whole basis of the floor arithmetic, so it is
# MEASURED off the staged dataset rather than assumed.  DataLoader is built
# with no drop_last, so iterations per epoch = ceil(len(trainset)/batch_size).
_ntrain, _ntrain_src = None, "assumed"
try:
    from torchvision import datasets as _ds
    _ntrain = len(_ds.CIFAR10(root='./data', train=True, download=False))
    _ntrain_src = "measured on the staged dataset"
except Exception as _e:
    _ntrain = 50000
    print("    guard 4f: NOTE -- could not read the staged CIFAR-10 (%s); "
          "falling back to 50000" % repr(_e)[:80])
iters = -(-_ntrain // bs)
print("guard 4f: train set %d images (%s), batch %d, no drop_last -> %d "
      "iterations/epoch" % (_ntrain, _ntrain_src, bs, iters))
steps = epochs * iters
b0 = np.float32(np.log(np.float32(alpha0)))
lo = np.float32(b0)
for _ in range(steps):
    lo = np.float32(lo - np.float32(mst))
hi = np.float32(b0)
for _ in range(steps):
    hi = np.float32(hi + np.float32(mst))
fl_c = float(clip_c.split(':')[0]); ce = float(clip_c.split(':')[1])
fl_r = float(clip_r.split(':')[0])
print("guard 4f: %d meta-steps (%d epochs x %d iterations); float32 travel "
      "bound [%.6f, %.6f]" % (steps, epochs, iters, float(lo), float(hi)))
first_floor = int(math.ceil((float(b0) - fl_c) / mst))
print("          the CLAMPED floor %.1f IS reachable  (%.6f nats of headroom "
      "below it,\n          %d meta-steps of spare travel); it is first "
      "attainable at meta-step %d\n          = %.2f%% of training, so AT MOST "
      "%.2f%% of a run can be exposed to it"
      % (fl_c, fl_c - float(lo), int((fl_c - float(lo)) / mst), first_floor,
         100.0 * first_floor / steps, 100.0 * (steps - first_floor) / steps))
print("          the RELEASED floor %.1f is NOT reachable: %.6f nats below the "
      "bound = %d meta-steps that do not exist"
      % (fl_r, float(lo) - fl_r, int((float(lo) - fl_r) / mst)))
print("          alpha at the reachable minimum exp(%.6f) = %.3e, a normal "
      "float32" % (float(lo), math.exp(float(lo))))
lines.append("META_STEPS %d TRAVEL_LO %.6f TRAVEL_HI %.6f" % (steps, float(lo), float(hi)))
lines.append("FIRST_FLOOR_STEP %d MAX_EXPOSURE %.4f"
             % (first_floor, (steps - first_floor) / float(steps)))
# THE BATCH IS POINTLESS IF EITHER HALF OF THIS FAILS.
if not (fl_r < float(lo) < fl_c):
    print("!!! guard 4f: the released floor is NOT strictly unreachable, or the "
          "clamped floor is NOT reachable, at ms=%g.  THE MANIPULATION HAS NO "
          "CONTRAST AND THIS BATCH MUST NOT BE SUBMITTED." % mst)
    bad += 1
if not (0 < first_floor < steps):
    print("!!! guard 4f: the clamped floor cannot be reached inside the budget")
    bad += 1
# and the same at the tuned meta-stepsize, which is why no arm is run there
lo4 = np.float32(b0)
for _ in range(steps):
    lo4 = np.float32(lo4 - np.float32(1e-4))
print("guard 4f: at ms=1e-4 the bound is %.6f, %.6f nats ABOVE the -15 floor, "
      "so the\n          box is inert there BY ARITHMETIC and no ms=1e-4 arm is "
      "needed" % (float(lo4), float(lo4) - fl_c))
lines.append("MS1E4_TRAVEL_LO %.6f" % float(lo4))
if float(lo4) <= fl_c:
    print("!!! guard 4f: the -15 floor IS reachable at ms=1e-4; the design's "
          "justification for omitting that rung does not hold")
    bad += 1
# cfr1's rung, reproduced so the two registrations can be checked against
# each other from ONE run of this guard
lo3 = np.float32(b0)
for _ in range(steps):
    lo3 = np.float32(lo3 - np.float32(1e-3))
print("guard 4f: at ms=1e-3 (cfr1's rung) the bound is %.6f, so cfr1's released "
      "floor had\n          only %.6f nats of margin where this batch has "
      "%.6f -- the instrument\n          transfers with a WIDER margin, not a "
      "narrower one"
      % (float(lo3), float(lo3) - fl_r, float(lo) - fl_r))
lines.append("MS1E3_TRAVEL_LO %.6f" % float(lo3))

# ---- guard 4h: the PROBE stride bound AT THIS ms ----------------------------
stride = mst * probe_every
print("guard 4h: PROBE=%d and |dbeta| <= ms per meta-step, so one stride moves "
      "beta by at\n          most %.4f nats.  The registered detector bound is "
      "0.0304 (cfr1's was\n          0.1004 at ms=1e-3): the wall detector has "
      "NO FALSE NEGATIVES and is %.2fx\n          TIGHTER than cfr1's at the "
      "same 500 records per run." % (probe_every, stride, 0.1004 / 0.0304))
lines.append("PROBE_EVERY %d STRIDE_BOUND %.6f" % (probe_every, stride))
if stride >= 0.0304:
    print("!!! guard 4h: ms*PROBE = %.6f is not below the registered detector "
          "bound 0.0304" % stride)
    bad += 1
max_lo_records = len([s for s in range(0, steps, probe_every) if s >= first_floor])
n_records = steps // probe_every
print("guard 4h: of the %d records PROBE=%d writes, AT MOST %d (%.2f%%) can "
      "carry a pinned\n          coordinate at this rung.  cfr1's ceiling was "
      "83.80%% and cfr1 measured\n          83.2-83.4%%; a cfr2 lo_rate near "
      "%.2f is a SATURATED manipulation."
      % (n_records, probe_every, max_lo_records,
         100.0 * max_lo_records / n_records, max_lo_records / float(n_records)))
lines.append("MAX_LO_RECORDS %d OF %d" % (max_lo_records, n_records))

# ---- guard 4g: the probe fields this batch's manipulation check depends on --
src_probe = inspect.getsource(HF._probe)
need = ("beta_true_min", "beta_true_max", "n_at_lo", "n_at_hi", "n_beta")
missing = [k for k in need if k not in src_probe]
if missing:
    print("!!! guard 4g: the live _probe does not write %s" % ", ".join(missing))
    bad += 1
else:
    print("guard 4g: the live _probe writes %s -- the coordinate-denominator "
          "fields\n          the manipulation check reads" % ", ".join(need))
src_pinit = inspect.getsource(HF._probe_init)
if "os.environ.get('PROBE'" in src_pinit.replace('"', "'") and \
        "PROBE_DIR" in src_pinit:
    print("guard 4g: PROBE is an INTERVAL read from the environment and "
          "PROBE_DIR is honoured")
else:
    print("!!! guard 4g: _probe_init does not read PROBE/PROBE_DIR as assumed")
    bad += 1
# TB emits beta only for scalar/blockwise: the reason the probe is mandatory.
# Comments are part of inspect.getsource(), so the test is on ACTIVE lines only.
_tb = [ln.split('#')[0] for ln in inspect.getsource(HF.step).splitlines()]
_emit = [ln for ln in _tb if "add_scalar" in ln and "beta" in ln]
_lay_emit = [ln for ln in _emit if "layerwise" in ln]
print("guard 4g: HF.step emits %d active beta scalars to TensorBoard, %d of "
      "them for a\n          layerwise arm" % (len(_emit), len(_lay_emit)))
for _ln in _emit:
    print("          %s" % _ln.strip())
if _lay_emit:
    print("!!! guard 4g: a layerwise beta emission exists on the live source; "
          "the claim that\n    the fine arm is unauditable without the probe "
          "is FALSE and must be rewritten")
    bad += 1
else:
    print("guard 4g: confirmed on the live source -- TensorBoard emits beta for "
          "scalar and\n          blockwise ONLY, so the layerwise arm is "
          "unauditable without the probe")

if bad:
    raise SystemExit(1)
open(out, "w").write("\n".join(lines) + "\n")
print("guard 4: PARTITION-MANIFEST.txt written to %s" % out)
